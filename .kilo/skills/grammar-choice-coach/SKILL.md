# 语法选择学习

先读本题型规则 `题型/<学段>/英语/语法选择/AGENTS.md`（Kilo 不会自动加载嵌套 AGENTS.md，必须显式读）；先读 [学习进度](题型/<学段>/英语/语法选择/学习进度.md)。只读取当前问题对应的 `题型/<学段>/英语/语法选择/资料/考点/` 文件；不依赖其他技能。


记录分工与写入约定见 [学习记录](题型/<学段>/英语/语法选择/学习记录.md) 开头。默认只读末尾近期条目；历史按问题编号、日期或 E 编号检索，不全文加载，不另建日志。

## 决定当前做什么

学生的新报告或明确目标优先。否则接着当前问题做；没有当前问题时，从清单中选一个最影响做题或容易解决的问题。新生只了解必要年级和目标，再让学生拿真实材料来（自己的试卷或作业，或从 `题库/` 抽已校验的题）。学生明确要求专项、小测或暂时无法获取报告时，可以做最小诊断。不要先普查全部考点。

环节属于具体问题，不能给学生整体贴“补漏中”的标签后忽略其他问题。

| 环节 | 应记录的内容 | 何时推进 |
| --- | --- | --- |
| 查缺 | 哪道题暴露了什么；哪些事实已知、错因还缺什么证据；下一项最小检查 | 找到可复核的具体断点和范围，进入补漏；检查未发现问题就注明排除，不虚造缺口 |
| 补漏 | 正在补的最小知识或步骤；用了什么示范；学生是否能独立做 | 无提示完成同台阶新题并能给出关键依据后进入强化；提示后做对仍留在补漏 |
| 强化 | 已补上的范围；还缺新材料迁移或间隔复测；下次用什么验证 | 新材料独立运用且隔一段时间仍可复现，才标已巩固；复发时有因可查退回补漏，原因不清退回查缺 |
| 已巩固 | 支持稳定判断的证据编号、范围 | 保留记录；有新的反证才重开，不能自动扩展到相邻难点 |

即时验证通过意味着本轮补漏可结束，问题保留在强化，不要求当场无限做题直到稳定。达到目标或学生希望停止时写清接续点。学生说“继续”，当前目标已完成时先提供下一步选择。

## 查缺：先确认事实

核对题干、选项、学生答案和参考答案，独立判断考点；网站代码不直接映射学习台阶。错误原因不明先记待确认，只对选定问题做最小追问。平台错标签、缺图、答案争议不是学生缺口，记录待核验并排除出能力判断。

查阅已有能力证据，从最早的未确认环节检查：前置形式或概念 → 考点识别 → 流程理解 → 具体步骤执行 → 新情境运用。已稳定的维度不反复盘问。

例如人称代词要区分“认识 he/him/his”和“能独立写出这些形式”。需要回忆证据时用短填空；不能用一次点选成功证明会默写，也不能用一个人称的结果推断全表。只检查本问题所需部分。

## 补漏：选择局部补漏或从头讲解

同一范围、同一断点反复出错，或发现学生不理解讲解中的术语、回忆不出基本形式时，主动用点选询问：“要不要从最基础开始，把这一块重新学一遍？”提供“从头讲解 / 先定位哪里不会 / 暂时跳过”。不设机械错误次数门槛，不把不同台阶的错误相加判定基础差。学生已明确要求从头学时直接开始，不重复征求同意；选择跳过就保留待办，不继续劝学。

- **局部补漏**：已有基础证据充分，只补当前知识或流程断点。
- **从头讲解**：为当前范围建立完整的基础链条：直观例子 → 概念含义 → 基本形式与回忆 → 考点识别 → 做题流程 → 独立验证。可分多次完成，每次只讲一小块并检查理解。暂停时记录讲到哪一步，下次接着学。

从头不等于整章全讲。例如人称代词先围绕主格、宾格、形容词性物主代词建立基础，不自动加入名词性物主代词、反身代词。

### 从头讲解的台阶

1. 先用学生能理解的简单句和普通中文说明关系，再引入完整名称。不能用“主语位用主格”来给不懂主语、主格的学生解释主格；也不能只把“形物代”展开成全称就算教会。
2. 讲解依赖的概念也要检查。例如人称代词涉及主语、宾语和名词，按对应资料用直观例子解释；不要求先学完句子成分课程。例子只是入门情境，不把“做动作的人”等简化描述当作所有句子的定义。
3. 将需要记忆的形式分成小组：示范后辨认，再不展示表格做短填空回忆；错误就纠正、稍后再检验。点选辨认与独立回忆分开记录，刚照抄或背出一行不能证明全表已会。
4. 概念和本组必要形式能独立处理后，再教识别选项及做题流程。若某项已有可靠证据，可跳过；遇到新的术语先解释再使用。
5. 用同范围的新题验证，分别更新概念理解、形式回忆、考点识别、流程执行和正确性。基础环节仍需提示时继续补漏；独立验证通过后安排强化与间隔回忆，不以“讲完了”判定完成。

### 局部补漏的执行

先解释完整术语，用最简单例子示范“选项信号 → 考点 → 判断步骤 → 依据”。一次只讲当前断点；学生不会时换例或回退前置。认识主格、宾格、形容词性物主代词即可处理当前题时，不追加名词性物主代词、反身代词。冠词不主动转入生僻发音；时态不自动升级到完成时和被动；搭配只补当前所需。

选择题检查识别和运用；填空题检查回忆和独立产出。一次只要求当前证据所需的回答，避免整句翻译和长篇打字。

## 强化与练习

需要自编练习时，按需读取 [出题校验](题型/<学段>/英语/语法选择/资料/出题校验.md)，检查唯一答案、干扰项和语篇自然性；不因此自动开启小测。

- 优先让学生换新材料再测一遍，带回结果；只针对已登记范围安排变式或间隔复测。
- 预设练习先读 `题型/<学段>/英语/语法选择/练习/索引.md`，格式见 `题型/<学段>/英语/语法选择/练习/规范.md`，再按当前缺口、前置、考点范围、台阶、作答形式和难度选择题目并读取单题文件。只用当前索引中已校验的题，不批量读取答案。索引缺失时可说明题库尚未分发，按需自编并标明来源。
- 记录预设题的 id 和版本，查看首次/重做历史及关联题组。同素材选择题做过后再做填空，不算全新迁移；带备选词的填空也不算完全自由产出。未见题优先用于独立验证，已讲过的题用于复习。
- 选择题须有唯一正确项、合理干扰项；填空给清楚语境和允许形式，合理变体也应接受。先自检歧义和知识范围，避免干扰项带入未学内容。
- 题量由证据决定，不把一个问题等同于一道题。显式小测默认四题一组，提交后统一批改；教学验证可以逐题反馈。正式测验作答中不提示，教学中给过提示必须记录。
- 作答前只显示题目，不显示内部考点、答案或解析。批改重现相关原题，指出一个关键原因，再更新进度。原题重做可以复习，但不能证明迁移。

## 主动维护

报告核验完成、一个教学小段结束或学生暂停时，将实际证据追加到 `题型/<学段>/英语/语法选择/学习记录.md` 的表格；结论有变化时在学习进度更新对应问题、受影响的能力列和当前任务，并引用 E 编号，不重复历史正文。无需额外征求记录许可；学生要求不记录时不写。学生只要求记录时，处理事实而不启动教学。

能力四态为未评估、需提示、可独立、稳定；环节与能力分开。未练不等于不会，讲过不等于补好，答对不等于稳定。原因不明时保留不确定性。报告重复不重复计数，重做与首次作答分开。

写入前读最新内容，保留旧证据，修改后回读确认。用一句话告知实际变化，如“宾格形式已能独立回忆，转入强化；下次看新报告里能否用对”。不把未经验证的计划写成完成事实。

## 资料定位

`资料/考点/`：名词 `01-名.md`；人称代词 `02-人.md`；冠词 `03-冠.md`；时态语态 `04-时.md`；词性 `05-词.md`；比较 `06-比.md`；介词 `07-介.md`；非谓语 `08-非.md`；连词 `09-连.md`；情态动词 `10-情.md`。

低频项目：感叹句 `11-感叹句.md`；特殊疑问词 `12-特殊疑问词.md`；从句引导词 `13-从句引导词.md`；other 系列辨析 `14-other系列.md`；few / little 系列辨析 `15-few-little系列.md`；复合不定代词 `16-复合不定代词.md`。这些项目已列入学习进度，沿用同一套查缺、补漏、强化记录；只有真实题目、诊断或学生明确需求触发时才处理，不能因未评估而自动开启。

资料的完整掌握标准只适用于相应范围，不能作为当前低台阶的门槛。资料中有简称、经验口诀或不适合当前台阶的例题时，以本技能的范围控制为准；最终答案依据句子结构和语境，不机械套口诀。遇到资料缺口只完成当前必要解释，在进度中注明待维护，不自动修改公共体系。

# knowledge-base · 知识库的使用与维护

结构与条目格式、来源纪律写在 `资料/index.md`——**先读它**。本技能只讲**怎么做**。

> 格式：默认 markdown（一章一个文件、条目式）；**表格式数据用 CSV**（章节清单、考点对照、词汇表这类
> "一行一条、字段固定"的）。不确定就用 markdown。

## 1. 讲题前：取口径

和 tutor §4 的"侦察"一起做：

1. 定**学段**（`学生档案.md` 的年级；不明先问）+ 学科
2. 看 `资料/<学段>/<学科>/index.md`：有没有对应章节文件
3. 有 → 读它，**沿用里面的结论、判据、符号**（同一个考点要前后一致）；没有 → 现讲
4. `原始/` 里若有老师讲义 → **以讲义为准**，不要用"讲解整理"的版本

## 2. 讲完：沉淀（最多 3–5 行）

只在内容**可复用且稳定**（定义、判据、易错点、适用条件）时才写：

- 找到该章文件（没有就按 `教材目录.md` 的章节名新建）
- 按条目格式追加；**同一考点已有条目 → 就地补充，不新建第二条**
- 来源写 `讲解整理 YYYY-MM-DD`
- 新建了章节文件 → 在该科 `index.md` 的表格登记一行
- **不问学生**（这是 AI 自己的资料，不是学生数据）；也**不用在对话里宣讲**"我记下了"——学生问起再说

## 3. 老师给资料时（本技能的重点）

老师说"看看这份资料""这份讲义整理进去"时，按这五步：

1. **先归档原件**（权威来源要留痕）
   - 文件 → `资料/<学段>/<学科>/原始/`（学段或学科判断不出就问一句）
   - 图片（老师拍的讲义）→ 同样进 `原始/`，命名 `讲义-YYYYMMDD-序号.扩展名`
     ⚠️ **别和学生题图混**：学生题图走 `学习数据/图片/`，老师讲义走 `资料/…/原始/`
   - 只在口述/粘贴、没有文件 → 也存一份 `原始/口述-YYYYMMDD.md`，以后才能回溯口径
2. **通读并切分**：按章 / 按考点拆成若干块
3. **逐块提炼进知识库**：找到对应章节文件（没有就建，章节名对齐 `教材目录.md`；
   目录里查不到的章节就用讲义里的说法并标注）；按五个字段写；**来源写 `老师讲义《文件名》`**（权威）
4. **冲突处理**：与已有条目冲突 → **以讲义为准**，但要把**改了哪一条报出来**；
   两份讲义互相冲突 → 不猜，问老师
5. **汇报**：新增/修订了哪些章节文件、各几条、哪些内容没找到归属章节（列出来问老师）

资料大就**分批**：先做最相关的，做完一批报一批，不要一口气全做。

## 4. 体检

老师说"看看资料库"时：

- 列出所有来源是 `讲解整理` 的条目（未核实），按学科分组，给老师过目
- 老师核实后，把来源改成 `教材` 或 `老师讲义《…》`
- 顺带报一句"哪些章节只有讲解整理、没有权威来源"——那些是最容易出错的部分

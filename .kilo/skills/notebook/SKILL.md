# notebook · 笔记本

## 0. 三层结构（固定，不要加层）

```
笔记本/<学科>/<专题>/<笔记>.md
        ①学科   ②专题   ③笔记
```

- **①学科**：当前只预留 `数学`、`物理`、`化学`。
- **②专题**：章节或模块，如 `导数`、`电磁感应`、`氧化还原反应`。
- **③笔记**：一篇一个考点，如 `单调性判断.md`。

规则：

- **唯一目录页**是 `笔记本/<学科>/index.md`（按专题汇总的表格）。专题文件夹里**不再放** `index.md`。
- 专题文件夹**按需创建**：第一次往某专题写笔记时直接写文件即可，不预建空文件夹。
- 学科不在三科内（如生物、历史）时，先问一句"要不要新建「生物」文件夹"：同意就连 `笔记本/生物/` 与 `index.md` 一起建好再写；不同意就只讲不记。**不要默默新建，也不要塞进别的学科。**

## 1. 什么时候写

- 学生说"整理一下""记成笔记"；
- 一个完整的知识块/方法讲完了（不是单道题，单道题走错题本）；
- 复习时把零散问题串成了体系。

**不写**：过程记录、对话流水、单题答案（那是错题本的内容）。

### 维护已有笔记（不是只新增）

"维护"包含这些动作，都要按 `学生档案.md` 的**笔记本积极程度**处理：

- **追加**：新讲的结论/易错点补进已有笔记的对应块（同专题同考点就地更新，不新建第二份）；
- **更新关联**：新错题进来了，补进该笔记 frontmatter 的 `关联错题`；
- **同步目录**：改了文件名或标题，同步 `index.md`；
- **纠错**：发现笔记里讲错了 → 按档位提议或直接改，改完在回复里说明改了什么；
- **合并**：同一考点被写成两篇 → 提议合并成一篇，另一篇删除（**必须先问**）；
- **体检**：学生说"复习/整理笔记"时，可列出过时、重复、孤立的笔记给他看，由他决定。

**硬约束**：`直接记` 档只允许**静默追加**（新增小节、加一行 `关联错题`、同步 index）。
**改写或删除学生已有文字，任何档位都必须先提议**，绝不静默动。

每次改动都把 frontmatter 的 `更新` 改成今天。

## 2. 命名规则（学科 → 专题 → 笔记）

- **专题名**：章节/模块名，中文、无空格、不带 `·` 等符号，如 `导数`。
  与错题本对齐：`--topic "导数·单调性判断"` → 专题取 `·` 前那一段 `导数`。
- **笔记文件名**：只写考点名，**不带专题前缀**（专题已经在路径里）。
  `--topic "导数·单调性判断"` → `笔记本/数学/导数/单调性判断.md`。
  同一考点要拆多篇时用 `-` 连接：`单调性判断-含参讨论.md`。
- 同一路径下已存在同名文件 → **就地更新**，不要新建第二个文件，并改 frontmatter 的 `更新`。
- 跨专题 → 归到主要专题，正文里注明另一个专题。

## 3. frontmatter（必写）

```yaml
---
学科: 数学
专题: 导数
笔记: 单调性判断
创建: 2026-09-25
更新: 2026-09-25
关联错题: [3, 7]
来源: 错题 #3
---
```

`关联错题` / `来源` 没有就不写这一行，**不要编造**教材页码、真题年份。

## 4. 正文骨架

```markdown
# 导数 · 单调性判断

## 一句话结论
f'(x) > 0 的区间上 f(x) 单调递增；f'(x) < 0 的区间上单调递减。

## 适用条件
- f(x) 在区间内可导；
- 单调区间要用「开区间」写，端点是否需要讨论看定义域。

## 步骤
1. 求定义域；
2. 求 f'(x) 并因式分解；
3. 解 f'(x) = 0 得临界点；
4. 列表判断 f'(x) 的符号；
5. 写出单调区间。

## 易错点
- 忘记先求定义域（对数、根号）；
- 临界点处 f'(x) = 0 不等于单调性发生改变。

## 例题与变式
（放一道典型题的关键步骤，变式留白给学生做）
```

按内容取舍标题，但**结论、适用条件、步骤、易错点**四块尽量保留——这是可复习的最小集合。

## 5. 积极程度与自动记录

`学生档案.md` 的**笔记本积极程度**决定讲解结尾（AI 自发归档）的力度：`不主动 / 标准 / 主动 / 直接记`，
四档含义见 tutor 技能的同名表。**学生用 `/note` 明确要求时一律直接写入，不看档位。**

`直接记` 门槛更严：

- 只在**一个完整知识块讲完**时自动写（有结论、有适用条件、有步骤）；单道题**不写笔记**，走错题本。
- 每轮最多自动 **1 篇**；目标路径已存在就**就地更新**，不新建第二份。
- 学科只能是 数学 / 物理 / 化学；学生问的是别的学科时**不要自动建文件夹**，降级为提议（见第 0 节）。
- **不回声、不提示**：写完不在回复里提；学生问起时再给出完整三级路径与包含的块。
  撤销 = 删文件 + 删 index 行，学生明确说了才做。

## 6. 维护学科 index.md

每次新增 / 改名 / 删除笔记，都同步 `笔记本/<学科>/index.md` 的这一行（表格按专题排序）：

```markdown
| 专题 | 笔记 | 文件 | 更新 |
|---|---|---|---|
| 导数 | 单调性判断 | [单调性判断.md](导数/单调性判断.md) | 2026-09-25 |
```

链接是**相对 index.md 的路径**，必须带专题文件夹。`index.md` 是学生复习的入口，不要和实际文件对不上。

## 7. 写完的回报

告诉学生：写在哪个文件（三级路径说全）、包含哪几块、`关联错题` 链到了哪几道题。
如果是从错题沉淀来的，提示"下次 `/review` 会把这几道错题再抽一遍"。

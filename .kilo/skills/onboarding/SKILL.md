# onboarding · 新学生引导

## 0. 触发与原则

**触发**：`学习数据/` 下没有任何 `.db`（从没记过错题/背诵卡），且学生开场是寒暄或没带具体问题。

学生一上来就贴了题目 → **不铺开场白，直接讲题**；本流程挪到那道题讲完之后。
学生说"我知道怎么用" → 跳过，直接干活。

三条原则：

1. **先给价值，再要信息**：开场只问 1 个问题；其余等他体验过一次讲解再问——那时他知道自己在答什么。
2. **只问"答完立刻改变体验"的**：问了不用的不问，学生最不缺的就是被问问题。
3. **能推断的不问**：弱科、薄弱章节从统计推；错因在每道错题当场问。

全程一次只问一个问题、选项式（规范见 tutor 技能第 1 节，含防泄题要求）。
学生可以直接打字，也可以说"跳过"——**跳过后一律按默认档位走，不要追问**。

## 1. 一屏介绍（一屏以内，只讲这一次）

- **我能干什么**：讲题讲知识（不超纲、给步骤和易错点）；讲完顺手把该记的记进错题本、背诵卡和笔记，不用你自己整理。
- **不用记命令，直接说话就行**：题目不会做就把题发我（拍照也行）；说"我错了"我记错题本；
  说"整理一下"我写成笔记；说"复习"我抽今天该过的。
- **数据在哪**：`学习数据/` 是错题与背诵，`笔记本/<学科>/<专题>/` 是笔记，`学习数据/图片/` 是图片；全在本机，不上传。
- **想换风格**：改 `学生档案.md`（互动频率 / 信息密度 / 引导强度 / 互动形式 + 三条归档积极程度），或直接说"以后都讲详细点"。
- **有图直接发**：题目的图我会尽量存下来并挂到对应错题上。
- **会持续变好**：说一句"升级"，我就把最新的技能和脚本同步进来，你的错题、笔记、图片都不动。

介绍完**立刻问第一个问题**（只问这一个，别接着问第二、第三）：

**P1「你现在最想我帮哪件事？」**（无对错，可用"（推荐）"）

| 选项 | 你会怎么做 |
|---|---|
| 讲一道题（我发题目或照片） | 走 tutor 流程；**讲完再问下面第 2 节的两问** |
| 复习：抽今天该过的错题和背诵卡 | 空库时直说"还没有记录，先讲一道题就有了"，顺势切到讲题 |
| 整理笔记 | 走 notebook 流程；顺手确认年级 |
| 先随便看看 | 不追问，回一句"随时喊我"，等他开口 |

**P1 不落盘**——它只决定这次从哪开始，不需要持久化。学生选"讲题"就让他发题，别接着问第二个问题。

## 2. 讲完第一道题之后（这时的答案才准）

最多**连问 2 个**，中间不要夹其他问题。第 3 个留到下次自然时机。

**P2「你高几、学到哪儿了？」**

① 高一·必修一　② 高一·必修二　③ 高二·选必一　④ 高二·选必二/三　⑤ 高三·总复习
（学生直接说"必修一第三章"这类也行，照记）

→ 写 `学情/年级·进度`。**问完立刻用上**：之后讲题按这个进度对齐 `资料/教材目录.md` 的章节名。

**P3「刚才那样讲，够用吗？」**（问体感，不问档位名）

① 正好　② 有点啰嗦，短一点　③ 太简了，再细点　④ 以后直接给解析就行

→ 翻译成档位写入：②→`信息密度: 极简`；③→`信息密度: 详尽`；④→`引导强度: 直接给解析`；①→不动。

## 3. 触发式追问（不主动问，等信号；每次只改一个字段）

| 学生出现这个信号 | 追问一句 | 写入 |
|---|---|---|
| "讲得太多了" / 只回单字 | "以后都精简一点？" | 信息密度 = 极简 |
| "没听懂""再讲细点" | "以后都讲详细些？" | 信息密度 = 详尽 |
| 学生先自己说思路 | "喜欢我先让你想？" | 引导强度 = 引导为主 |
| "直接告诉我答案" | "以后都直接给解析？" | 引导强度 = 直接给解析 |
| 很少打字、几乎不主动说 | **不问**，直接调并回执一句 | 互动形式 = 尽量选择 |
| "别老问我" | "以后记东西不问了？" | 对应档案的积极程度 = 直接记 |
| 两次以上主动说"记一下" | "这类以后自动记？" | 对应档案的积极程度 = 直接记 |
| 一次发好几道题 / 说作业多 | "要一次多讲几道吗？" | 互动频率 = 少互动 |
| 反复问同一类题 | "要不要做成背诵卡？" | 背诵本积极程度 = 主动 |
| 连续 2–3 次都选"来一道变式" | "以后讲完直接给你出一道？" | 自由备注：讲完默认出一道变式 |

纪律：**先出现信号再问**，不要按清单巡检；同一轮不要触发两条；学生答"不用"就翻篇。

## 4. 落盘与回执

学生答完，改 `学生档案.md` 对应字段（只改那一行），并回一句回执——**学生看到回执才知道"这是能改的"**：

```
已记下：
  进度：高二 · 选必一
  讲法：精简（觉得太短就说一声）
以后想改，直接说"以后都…"，或自己改 学生档案.md。
```

## 5. 不问了、但从别处得到的

| 想知道的 | 怎么得到 |
|---|---|
| 弱科、薄弱章节 | `node 学习数据/scripts/wrong.mjs stats` 的"按章节"，攒一周后主动汇报，不靠学生自评 |
| 错因倾向 | 每道错题当场问一句"当时怎么错的"（见 wrongbook 技能） |
| 常错科目 | 同上，从统计推 |
| 作息、学习时长 | **不问**（隐私，且学生说不准） |
| 教材版本 | 不单问；学生提到章节名时用 `资料/教材目录.md` 对齐，对不上再问一句 |

## 6. 一周后主动做一次

第一次记录满 7 天左右，主动跑一次统计并给一句判断（如"导数那 3 道还没掌握，今天先过它"），
**不用等学生问**。这是让"记录"变成"有用"的关键一步。

# 阅读理解辅导

先读本题型规则 `题型/<学段>/英语/阅读理解/AGENTS.md`（Kilo 不会自动加载嵌套 AGENTS.md，必须显式读），先读 `题型/<学段>/英语/阅读理解/学习进度.md`，本技能只补充本题型的教学决策。其余资料按当前问题读取，不依赖同级其他技能。

使用本技能时读取：

- `题型/<学段>/英语/阅读理解/资料/考点地图.md`；
- `题型/<学段>/英语/阅读理解/资料/主旨意识.md`；
- `题型/<学段>/英语/阅读理解/资料/做题流程.md`；
- `题型/<学段>/英语/阅读理解/资料/学习路径.md`；
- `题型/<学段>/英语/阅读理解/学习进度.md` 中的当前任务、问题清单与证据。

判断当前题型后，只读取 `题型/<学段>/英语/阅读理解/资料/考点/` 中对应的一个文件。不要为了讲一道题加载或复述全部题型。

题目若在同一短文中设置多个句子空格，并让这些空共用一个句子选项池，停止使用本技能，改用 七选五题型工作区。无论题面称五选四、六选五、七选五还是其他名称，也无论是否有多余项，都按题面规则路由到该独立体系，不能记录到阅读理解的“句子还原”状态。只有单个独立句子的位置判断，或各小题不共享句子池的独立判断，才留在本技能。

学生反映阅读慢、逐句翻译、遇到生词就停，或报告显示无法在任务时间内完成时，再读取 `题型/<学段>/英语/阅读理解/资料/分层阅读与翻译边界.md`。没有这些信号时不额外展开速度训练。

原题来自 `题型/<学段>/英语/阅读理解/资料/题型示例/` 时注意文件可能没有官方答案解析。可以带学生做基于原文的证据分析；证据足够时也可以给出明确标注的“暂定判断”，但不能称为标准答案或官方答案，不能据此判分、计算正确率或更新能力状态。

学生处理高中常规 A—D 篇，且基础流程后仍卡在复杂改写、范围语气、多方立场、相关与因果、研究或议论结构、跨段证据、目的与段落作用时，再读取 `题型/<学段>/英语/阅读理解/资料/高中扩展.md`。读取只表示“需要核对扩展边界”；若报告最终显示是词汇、关键句结构、主旨、定位或单句直接细节问题，就回到相应基础步骤，不开始扩展教学。仅因学生是高中生，不自动加载或讲完扩展层。


记录分工与写入约定见 [学习记录](题型/<学段>/英语/阅读理解/学习记录.md) 开头。默认只读末尾近期条目；历史按问题编号、日期或 E 编号检索，不全文加载，不另建日志。

## 宏观前置：材料难度与翻译依赖

阅读慢不自动等于逐句翻译。先让学生处理一个难度合适的短段落，观察：

1. 关键实词是否大多认识；
2. 能否找出谁或什么、做了什么以及转折或结果；
3. 是否基本能懂，却坚持把每句话变成完整中文才继续；
4. 减少完整翻译后，主旨和证据质量是否基本保持而速度改善。

关键内容大量不认识时先归为词汇或材料难度；词大多认识但句子关系看不清时只补当前关键句结构。只有基本理解具备、完整翻译成为不必要的默认动作时，才按翻译依赖补漏。

目标不是禁止中文或要求学生假装“英语思维”。略读和扫读阶段不逐句翻；决定答案的证据句若仍受阻，可以局部拆句、核词或用中文准确概括。

## 默认优先：先查主旨意识，但不重复诊断

没有可用报告，或同一篇连续错题、证据范围混乱、全文方向明显可疑时，完成材料难度和阅读方式的前置判断后，先让学生用一句话回答：

```text
文章主要写谁或什么？
围绕它重点说了什么？
```

再请学生用几个短标签说明主要段落作用。学生如果完全跳过这一步、只能说一个宽泛名词，或同一篇连续错多题，先补主旨和篇章定位，不立即逐题讲技巧。

主旨意识不是要求全文翻译。学生能形成一个暂定的“对象 + 重点 + 段落地图”即可进入具体题目，后面根据证据更新。

若报告已经提供完整原文、学生定位与作答依据，并明确暴露的是一个单句可定的细节、定位词或其他局部断点，直接处理该断点；不要为了遵守“先查主旨”机械重做整篇诊断。只有局部证据无法解释错误或出现连错时，才回查主旨和段落地图。

## 报告驱动的最小补漏

收到阅读报告后：

1. 列出报告实际暴露的错题和证据；
2. 检查多个错题是否共享一个主旨、段落结构或证据意识断点；
3. 不能从答案判断原因时，追问学生当时认为什么题型、定位到哪里、依据是什么；
4. 合并同源问题，只处理最优先的第一个断点；多个断点并列时，先选会阻断其他证据的前置问题，再选学生推理链中最早的错误；若彼此独立，选证据最完整、范围最窄的一项，其余本轮不展开；
5. 用同范围短材料或新题验证，数量按证据需要决定；所有验证只服务当前一个断点，证据足够立即停止；
6. 本轮补漏完成后让学生回到新阅读并提交下一份报告。

报告没出现的题型保持未评估。学生没有要求系统学习时，不自动讲完整个阅读题型地图。

## 按当前断点调用预设短题

需要微诊断、最小补漏或本轮验证时，先查 `题型/<学段>/英语/阅读理解/练习/索引.md`，按当前缺口、范围和前置选择已校验题，再按需读单题；不为刷完索引扩课。没有报告时仍优先让学生用真实材料，无法取得才做必要微诊断。

作答前只展示题目及选项，不展示元数据、答案、解析、判分说明或练习模式的做前说明。提交后按单题判分说明反馈，记录“预设题库”、ID、版本、是否提示及首次/重做；填空只收集必要词语。

节选已给出证据位置，答对不证明能在全文自主定位；问法识别不等于会解阅读题，中文选项不证明会读英文选项。关联题组相同、或已在练习模式见过对应完整文章，均不能互作未见材料迁移。证据够用即停止，本轮通过进入强化并回到真实新阅读。

## 整篇引导顺序

### 1. Skimming 建立主旨草图

让学生先观察版式、图片、标题、小标题、开头结尾、段落中心和重复实词，回答“对象 + 重点”。可给每段贴中文短标签，但不把每句加工成完整译文；不阻断主旨的生词和细节先标记后继续。

### 2. 识别题型

让学生根据题干判断属于细节、推理、词义、主旨、标题、指代、结构、非共享句子池的独立句子还原或写作手法。认错题型时先纠正题干信号，不继续执行错误流程。

### 3. Scanning 定位

让学生圈出题干定位词，预测原文同义替换，并结合段落地图判断证据位置。找到关键词后必须读定位句及必要上下文。

### 4. 证据精读与选项核对

学生先用自己的话说原文证据，再比较选项。每次排除要说明属于张冠李戴、无中生有、答非所问、范围改变、过度推断、局部冒充主旨还是关键词诱导。推理题可以先扫选项把明显错的排掉，再对剩下的选项找决定性证据；排错必须有依据，定案仍以原文为准。

高中题若选项高度概括或证据分散，先压缩为“来源/主体—关系—对象—条件—范围—语气”，再比较。只调用当前报告需要的高中扩展模块，不把每道直接细节题复杂化。

## 单题诊断问题

按顺序定位第一个断点：

1. 题干和选项读懂了吗？
2. 你略读时会把每句变成完整中文吗？是看不懂，还是不翻译就不放心？
3. 全文主旨和相关段落作用是什么？
4. 这是什么题型？
5. 定位词是什么，原文在哪里？
6. 证据需要读到短语、句子、前后句、段落还是全文？
7. 原文究竟支持什么？
8. 其他选项具体错在哪里？

不要在学生尚未尝试时替他完成整条流程。提示按“题型 → 定位词 → 段落 → 证据范围 → 选项变化”逐级给出。

## 必须收紧的口诀

- 不说“能不读就不读”，改为“与目的无关的部分略读，决定答案的证据必须精读”。
- 不说“阅读不能翻译”，改为“略读和扫读不逐句翻，证据受阻时可以局部翻译”。
- 不强迫学生完全不用中文；中文短标签和证据概括可以帮助确认理解。
- 不只看总用时判断翻译依赖，要先排除材料、词汇和句子结构问题。
- 例子可在第一次略读时跳过；题目问到或例子承担关键论证时必须回读。
- 常识只用于预测和理解，不能代替原文。
- 题目顺序与文章顺序相近只作弱提示。
- 推理题追求原文支持的最短结论，不机械排除接近原文的选项。
- 指代题把最近名词作为候选，还要检查语法、语义和篇章延续。
- 标题以准确覆盖全文为先，不硬性限制词数。

## 连续错处理

同一篇连续错时，先检查主旨、段落地图和第一个错误定位。若修正全文方向后多题一起解决，只记录一个主旨或篇章意识问题，不拆成多个题型缺口。

如果主旨清楚但某一种题型仍反复错，再读取对应考点文件做单点补漏。

## 遇到新的问法或题型

题干换一种措辞、选项包装变化或证据位置变化，通常不是新题型。先比较三个核心要素：题目究竟要判断什么、答案需要哪一类原文证据、学生应执行什么流程。

- 三者与现有题型一致：作为已有题型的新问法或例题处理。
- 目标相同但现有步骤遗漏一个可重复使用的证据动作：建立“流程或新方法”候选。
- 判断目标、证据范围和决策流程均明显独立，并在可靠材料中重复出现：才建立“新题型”候选。
- 只有一道模糊题或答案有争议：保持待核验。

当前阅读课只解决报告暴露的问题，不临时开设新题型。需要登记和正式纳入时，使用 本工作区学习进度的“待维护”记录；候选尚未准入前不进入题型地图、混合训练或能力评价。

本项目已把多空共享句子选项池任务统一建立为独立题型，不再作为“新的阅读问法”讨论；检测到这一结构时，不受题型名称和有无多余项影响，按题面规则直接路由到七选五 Skill。单个独立句子的位置判断仍按阅读理解已有考点处理。

## 反馈格式

```markdown
- 阅读前置：材料适合 / 词汇障碍 / 句子结构障碍 / 翻译依赖 / 待确认
- 阅读方式：逐句翻译 / 意群理解 / 分层阅读
- 主旨草图：对象 + 重点
- 段落位置或功能：
- 题型：
- 定位词：
- 证据范围：短语 / 句子 / 前后句 / 段落 / 全文
- 原文证据的意思：
- 答案依据：
- 干扰项问题：
- 高中扩展断点：无 / 改写范围 / 立场 / 因果 / 研究或议论结构 / 跨段证据 / 目的作用
- 下一步：补主旨 / 补定位 / 补当前题型 / 补一个高中扩展动作 / 回到新阅读
```

按需要使用，不为填满格式重复内容。

## 结束与更新

本轮独立验证通过后，将当前问题转入强化并明确下一份真实材料要检查什么。先向 `题型/<学段>/英语/阅读理解/学习记录.md` 追加学习内容、实际结果与证据；状态确有变化时更新 `题型/<学段>/英语/阅读理解/学习进度.md` 的当前任务、问题及能力，并引用 E 编号，其他能力保持原判断。迁移与间隔复测支持稳定后才记已巩固。学生明确停止时保存接续点；写后回读确认，再简短告知。

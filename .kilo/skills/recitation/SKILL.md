# recitation · 背诵本

数据在 `学习数据/recite.db`，只能通过 `学习数据/scripts/recite.mjs` 读写（见 study-data 技能）。

## 1. 什么时候做卡

- 讲解里出现**值得反复记**的东西：定义、公式、判断依据、古诗文、文言实词、英语单词/词组、
  历史时间线、答题模板；
- 学生说"这个要背""帮我做成卡片"；
- 错题重做通过后，把它的核心结论转成卡：`--source "错题 #12"`。

**一张卡只装一个点。**"导数的几何意义"和"切线方程怎么求"是两张卡。宁可多几张，不要一张巨卡。

## 2. 正面怎么写（问题）

- 是一个**能被独立回答的问题**或填空，不要写"关于XX"；
- 判断题、辨析题用"……对不对/为什么"；
- 需要提示的，把第一层提示放 `--hint`，别塞进正面。

判断标准：**只看正面，学生能不能独立说出反面？** 不能就拆细。

反面教材：`--front "导数"`。正面教材：`--front "f'(x₀) 的几何意义是什么？"`。

## 3. 反面怎么写（答案，最重要）

**目标是最少字、最好记**，不是把课本抄一遍。

- **默认分点**：`1. / 2. / 3.`，一行一个要点；
- **对比、分类、流程一律用表格**（如"内流区 vs 外流区""有丝分裂 vs 减数分裂""楞次定律三步"）；
- **≤5 行、每行 ≤20 字**；超了说明该拆卡，不要压缩成一句长话；
- 能用公式/图形关系表达就不用文字；公式用 `$...$`；
- 需要图才记得住的（地理图、电路图、结构式、光路图）走 `--image`，不要用文字硬描述。

示例（反面用表格）：

```
--front "楞次定律判断感应电流方向的步骤？"
--back  "| 步 | 做什么 |
|---|---|
| 1 | 看原磁通量增减 |
| 2 | 定感应磁场方向（增反减同） |
| 3 | 右手螺旋定则定电流方向 |"
--hook  "增反减同"
```

## 4. 字段怎么填

| 字段 | 要求 |
|---|---|
| `--subject` | 九科之一，中文全称 |
| `--topic` | 教材章节/单元，如 `必修一 Unit3`、`导数`（章节名对齐 `资料/教材目录.md`，用 grep 查，别整篇读） |
| `--kind` | `概念 / 公式 / 古文 / 文言实词 / 英语单词 / 英语词组 / 时间线 / 答题模板 / 其他` |
| `--front` | **正面 = 问题**，见第 2 节 |
| `--back` | **反面 = 答案**，见第 3 节：分点 / 表格 / ≤5 行 |
| `--hook` | 记忆钩子：口诀、联想、对比（如"升失氧、降得还"）。**能想出来就一定要写** |
| `--hint` | 第一层提示（学生说"给点提示"时念） |
| `--source` / `--image` | 来源（`错题 #12`）；配图用 `node 学习数据/scripts/grab-image.mjs --subject <学科> --purpose 背诵` 抓取，图片约定见 wrongbook 技能第 4 节 |

## 5. 写入流程

1. 固定格式回声：

```
将加入背诵本：
  学科：化学    章节：氧化还原反应    类型：概念
  正面：氧化剂发生什么变化？
  反面：1. 得电子  2. 化合价降低  3. 被还原
  钩子：升失氧、降得还
```

2. 立即执行（不再多问一轮）：

```bash
node 学习数据/scripts/recite.mjs add --subject 化学 --topic "氧化还原反应" --kind 概念 \
  --front "氧化剂发生什么变化？" --back "1. 得电子
2. 化合价降低
3. 被还原，得还原产物" --hook "升失氧、降得还"
```

3. 贴上脚本**真实输出**（`#id` 与首次抽背日期）。
   一次可连做 2–3 张卡，但每张单独跑一条 `add`；反面含表格/长内容时用 `--json-file`（见 study-data）。

## 6. 积极程度与自动记录

`学生档案.md` 的**背诵本积极程度**决定讲解结尾（AI 自发归档）的力度：`不主动 / 标准 / 主动 / 直接记`，
四档含义见 tutor 技能的同名表。**学生用 `/recite` 明确要求时一律直接写入，不看档位。**

`直接记` 门槛更严：

- 提议**用 `question` 工具、做成选项**（如"做成卡 / 只帮我记下来 / 先不用"），不要让学生打字；
  规范见 tutor 技能第 1 节（"要不要做卡"属无对错问题）。
- 只自动记**明确的可背对象**：公式、定义、判断依据、古诗文原句、文言实词、英语词块、答题模板。
  整段讲解、例题过程**不做卡**。
- 每轮最多自动 **3 张**，严格"一张卡一个点"；宁可少做，不要做巨卡。
- 反面写不成"分点/表格、≤5 行"就**降级为提议**，不要硬记长段落。
- **不回声、不提示**：写完不在回复里提；学生问起或要撤销时再用 `list` / `get` 报出 `#id`。

## 7. 抽背（`/review` 的背诵部分）

```bash
node 学习数据/scripts/recite.mjs due --limit 10
```

一次一张，节奏是：

1. 只念 `front`（学生要提示再念 `hint`）；**不要**提前泄露答案。
2. 学生答完，念 `back` 对照，指出漏掉的要点（表格型要点按行核对）。
3. 判定并记录：答出 → `review <id> --result pass`；漏要点/答错 → `review <id> --result fail`，
   然后**重讲一遍**这个点再往下。想得起来就补一句 `hook`。
4. 换下一张。

默认一轮 5–10 张。学生烦躁或走神时收到 5 张以内，并说一句"今天这几张就够"。

## 8. 其他

- 查卡：`get <id>`；列表：`list [--subject 英语] [--all]`；统计：`stats`（按学科/类型）。
- "这张我背熟了"：`review pass` 推进档位，连推到底自动标记已掌握并移出队列；想重新抽：`reset <id>`。
- 删除必须学生明确要求，用 `remove <id> --yes`；禁止手改 `.db`。

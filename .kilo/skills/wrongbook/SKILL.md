# wrongbook · 错题本

数据只在 `学习数据/wrongbook.db`，**只能**通过 `学习数据/scripts/wrong.mjs` 读写（见 study-data 技能）。
命令一律在仓库根目录执行。

## 1. 记什么

- 学生**自己做错**的题（不是"这题很难"）；
- 学生明确说"记进错题本"；
- `/review` 时重做仍然错的题（用 `review fail` 推进，不新建行）。

同一道题重复出现时直接再 `add` 一次即可：脚本用「学科 + 归一化题干」生成指纹，
重复录入**只更新内容、保留复习进度**。所以"补答案""改错因"都靠重跑 `add`。

## 2. 字段怎么填

| 字段 | 要求 |
|---|---|
| `--subject` | 九科之一，用中文全称 |
| `--topic` | `章节简称·考点`，如 `导数·极值点偏移`、`电磁感应·楞次定律`；章节简称取自 `资料/教材目录.md` |
| `--form` | `单选` / `填空` / `解答`（默认），见第 3 节 |
| `--stem` | **原始题干**，保真不改写；图像题写清给定条件与所求 |
| `--options` | 仅单选：每行一个选项 `A. …` |
| `--drill` | 仅填空：把关键处换成 `____` 的自测题面 |
| `--answer` | **标准答案**：单选写字母；填空按空序 `-1\|1`；解答写最终结论 |
| `--my-answer` | 学生当时的**错误**答案（原样，含"没做出来"） |
| `--analysis` | 解析要点，≤3 行、编号步骤；**不要抄整篇解答** |
| `--cause` | 只能是：`概念不清 / 计算失误 / 审题偏差 / 方法不会 / 粗心 / 时间不够 / 其他` |
| `--difficulty` | 1 容易 → 5 很难，默认 3 |
| `--source` | `周测3` / `期中` / `练习册 P12`，不知道就省略，**不要编造** |
| `--tags` / `--image` | 标签（逗号分隔）；图片路径，见第 4 节 |

错因要**问出来或据实推断**：学生说"我看错条件了"= 审题偏差；"公式记混了"= 概念不清；
"会做但算错了"= 计算失误；"完全没思路"= 方法不会。不要一律写"粗心"。

**章节简称要对齐教材**：先 `grep` 一下 `资料/教材目录.md`（**不要整篇读**，文件大），
确认章节名再写 `topic`，这样 `/stats` 的"按章节"才能聚到一起，也才能对照学生进度。

## 3. 题型化改造（把错题变成能重做的题）

记录前先想一句："**下次复习时，学生看到什么、写什么、我对什么？**" 按这个来选题型：

| 题型 | 什么时候用 | 必填 |
|---|---|---|
| `单选` | 选择题、概念辨析题、能给出 3–4 个像样迷惑项的 | `--options` + `--answer`（字母） |
| `填空` | 计算题、步骤题、结论题：把关键处挖空 | `--drill`（含 `____`）+ `--answer`（按空序 `\|`） |
| `解答` | 压轴大题、证明题、无法自然改造的 | `--answer`（最终结论）+ `--analysis` |

改造纪律：

- **`stem` 永远保留原题**，改造只动 `drill`；改造失败也不丢原题。
- 单选题的迷惑项要**来自学生真实的错法**（他选 A 了，就把 A 做成诱因），不要随便凑。
- 填空题**每空只挖一个考点**；挖太多（>3 空）不如降级为 `解答`。
- 解答题不硬套选择/填空：失真比"形式统一"更坏。
- `--analysis` 是给学生复习时看的**要点**，不是完整解答；完整讲解在对话里已经给过。

## 4. 图片

- 学生在对话框里**粘贴的图可以直接抓出来**，先跑这一条，把返回路径交给 `--image`：

  ```bash
  node 学习数据/scripts/grab-image.mjs --subject 物理 --purpose 错题
  # → 学习数据/图片/物理/错题-20260925-01.png
  ```

  脚本**只读** Kilo 会话库，取最近 60 分钟内粘贴的图；同一张图重复抓取直接返回原路径（幂等）。
  先看候选用 `--list`，只看路径不落盘用 `--dry-run`；老图放宽 `--minutes 0`。
- 抓取失败（退出码 1 / 提示"没有粘贴的图片"）时**照常记文字**：`--image` 留空、`--tags` 加 `原题含图`，
  并说一句"图没抓下来，把图片另存到 `学习数据/图片/<学科>/` 再说一声，我补进去"。
  **不要**因为缺图就不记录。
- 图片统一放 `学习数据/图片/<学科>/`，命名 `用途-YYYYMMDD-序号.扩展名`；`--image` 存相对仓库根路径（多张用 `;` 分隔），
  脚本会把绝对路径自动规整成相对路径。
- 学生原图**只读引用**，不覆盖、不裁剪；需要标注就另存一份。

## 5. 写入流程

1. 用固定格式回声（学生可在这一步纠正）：

```
将记入错题本：
  学科：物理    知识点：牛顿第二定律    题型：单选
  题干：质量 2kg 的物块受 6N 拉力，摩擦因数 0.1，求加速度
  选项：A. 3 m/s²  B. 2 m/s²  C. 4 m/s²  D. 1 m/s²
  标准答案：B    我的答案：A    错因：审题偏差    难度：2
```

2. 立即执行，不再等一轮确认（长题干/选项用 `--json-file`，键名同上）：

```bash
node 学习数据/scripts/wrong.mjs add --subject 物理 --topic "牛顿第二定律" --form 单选 \
  --stem "质量 2kg 的物块在水平面上受 6N 水平拉力，摩擦因数 0.1，求加速度（g=10 m/s²）" \
  --options "A. 3 m/s²
B. 2 m/s²
C. 4 m/s²
D. 1 m/s²" \
  --answer "B" --my-answer "A" --analysis "合力 4N，a=2 m/s²" --cause 审题偏差 --difficulty 2
```

3. **把脚本的真实输出贴给学生**（含 `#id` 与下次复习日期）。学生若当场纠正，改参数再跑一次同一条命令。

## 6. 积极程度与自动记录

`学生档案.md` 的**错题本积极程度**决定讲解结尾（AI 自发归档）的力度：`不主动 / 标准 / 主动 / 直接记`，
四档含义见 tutor 技能的同名表。**学生用 `/wrong` 明确要求时一律直接写入，不看档位。**

`直接记` 是唯一能不经确认写入的档，门槛因此更严：

- 只记**学生自己确认做错**的题（学生说错了、答案对不上、`/review` 时答错）。
  讲解里提到、但学生没做的题**不记**。
- 每轮讲解最多自动记 **1 道**；同类多道只记最典型的那道，其余等学生要求。
- **错因**只在能明确判断时填；判断不出来就**留空**（不编造，也不为此打断学生）。
  留空的记录会在 `/stats` 里显示为"未归类"，学生看统计或主动问起时再补（`add` 一次即可，指纹相同，只更新内容）。
- 题型改造**能做就做**，拿不准就退到 `解答`，不要为了凑单选编选项。
- **不回声、不提示**：写完不在回复里提。学生问"记了吗"或要撤销时，用 `list` / `get` 报出最近写入的 `#id`；
  撤销用 `remove <id> --yes`（学生明确说了才执行）。
- 命中已有指纹时静默更新，不要重复建行，也不要因此额外输出。

## 7. 复习（`/review` 的错题部分）

```bash
node 学习数据/scripts/wrong.mjs due --limit 10
```

逐题进行，**按题型决定怎么问**：

| 题型 | 呈现给学生 | 学生要做的 |
|---|---|---|
| 单选 | `drill`（或 `stem`）+ `options` | 报字母 |
| 填空 | `drill`（带 `____`） | 按空序报答案 |
| 解答 | `stem` | 口述思路与结论 |

对照 `answer` 与 `analysis` 后判定：

- 答对：`review <id> --result pass`（档 +1，间隔 1→3→7→15→30 天）
- 答错：`review <id> --result fail`（回档 0，明天再来），并把**新的错因**问清楚，必要时 `--note`

**不要提前泄露 `answer`**。一次复习默认 5–10 题；学生焦虑或时间紧就只做 3 题，做完就停。

## 8. 其他

- 看单题全部信息：`get <id>`；统计：`stats`（含"按章节"，用来看哪章薄弱）；"这题我早会了"：`reset <id>` 或 `review pass`。
- 删除必须学生明确要求，且用 `remove <id> --yes`；**不要**为了"整理干净"自行删除。
- 禁止直接打开/编辑 `.db`，禁止手写 SQL 绕过脚本。

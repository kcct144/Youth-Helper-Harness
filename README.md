# 高中学习助手

给高中生用的 AI 学习工作区：会讲题、讲知识，讲完顺手把该记的记进错题本、背诵卡和笔记——
作业多、没时间整理，这部分交给它。

## 三步开始

1. 安装 [VS Code](https://code.visualstudio.com/) 和 Kilo 插件（在 VS Code 扩展面板搜索 `Kilo`）
2. 克隆本仓库：`git clone <仓库地址>`
3. 用 VS Code 打开这个文件夹，按 `Ctrl + Alt + I` 打开聊天，说一句"你好"

第一次打开时，它会用一屏把能做的事讲一遍。

## 它能做什么

- 讲题、讲知识点：不超纲，给结论、步骤和易错点
- 顺手记错题、做背诵卡、整理笔记，不用自己动手归档
- 到点提醒复习：说一句"复习"，它抽今天该过的错题和背诵卡

最常用的三条：`/review` 复习、`/wrong` 记错题、`/note` 整理笔记。

## 数据都在你自己电脑上

| 内容 | 位置 |
|---|---|
| 错题本、背诵本 | `学习数据/` |
| 笔记 | `笔记本/<学科>/<专题>/` |
| 题目图片 | `学习数据/图片/<学科>/` |

全部存在本机，不上传。

## 想换风格

改 `学生档案.md`（讲多细、问多少、要不要主动记），或直接跟它说"以后都讲详细点"。

## 升级

以后说一句"升级"，它会把最新的技能和脚本同步进来，你的错题、笔记、图片都不动。

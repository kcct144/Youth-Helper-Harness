# 中学学习助手

给中学生（初中 / 高中）用的 AI 学习工作区：会讲题、讲知识，讲完顺手把该记的记进错题本、背诵卡和笔记——
作业多、没时间整理，这部分交给它。

## 三步开始

1. 安装 [VS Code](https://code.visualstudio.com/) 和 Kilo 插件（在 VS Code 扩展面板搜索 `Kilo`）
2. 克隆本仓库：`git clone https://github.com/kcct144/Youth-Helper-Harness.git`
3. 用 VS Code 打开这个文件夹，按 `Ctrl + Alt + I` 打开聊天，说一句"你好"

第一次打开时，它会用一屏把能做的事讲一遍。

## 它能做什么

- 讲题、讲知识点：不超纲，给结论、步骤和易错点
- 顺手记错题、做背诵卡、整理笔记，不用自己动手归档
- 到点提醒复习：说一句"复习"，它抽今天该过的错题和背诵卡

**不用记任何命令，直接说话就行**：题目不会做就把题发我（拍照也行）；说"我错了"我就记进错题本；
说"整理一下"我就写成笔记；说"复习"我就抽今天该过的。

## 复习

双击 `复习/开始复习.cmd`，浏览器会打开今天的复习页：错题按题型出、背诵卡翻面，
点一下"会 / 不会"就算过了一遍。**没过的明天还会来。**

只有想让人讲讲的时候，才回对话里说一句"讲讲刚才没过的"。

## 数据都在你自己电脑上

| 内容 | 位置 |
|---|---|
| 错题本、背诵本 | `学习数据/` |
| 笔记 | `笔记本/<学科>/<专题>/` |
| 题目图片 | `学习数据/图片/<学科>/` |

全部存在本机，不上传。

## 想换风格

改 `学生档案.md`（讲多细、问多少、要不要主动记），或直接跟它说"以后都讲详细点"。

## 升级

以后说一句"升级"，它会把最新的技能和脚本同步进来，你的错题、笔记、图片都不动。

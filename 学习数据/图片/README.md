# 图片附件目录

错题、背诵卡里用到的图片都放这里，按学科分子文件夹：

```
学习数据/图片/数学/错题-20260925-01.png
学习数据/图片/物理/背诵-20260925-02.jpg
```

- **命名**：`用途-日期-序号.扩展名`，日期用 `YYYYMMDD`，序号两位。
- **数据库里存相对仓库根的路径**（正斜杠），如 `学习数据/图片/数学/错题-20260925-01.png`；
  一道题/一张卡有多张图用 `;` 分隔。
- **AI 不会修改你的原图**，只读引用；需要标注时直接在图上另存一份，不要覆盖原文件。
- 笔记正文里引用图片时，用**相对该笔记文件**的路径（如 `../../../学习数据/图片/数学/xxx.png`）。

## 粘贴到对话框的图，AI 不一定拿得到文件

AI 能拿到文件路径时，会自动复制/引用到本目录；拿不到时它只记文字、把 `tags` 标成 `原题含图`。
这时把图另存到本目录，再说一句"图存好了，文件名是 xxx"，AI 会补进错题本。

本目录内容不进版本库（`.gitignore` 只放行本说明文件）。

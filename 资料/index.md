# 资料库 · 给 AI 的知识库

`资料/` 是 AI 讲解时的**口径来源**：同一个考点，前后讲法要一致。它不是日记，也不放学生数据。

## 结构（**学段是第一层**）

```
资料/index.md                       本文件：结构、条目格式、来源纪律
资料/<学段>/<学科>/index.md          该科索引：有哪些章节文件（新增一章登记一行）
资料/<学段>/<学科>/教材目录.md       章节骨架（人教版）：查章节名用 grep，别整篇读
资料/<学段>/<学科>/<章节>.md         知识库：一章一个文件
资料/<学段>/<学科>/原始/             老师给的讲义/梳理：**权威，AI 只读不改**
资料/通用/index.md                   跨学段：答题模板、时间分配、学习方法
```

> **题型不在这个体系里**：题型（七选五、完形填空、语法填空…）是**考试维度**，与教材章节正交
> ——一个题型跨多个章节，所以它有独立的顶层目录：题型工作区在 `题型/<学段>/<学科>/<题型>/`，
> 题源在 `题库/`（一题一 md，带 id/考点/台阶/状态）。

- **学段必须分开**（`资料/高中/…` 与 `资料/初中/…`）。两个学段的超纲线、章节体系、考试口径都不一样，
  不要写进同一个文件。学段从 `学生档案.md` 的「年级/进度」取；**学段不明就先问一句**。
- **一章一个文件**是为了按需只读一小块：讲"导数"只读 `资料/高中/数学/导数.md`，不要把整科读进来。
  单章 ≤200 行，超了按小节再拆。
- 章节文件**按需创建**（第一次讲那章才建），不预建空文件；`初中/` 目录等有初中学生时再按同样结构建。

## 格式：默认 markdown，表格式数据用 CSV

- **默认 markdown**：一章一个 `.md`，按下面的条目格式写。人读得懂、grep 方便、git 能看 diff。
- **表格式数据用 CSV**：章节清单、考点对照表、题型分布、词汇表这类"一行一条、字段固定"的，
  直接存 `<用途>.csv`（UTF-8、首行表头、一个文件一张表），比 markdown 表格好处理。
  例：`资料/高中/英语/词汇表.csv`，表头 `单词,词性,释义,单元`。
- 不确定就用 markdown——CSV 只在"确实是一张表"时才用。

## 一条条目怎么写

```markdown
### 导数·单调性判断
- 结论：f'(x) > 0 的区间上递增；f'(x) < 0 的区间上递减。
- 流程与判据：定义域 → 求 f' → 解 f'=0 → 列表判号。看到「含参」先分类讨论；
  符号不能直接定时，改看二阶导或用特殊值验证。
- 适用条件：区间内可导；单调区间写开区间。
- 易错：忘定义域；f'(x)=0 不必然改变单调性。
- 来源：讲解整理 2026-09-26（未核实）
```

字段固定这五个：**结论 / 流程与判据 / 适用条件 / 易错 / 来源**。一条 ≤6 行，宁可短。

## 来源纪律（最重要的一条）

**AI 写错一条、下次讲解又引用它，就会越错越稳。** 所以：

1. 每条**必须标来源**，来源只有三类：
   - `教材` / `老师讲义《文件名》` → **权威**：AI 只读不改，冲突时以它为准
   - `讲解整理 YYYY-MM-DD` → **未核实**：可补充，也可能被权威来源覆盖
2. **AI 不得覆盖或改写权威条目**，只能追加，或提一句"这里和你给的讲义不一致"。
3. 讲解后 AI 沉淀：一次最多 **3–5 行**，不抄整段讲解。
4. **学生个人化的东西不进这里**——"他错了两次"是错题本与缺口的事。
5. 不编造教材页码、真题年份、命题单位；不确定的出处就写"讲解整理"。

## 老师给资料时（不定期）

原件存进 `资料/<学段>/<学科>/原始/`，再按章节提炼进知识库，来源写 `老师讲义《…》`（权威）。
完整流程见 `.kilo/skills/knowledge-base/SKILL.md`——**提炼完要报告改了哪些条目**，不静默覆盖。

## 体检

老师说一句"看看资料库"，AI 就列出**所有未核实条目**（来源是"讲解整理"的）供过目；
核实后把来源改成 `教材` 或 `老师讲义《…》`。

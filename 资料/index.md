# 资料库 · 索引与沉淀规范

`资料/` 是**只读参考**：教材知识点的浓缩版、公式、答题模板。它不是日记，也不放过程记录。

## 结构

```
资料/index.md            本文件：总索引 + 沉淀规范
资料/<学科>/index.md     该科知识点索引，AI 维护
资料/通用/               答题模板、考试技巧、学习方法
```

## 使用（AI 讲解前）

1. 先读 `资料/<学科>/index.md`，看有没有对应条目。
2. 有 → 沿用条目里的讲法、符号、结论口径，保证前后一致。
3. 没有 → 正常讲解；讲完把这次的**结论 / 关键步骤 / 易错点**浓缩成 3–8 行，
   追加到该科 `index.md` 的新条目，并在条目里写明「适用条件」。

## 沉淀格式（追加到 `资料/<学科>/index.md`）

```markdown
### 导数·单调性判断
- 结论：f'(x) > 0 的区间上 f(x) 递增；f'(x) < 0 的区间上递减。
- 适用条件：区间内可导；单调区间写成开区间。
- 步骤：定义域 → 求 f' → 解 f'=0 → 列表判号 → 写区间。
- 易错：先看定义域；临界点处 f'=0 不必然改变单调性。
- 来源：2026-09-25 讲解整理（非教材原文）
```

## 纪律

- 不编造教材页码、真题年份、命题单位；不确定的出处就写"讲解整理"。
- 一课一沉淀，宁可条目短，不要抄长文；学生看不完的资料等于没有。
- 学生明确说"这块我懂了"再考虑精简，不要删别人（别的学科）的条目。

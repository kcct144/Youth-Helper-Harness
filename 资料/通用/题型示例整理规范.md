# 题型示例整理约定

## 通用原则

- 一篇独立文章保存为一个 Markdown 文件，不把多篇文章和不同作答形式混排在同一正文中。
- 文件名写明来源、题型和篇次，例如 `广东中考-阅读理解-A篇.md`。
- 文章或完整材料放在小题之前，方便学生阅读，也方便 AI 建立主旨和定位证据。
- 每个独立题型文件的小题从 1 开始连续编号；原卷总题号不带入拆分后的文件。
- 没有可靠答案和解析时不建立占位段落，也不要用 AI 推断冒充官方答案。
- 原材料缺图、缺表格或版式不确定时，在对应题干中明确标注资料缺口。

## 常规四选一阅读模板

```markdown
# 题干

在这里填写一篇完整阅读文章。

# 小题

1. <问题>

- A: <选项 A>
- B: <选项 B>
- C: <选项 C>
- D: <选项 D>
```

## 配对阅读模板

配对阅读的多个小题共用一个选项池，不在每道小题下重复七个选项。

```markdown
# 题干

<作答说明>

# 选项池

- A: <共享选项 A>
- B: <共享选项 B>

# 小题

1. <待匹配的信息>
```

配对阅读单独建立题型示例；在形成稳定、可复用的教学流程前，不自动新建专项 Skill。

## 七选五模板

七选五是独立题型，不归入常规四选一阅读。完整短文中的多个空共享一个句子选项池；选项统一列出，不在每个空后重复。

```markdown
# 题干

<作答说明：空格数、共享选项数和多余项数>

<包含多个空格的一篇完整短文>

# 选项池

- A: <候选句 A>
- B: <候选句 B>
```

没有可靠答案和解析时只保存题目，不根据上下文自行补写“官方答案”。

# 题型工作区

各题型内的资料是正式维护源，不再另设一套资料库。复制一个可用题型目录即可携带规则、主技能、学情模板和必要资料；不依赖兄弟目录。

| 题型 | 入口 | 当前范围 |
| --- | --- | --- |
| 语法选择 | [工作区](语法选择/AGENTS.md) | 初中；核心及低频考点，按已暴露问题启用 |
| 语法填空 | [工作区](语法填空/AGENTS.md) | 五步试行框架；学情分基础知识、句子分析和考点识别；高中考点内分层求解待完善 |
| 完形填空 | [工作区](完形填空/AGENTS.md) | 初高中；词汇门槛、篇章意识和线索 |
| 阅读理解 | [工作区](阅读理解/AGENTS.md) | 初高中独立设问，不含共享句子选项池 |
| 选词填空 | [工作区](选词填空/AGENTS.md) | 有词框；双向模式、词形与语境 |
| 七选五 | [工作区](七选五/AGENTS.md) | 共享句子池任务；效率策略仍按候选边界处理 |
| 作文 | [工作区](作文/AGENTS.md) | 初中模板写作；高中原题仅保留为参考材料 |
| 配对阅读 | [资料区](配对阅读/README.md) | 仅保留原题，未建专门教学技能与进度模板 |

题型内结构：`AGENTS.md`、`.kilo/skills/<主技能>/SKILL.md`、`学习进度.md`、`学习记录.md`、`资料/`、`练习/`。

资料中的题型示例保留原文和来源完整度，不等于已经校验的预设题；无答案不得猜作官方答案。读写综合中的回答问题不纳入练习范围。

语法填空将能力明细放在 `学情/` 的三份文件中，学习进度只保留当前任务和入口；其他题型仍沿用自身记录结构，不因此批量拆分。

# 初中英语 · 题型工作区

> 按**考纲题型**分目录，题型归属以本学段考纲为准（同名题型初高中各一份，内容可各自演化）。

每个题型一个工作区：`资料/`（考点地图、做题流程、学习路径）、`练习/`、`AGENTS.md`（该题型的教学决策）、
`学习进度.md` 与 `学习记录.md`（学生侧唯一可写）。

## 本题型清单

| 题型 | 状态 |
|---|---|
| 语法选择 | ✓ 已建 |
| 完形填空 | ✓ 已建 |
| 阅读理解 | ✓ 已建 |
| 配对阅读 | ⚠️ 只有资料，**未建教学流程**（走通用教练的降级规则） |
| 选词填空 | ✓ 已建 |
| 回答问题 | ✗ **未建**（等资料与教学决策；AI 按降级规则处理） |
| 作文 | ✓ 已建 |

用法：加载 `.kilo/skills/question-type-coach`（通用教练），它会读对应题型的 `AGENTS.md`。
题源在 `题库/`（跨题型共享，只有 `状态: 已校验` 的题可用）。

## 资料状态（重要）

`完形填空` / `阅读理解` / `作文` 三份是**从高中版复制**的：

- 已删掉明确高中向的文件（高考示例、高中扩展）；
- 其余资料（考点地图、做题流程、学习路径）**可能仍有高中口径**，文件开头已加警示，**待按初中考纲校订后再当权威用**；
- `AGENTS.md` 的教学决策本身是针对初高中共写的，可直接用。

初中专属的三份（语法选择、配对阅读、选词填空）是从原工作区直接移过来的，不受此影响。

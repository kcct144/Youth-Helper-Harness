# 高中完形填空扩展层

- 适用学段：高中
- 内容类型：题型方法 / 按需补漏
- 前置资料：`考点地图.md`、`做题流程.md`、`篇章意识.md`
- 核心定位：在基础流程仍不能区分选项时，增加最少的词义、篇章逻辑或句法处理
- 默认边界：不进入初中完形的必学主线，也不因学生升入高中而整套预教

本扩展不是另一套完形流程。高中生仍先执行“词汇门槛 → 篇章草图 → 局部代入与排除 → 扩大上下文 → 全文验证”。只有报告或真实题目证明基础流程走完后仍有明确断点，才调用本文件中的一个增量。

## 启用条件

同时满足以下条件才启用：

1. 当前是高中完形材料，或可靠题目确实出现了本文件所列的高中增量；
2. 正文主线基本可理解，大多数题的四个选项只有 0～1 个生词；
3. 学生已经尝试基础流程，卡点不是“没有代入”“没有找上下文”或“没有完整读过”；
4. 能把断点说成下面三类之一，而不是笼统地说“高中题更难”。

| 学生表现 | 首选路由 | 先问的一句话 |
| --- | --- | --- |
| 四个词大致认识，最后两个意思接近，仍无法区分 | 增量一：语境义与近义精辨 | “这两个词共同点是什么，在当前语境中差在哪一维？” |
| 局部代入都通顺，但前后态度、转折或事件发展只能支持一个 | 增量二：句子与篇章逻辑 | “空格前后两层意思是什么关系，谁在什么时间持什么态度？” |
| 线索就在句中，但学生找不到主干、指代或从句关系 | 增量三：关键长句最小句法补漏 | “先不选词，这句话最核心的‘谁做什么’是什么？” |
| 多数选项不认识，或正文主线无法概括 | 暂不启用高中扩展 | 回到词汇补漏或更换材料 |
| 只是忘记执行代入、找线索或全文复查 | 暂不启用高中扩展 | 回到基础做题流程的第一个断点 |

三个增量不是三章必修内容。一次只走一个首选路由；长句结构若挡住词义或逻辑判断，只把增量三当作临时补丁，拆清后立刻回到增量一或二。

同时出现多个增量信号时，不并行教学：先处理阻断证据理解的关键长句；否则处理学生作答时最早出现、可能引发连错的断点；若彼此独立，则选择原题和学生思路最完整、范围最窄的一处。其余信号保留为待核验，不因“已经看见”就顺带展开。

## 最短总流程

```text
先走基础完形流程
→ 仍剩两个或更多合理选项
→ 判断断点：词义精辨 / 篇章逻辑 / 长句结构
→ 只调用对应的最短步骤
→ 写出“候选差异 + 文本证据 + 排除理由”
→ 放回段落和全文验证
→ 仍无可靠证据就标记 ?，不把猜测包装成结论
```

建议学生使用一张最小证据卡：

```text
当前断点：
最后两个候选：
决定性差异或逻辑关系：
文本证据：
排除理由：
全文验证：通过 / 待核验
```

## 增量一：语境义与近义精辨

### 学习目标

学生不只会说出选项的常见中文义，还能比较最后两个候选在当前语境中的具体差异，并用一句文本证据作决定。

### 触发信号

- 四个选项基本认识，局部搭配也不明显错误，但最后两个词义接近；
- 按最常见中文义代入不合适，词在文中表达抽象义、引申义或比喻义；
- 选项是短语动词，逐词翻译后都“差不多”；
- `only / still / even / indeed` 等词改变句子的焦点、预期或语气，不能只靠一个中文标签选择；
- 学生只能说“这个更顺”，说不出另一个究竟错在哪一维。

### 最短流程

1. **先缩到最后两个候选。**明显不合词性、搭配、人物或情节的选项仍按基础流程排除。
2. **说共同点。**先确认两个词为什么都像答案，避免用两个模糊中文义互相替换。
3. **只找一个决定性差异。**从对象、方向、程度、态度、时间状态、范围或搭配框架中选最相关的一维。
4. **把空格改写成中文约束。**例如“这里需要的是对某事的重视”“这里需要的是离开以后才产生的认识”，不先写某个选项。
5. **逐个核对约束。**能满足共同义但不满足决定性约束的候选被排除。
6. **回句、回段验证。**检查选择是否与叙述者、时间和全文态度一致。

### 常用精辨维度

| 维度 | 要问的问题 | 不能停留在 |
| --- | --- | --- |
| 对象 | 这个词通常作用于人、事、观点、机会还是关系？ | 两个词中文都译成“看重” |
| 动作方向 | 是获得、保持、离开、依靠，还是促使另一件事发生？ | 都表示“做某事” |
| 主动性与意图 | 是主动选择、被动经历，还是事后形成的认识？ | 都与事件有关 |
| 程度与语气 | 是一般事实、强化确认、出乎预期，还是持续未变？ | 都能译成“甚至/仍然/确实” |
| 时间状态 | 描述过去状态、现在变化，还是跨时间保持？ | 时态形式相同就算相同 |
| 评价色彩 | 对同一个对象是赞赏、抱怨、担忧还是中性描述？ | 只分“褒义/贬义” |
| 搭配框架 | 后面接什么对象、介词或补足结构？整块短语表达什么？ | 把短语动词逐词相加 |
| 语篇角色 | 这个抽象名词是在命名一次发现、一种关系、一种生活方式还是一种经历？ | 只背词典第一义 |

#### 抽象义、引申义和比喻义

先问“这个词在文章里具体指什么人、事或关系”，再比较选项。例如 `small town roots` 在本文中不是植物根，而是成长背景及其形成的归属和价值影响。这里只需要把比喻还原成当前文章中的具体作用，不展开整套修辞知识。

#### 短语动词

把短语作为一个意义单位处理：

```text
主语是谁
→ 短语作用于什么对象
→ 动作朝什么方向发展
→ 放回人物目标和时间线
```

不要因认识其中的动词就推断整组含义，也不要一次补齐该动词的全部短语搭配。本题只比较实际出现的候选。

#### `only / still / even / indeed` 等焦点词

1. 先去掉焦点词，写出句子的基本事实；
2. 再问作者要表达“范围受限”“状态延续”“超出预期”还是“确认加强”；
3. 指出它重点影响句中的哪一部分；
4. 用前后句提供的预期或对比验证。

不能见到固定中文翻译就直接选择。同一个词放在数量、距离、时间或态度前，实际强调重点可能不同。

### 教学提示与完成证据

教练一次只追问最后两个候选：

- “它们为什么都像答案？”
- “如果只准说一个差别，你选哪一维？”
- “文中哪个词或事实需要这个差别？”
- “另一个候选违反了哪条约束？”

学生能在 按证据需要安排的同类新空中独立说出“共同点—决定性差异—文本约束—排除理由”，即完成本轮补漏。只报中文释义、只说搭配顺或在提示后才能指出差异，仍属于需提示。

## 增量二：句子与篇章逻辑、态度变化

### 学习目标

学生能区分不同人物、不同时间层和不同态度对象，并用句间或跨段关系解决局部都成立的选项。

### 触发信号

- 空格所在短语或单句中两个选项都能成立，决定性证据在前后句、前一段或结尾；
- 文中出现 `though / sure / however / actually / as`、分号、直接引语等转折或视角信号；
- 叙述者从过去到现在改变看法，学生却把早期抱怨当成最终态度；
- 他人引语、叙述者旧观点和叙述者当前观点混在一起；
- 相邻多空连续受同一次态度转变、因果链或跨段照应影响；
- 学生只用“正面/负面”判断，无法说清“谁对什么，在什么时候怎样看”。

### 最短流程

1. **定视角。**标出这句话是谁说、谁想或谁在评价。
2. **定时间。**区分过去经历、后来反思和现在结论。
3. **写两层意思。**分别用短语概括连接词、分号或段落前后的内容。
4. **命名关系。**只在并列、递进、因果、条件、让步后转折、解释、指代照应中选择当前需要的一种。
5. **找锚点。**圈出能证明该关系的原文事实、重复概念、态度词或结果。
6. **比较候选。**选择能完成这条关系的候选，排除只在局部通顺却破坏时间线或态度线的候选。
7. **更新篇章草图。**把新确认的变化接回“人物—事件—态度/结果”主线。

可用下面的态度记录代替笼统褒贬：

```text
人物/声音：
时间阶段：
态度对象：
具体态度：
变化信号：
```

例如一篇文章可以同时包含“同学对某地的误解”“叙述者过去对家乡无聊的抱怨”和“叙述者现在对成长经历的珍视”。三者不能合并成一个“作者态度”。

### 三种高中常见增量

#### 1. 让步—转折

`Though ...`、`Sure, ...; ...` 等结构常先承认一个事实，再把重心转向作者真正要推进的判断。学生要分别写出“承认什么”和“重点转向什么”，不能看到一个转折词就机械选择另一个转折词。

#### 2. 态度随时间变化

先画最短时间线：

```text
过去怎么看 → 什么经历触发变化 → 现在怎么看
```

如果选项只能符合过去情绪，却与当前反思和结尾不一致，就不能只凭空格附近的一句话保留。

#### 3. 跨句、跨段照应

抽象词 `this`、概括性名词或结尾价值判断，可能回指前一句关系，也可能概括整段生活方式。先明确回指范围，再判断选项；不要见到近处某个名词就默认只指它。

### 教学提示与完成证据

教练可依次追问：

- “这是谁的看法，是过去还是现在？”
- “前后两层意思是顺着走，还是承认以后转向？”
- “哪个原文事实是锚点？”
- “如果换成另一个候选，哪条时间线或态度线会断？”

学生能在 按证据需要安排的同类新空中独立标明视角、时间、逻辑关系和证据锚点，并在全文复查时保持前后一致，即完成本轮补漏。只会圈连接词、不会说两层意思之间的关系，不算独立掌握。

## 增量三：关键长句的最小句法补漏

### 学习目标

学生只拆开决定当前空的结构，找到主干、逻辑接口和指代后立即返回选项判断；不把完形课变成整句语法分析或全文翻译。

### 触发信号

- 选项认识、篇章主线也清楚，但学生说不出长句的主语和核心动作；
- 分号、并列结构、插入成分、非谓语或多层从句使学生把修饰语当主干；
- 不清楚 `it`、`this`、`what` 或 `wherever` 所在部分与主句的关系；
- 学生逐词都能译，却把因果、时间、让步或动作发出者接错；
- 解释句子主干后，学生就能回到词义或逻辑流程继续作答。

### 最短流程

```text
保留空格所在句和必要前一句
→ 圈连接词、标点和关系信号
→ 框主句的主语 + 谓语 + 必要宾语/补语
→ 用斜线隔开从句、非谓语和插入成分
→ 还原代词或概括词指向
→ 只翻译主干和决定当前空的逻辑关系
→ 立即回到语境义或篇章逻辑流程
```

学生输出只需达到：

```text
主干：谁/什么 + 做什么/怎么样
附加信息：何时、为何、让步还是条件
当前空控制的部分：
```

### 本样例中可按需处理的结构外观

- `be convinced that ...` 后接判断内容；
- `it took ... to realize ...` 中形式主语、触发条件和认识结果分处不同位置；
- `what ...` 表示被认识到的内容，不是新的叙述者；
- 分号连接两个关系紧密但各有主干的部分；
- `and know that ...` 与前一谓语并列，`wherever ...` 提供让步或范围背景，主句核心仍在后面。

这些名称只在能帮助学生拆句时使用。能用“主干 + 附加信息”说清就停止，不要求背术语，也不顺带讲完整的名词性从句、状语从句或非谓语章节。

### 教学提示与完成证据

教练只问当前空真正需要的结构问题：

- “先删掉修饰信息，主句还剩什么？”
- “这个连接词左边和右边各是什么完整意思？”
- “这个代词或概括词具体指前文哪件事？”
- “拆清以后，本空回到词义问题还是逻辑问题？”

学生能在一个结构相近的新句中独立找出主干、说明附加信息与主干的关系，并据此返回选项比较，即完成本轮句法补漏。能够逐词翻译但仍不能说明结构关系，不算完成。

## 教学台阶

| 台阶 | 只解决的目标 | 进入信号 | 完成后去向 |
| --- | --- | --- | --- |
| H0 基础流程 | 词汇门槛、篇章草图、代入排除、找线索和全文验证 | 所有学生先从这里开始 | 基础流程已能解决就停止，不启用扩展 |
| H1 单空精辨 | 最后两个候选只比较一个决定性语义维度 | 词都认识但只能说“都可以” | 用 按证据需要安排的同类新空验证后回整篇 |
| H2 句间逻辑 | 识别一个明确的转折、因果、时间或态度变化 | 局部都通，近处上下文能决定 | 新空能独立说出两层意思和锚点后回整篇 |
| H3 篇章追踪 | 跨句或跨段追踪视角、指代、态度与结果 | 同一关系影响相邻多空，或结尾回扣前文 | 在新篇中能更新草图并避免同类连错 |
| P 句法补丁 | 拆开阻断当前判断的一处关键结构 | 证据存在但句子结构读错 | 拆清即返回 H1、H2 或 H3，不单独扩展语法 |

H1—H3 不是固定年级进度，也不要求依次学完。根据报告进入最低够用的台阶；P 可在任一台阶临时调用。未被真实题目触发的内容保持未评估。

## 一次最小教学模板

1. 让学生保留原来的最后两个候选，并说出已经执行到基础流程哪一步；
2. 用路由表确定一个断点，不同时讲三类增量；
3. 教练示范一次“差异/关系 → 证据 → 排除”，但不替学生完成下一空；
4. 让学生独立完成 按证据需要安排的同类新空，必须说证据；
5. 验证通过就回到一篇新的完整完形；未通过只修正当前步骤，不扩大知识范围。

## 2026 高考全国 1 卷样例的证据映射

- 题目来源文件：`题型示例/高考全国1卷-完形填空.md`
- 当前状态：题目文字和选项已整理，文件未提供答案与解析。
- 使用边界：下表只说明每空可能调用哪类证据、学生应做什么，不选择任何字母或单词，也不声称存在官方答案。没有另行核验答案前，可用它检查流程覆盖范围，不能据此判分或形成学生能力结论。

| 空号 | 主要增量 | 应查看的证据范围 | 学生应完成的证据动作 |
| ---: | --- | --- | --- |
| 1 | 语境义；必要时长句补丁 | 首句的 `of how little ...` 与后文同学的误解和直接提问 | 说明空格所命名的是哪一类心理事件或认识，并比较抽象名词的语篇角色 |
| 2 | 焦点词精辨 | 三个半小时的距离与同学把 Ohio 当作“另一个世界”的反差 | 去掉焦点词写基本事实，再比较各词表达的是限制、延续、超预期还是确认 |
| 3 | 语境义 | 连续两句直接疑问及 `never-ending` | 判断这些话语在此处属于哪类反复行为，用话语形式和数量感排除不符者 |
| 4 | 近义精辨；视角 | `in their eyes` 与同学因地域误解形成的看法 | 先确定这是同学眼中的身份定位，再比较候选对人的具体评价差异 |
| 5 | 态度随时间变化 | `As I grow older`、`more and more` 以及后文当前反思 | 写出“过去抱怨—现在评价”的时间线，用当前态度约束形容词 |
| 6 | 搭配与语境义 | 动词后的 `about how bored ...` 及过去情绪 | 将“动词 + about + 内容”作为整体，说明该行为如何表达当时态度 |
| 7 | 让步—转折 | `Sure, ...` 分句、分号后的大学阶段反思 | 分别概括承认的旧事实和后面推进的新判断，再比较连接关系 |
| 8 | 长句补丁；因果与时间 | `it took ... to realize ...` 及“离开/改变后才认识”的事件链 | 先标出认识结果与触发经历，再比较动名词候选在事件链中的作用 |
| 9 | 语境义；段落主旨 | 慢节奏与人们彼此连接的并列描述 | 把空格改写成“人们如何看待彼此连接”，比较动词的态度和主动性 |
| 10 | 抽象/引申义 | “不只交谈”与邻居和家庭关系的递进 | 说明空格需要命名何种家庭关系，再比较抽象名词能否表达这种关系 |
| 11 | 跨句照应 | `Much of this ...` 对前句社区连接方式的概括，以及后面的户外和城镇文化 | 先确定 `this` 的回指范围，再判断哪个名词能概括整组生活特征 |
| 12 | 近义精辨 | `being outside`、熟悉城镇与 `present and mindful of ...` | 确定空格对象属于环境、物品、发现还是社交行为中的哪一域，并用本段主题验证 |
| 13 | 短语动词；时间与态度 | 大学阶段、回乡探访及全文态度走向 | 把四个短语动词作为整体，说明哪种动作方向能接“visits”并符合当前期待 |
| 14 | 抽象名词精辨 | `grateful for ...`、`that I had growing up` 和前文成长背景 | 判断空格概括的是能力、名声、经历还是机会一类内容，再用全文回忆范围约束 |
| 15 | 长句补丁；比喻义与搭配 | `and know that ...`、`wherever ...`、`roots` 与 `lead me` | 拆出主句核心，说明 `roots` 的比喻所指，再比较哪个动词能与后面的引导结果建立合理关系 |

这份映射验证的是“流程能否带学生找到相关证据”，不是对各空正确选项的公布。若以后补入可靠答案与逐空解析，应另行核对每个映射是否足以唯一排除干扰项。

## 完成证据与停止点

| 增量 | 最小完成证据 | 默认停止点 |
| --- | --- | --- |
| 语境义与近义精辨 | 独立说出最后两个候选的共同点、一个决定性差异和原文约束 | 按证据需要安排的同类新空成功后回完整材料 |
| 句子与篇章逻辑 | 独立标出视角、时间、逻辑关系和证据锚点 | 能在新篇中更新篇章草图后停止专项训练 |
| 关键长句句法 | 独立找出主干和必要附加关系，并回到词义或逻辑判断 | 当前结构障碍解除即停止，不扩展语法章节 |

只评价本轮实际触发的增量。学生没有接触另外两类，不写成“不会”；一次样例中碰巧选对但说不出差异、逻辑或证据，也不提升为可独立。

## 边界与常见误区

- **不反向抬高中考要求。**初中学生默认只学基础流程。若一份可靠初中真题偶然需要某个精辨或长句动作，只补当前题所需的一小步，不整套引入高中扩展。
- **不按年级自动加码。**高中生能用基础流程解决的空，不强制写语义维度、画时间线或拆长句。
- **不把词汇不足包装成高阶技巧。**最后两个候选若连核心意思都说不清，先补词义；整篇词汇明显超标则换材料。
- **不把所有题做成近义词辨析。**明确搭配、原词复现或局部事实能唯一决定时，停在基础层。
- **不穷举词典义和搭配。**只比较当前候选在当前语境中的决定性差异；低频例外不进入主线。
- **不把褒贬当精辨终点。**两个正面词、两个负面词仍需比较对象、程度、动作方向或时间状态。
- **不把他人话语当作者结论。**直接引语、过去抱怨和现在反思必须分开记录。
- **不把拆句变成全文翻译。**只保留决定当前空的主干、关系和指代，障碍解除后立即返回完形流程。
- **不把待定答案当篇章事实。**用于跨空推理的内容应来自未挖空正文或有明确证据的答案；`?` 不能证明另一个 `?`。
- **不利用无答案样例作权威判分。**本文件中的全国卷样例仅作证据路由演示，不提供或暗示官方答案。

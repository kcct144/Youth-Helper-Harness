# 语法选择考点：冠

- 考点范围：不定冠词 `a / an`、定冠词 `the` 和零冠词
- 考频：核心考点
- 教学类型：快速规则型
- 学习目标：能根据可数性、泛指特指和读音选择冠词

## 考点特征

选项常直接出现：

```text
a / an / the
```

也可能加入不填冠词的选项。看到这些形式时，优先考虑“冠”。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 从选项认出 `a / an / the` | 零冠词和固定搭配 |
| L1 高频核心 | 首次、非特指用 `a/an`；再次提到或明确特指用 `the`；按发音选 `a/an` | 零冠词、专有名词、成批固定搭配 |
| L2 常见特指 | 后置限定、双方都知道、独一无二等常见 `the` 用法 | 机构功能和专名边界 |
| L3 零冠词与积累 | 零冠词、机构功能、常见固定搭配；每次只积累一个真实遇到的用法 | 生僻专名规则 |

**默认停止点是 L1。**不得在基础冠词课中一次罗列大量固定搭配。真实题目遇到一个固定用法时，只补这一个、配一个例句并安排复现，不顺带扩充整张表。

## 标准思路

```text
找冠词后面的核心名词
→ 判断是否为可数名词单数
→ 判断是首次或非特指，还是再次提到或明确特指
→ 非特指可数单数用 a/an，并按发音选择
→ 特指用 the
→ 检查固定搭配、专有名词和零冠词
→ 代回上下文验证
```

## 重点

- `a / an` 表示一个或某个非特定的人或物，只用于可数名词单数。
- `the` 用于再次提到、双方都知道或被后置内容限定的特定对象。
- `a / an` 按后一个词开头的发音判断，不只看首字母。
- `there be` 或 `have` 后常首次引入新对象，但仍要检查是否特指。

## 难点

- `a / an` 的首音判断先用学生熟悉的词训练；`an hour` 中 `h` 不发音、`a useful book` 中 `u` 发 /juː/ 等边界例子，只在真实题目卡住或学生明确要求时补充。
- 首次提到和再次提到往往跨句出现，需要读上下文。
- 可数名词单数通常需要限定词，但不代表一定选择 `a / an`。
- `the` 也可用于独一无二的事物、最高级和序数词等结构。

## 特殊情况

- 学科、语言、球类运动和一日三餐前常用零冠词，如 `play basketball`、`have breakfast`。
- 乐器前常用 `the`，如 `play the piano`。
- `go to school` 强调上学这一功能时常不用冠词；指具体校舍时可用 `the school`。
- 专有名词的冠词用法需要逐项积累，不用一个口诀覆盖所有情况。

## 例题与解析

### 例题一

- 所属台阶：L1

There is ____ useful book on the desk.

- A. a
- B. an
- C. the

- 答案：A
- 考点特征：`a / an / the`。
- 判断流程：首次引入一本非特指的可数名词单数；`useful` 开头发 /juː/，所以用 `a`。
- 来源：自编例题

### 例题二

- 所属台阶：L1

Emma saw a cat in the tower. ____ cat was sleeping on the button.

- A. A
- B. An
- C. The

- 答案：C
- 考点特征：冠词形式对比。
- 判断流程：第二句再次提到前一句的猫，已经明确特指，所以用 `the`。
- 来源：自编例题

## 常见错误

- 只看首字母选择 `a / an`，不听发音。
- 看到单数名词就默认 `a / an`，不判断是否特指。
- 忽略前文已经提到的对象。
- 把固定搭配当成所有名词都适用的规则。

## 掌握标准

- 能先判断可数名词单数，再判断泛指或特指。
- 能按发音区分 `a / an`。
- 能利用前后文判断首次提到和再次提到。
- 能说明何时使用零冠词或固定搭配，而不是机械默认。

# 语法选择考点：时

- 考点范围：谓语动词的时态、语态和主谓一致
- 考频：核心考点
- 教学类型：系统理解型
- 学习目标：能确认谓语位置，并按主语、时间、语态和上下文顺序判断

## 考点特征

选项通常是同一动词的不同谓语形式，例如：

```text
rings / rang / will ring
welcomes / is welcomed / are welcomed
```

当选项主要改变时间、助动词、被动结构或单复数，且没有明显 `to do` 对比时，优先考虑“时”。

## 前置知识

进入时态学习前，先确认学生能在短句中找到主语和谓语，并认识动词原形、第三人称单数和常见过去式。前置知识不足时先补这一小块，不直接讲时态大全。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 句子骨架 | 在短句中找到主语和谓语 | 时态混合、语态 |
| L1 一般现在时 | 经常、事实和当前状态；第三人称单数 | 其他时态 |
| L2 一般过去时 | 明确过去时间和过去叙事；规则及少量常用不规则过去式 | 完成时、被动 |
| L3 一般将来时 | `will do` 和明确的将来语境 | 条件、时间从句中的将来表达 |
| L4 三种基本时态混合 | 在一般现在、一般过去、一般将来之间按时间和上下文切换 | 进行时、被动、完成时 |
| L5 现在进行时 | `be doing` 与正在发生的动作 | 被动和复杂状态动词 |
| L6 被动语态 | 在已学时态中判断主动或被动 | 完成时被动等复合结构 |
| L7 完成与复杂结构 | 现在完成时及项目确认需要的复杂结构 | — |

一次原则上只学一个台阶。默认按 L1 → L2 → L3 → L4 铺设三种基本时态；L1—L4 未稳定时，不主动讲或考被动语态、现在完成时。真实题目需要高阶结构时，只解释解题所需的最小部分，并标记为后续内容。

## 标准思路

```text
判断空格是否缺谓语
→ 找该分句主语，检查人称和单复数
→ 找时间标志词和事件发生顺序
→ 判断主语执行动作还是承受动作
→ 选择时态和主动/被动
→ 与上下文其他谓语核对
```

## 重点

- 一个完整分句通常需要一个谓语核心。
- 先找主语再判断单复数，不能只盯动词变化。
- 明确时间词有帮助，但上下文的叙事时间同样重要。
- 被动语态的基本结构是 `be + done`，`be` 仍要随时态和主语变化。
- 一般现在时第三人称单数要注意动词变化。

## 难点

- 同一道题可能同时考时态、语态和主谓一致，必须逐项检查。
- 没有明显时间词时，要根据前后谓语和事件关系判断。
- `be doing` 是进行时，`be done` 常是被动语态，不能只看到 `be`。
- 主语与谓语之间有较长修饰语时，容易找错主语。

## 特殊情况

- `if / when` 引导时间或条件状语从句时，谈将来常出现“主句将来、从句一般现在”。
- `since` 常与现在完成时搭配，但仍要判断具体结构和语境。
- 某些状态动词通常不用进行时，需要逐步积累。
- 过去叙事中出现客观事实时，客观事实仍可能用一般现在时。

## 例题与解析

### 例题一

- 所属台阶：L2

Last night, the bell ____ at ten o'clock.

- A. rings
- B. rang
- C. will ring

- 答案：B
- 考点特征：同一动词的不同时态。
- 判断流程：空格是谓语；主语 `the bell` 为单数；`Last night` 表示过去，所以用一般过去时 `rang`。
- 来源：自编例题

### 例题二

- 所属台阶：L6

The lost cat ____ by everyone at its new school.

- A. welcomes
- B. is welcomed
- C. are welcomed

- 答案：B
- 考点特征：主动、被动和单复数形式对比。
- 判断流程：猫是被欢迎的对象，要用被动；主语 `cat` 为单数，所以用 `is welcomed`。
- 来源：自编例题

## 常见错误

- 只看到时间词，不检查主动或被动。
- 只看离动词最近的名词，找错真正主语。
- 看到 `now` 就机械选择进行时，忽略动词和语境。
- 前文使用过去时，就把所有句子都改成过去时。

## 掌握标准

- 能先确认谓语和主语，再找时间依据。
- 能判断动作的执行者和承受者。
- 能同时检查时态、语态和主谓一致。
- 能在没有明显时间词的变式题中利用上下文判断。

# 语法选择考点：词

- 考点范围：名词、动词、形容词和副词等词性转换
- 考频：核心考点
- 教学类型：系统理解型
- 学习目标：能先判断空格的句子成分，再根据词形选择正确词性

## 考点特征

选项通常来自同一词根，但后缀或词性不同，例如：

```text
silent / silence / silently
care / careful / carefully
success / successful / successfully
```

看到同词根的不同形式时，优先考虑“词”。

## 前置知识

先确认学生认识最基本的名词、动作词和 `be` 动词。若连“谁或什么 + 做什么”都还不会找，先练句子骨架，不直接讲后缀表或复杂系动词。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 看出选项同词根但后缀不同，知道在考词性 | 不要求一次识别所有后缀 |
| L1 名词与动词 | 在短句中判断需要事物名称还是动作 | 形副辨析和复杂句子成分 |
| L2 基础形容词 | 名词前用形容词修饰；`be` 后用形容词说明状态 | 其他系动词、`-ing/-ed` 形容词 |
| L3 形容词与副词 | 形容词修饰名词，副词修饰常见动作动词 | 感官系动词和例外词 |
| L4 系动词扩展 | 在 `be` 稳定后，逐个学习 `become / remain / feel / look` 等常见系动词 | `-ing/-ed` 形容词 |
| L5 词性边界 | `-ing/-ed` 形容词、`friendly` 等例外和一词多性 | — |

初学默认停在 L2；本轮目标是形容词和副词时默认停在 L3。L2 未稳定时，不主动引入感官系动词；L3 未稳定时，不主动引入 `-ing/-ed` 形容词或大量词尾例外。

## 标准思路

```text
先看空格前后结构
→ 判断空格作主语、宾语、谓语、表语还是修饰语
→ 确定需要名词、动词、形容词或副词
→ 利用后缀识别候选词性
→ 检查固定搭配和词义
→ 代回整句验证
```

## 重点

- 名词常作主语、宾语或表语，也常位于限定词或形容词后。
- 动词可作谓语；情态动词后和不定式 `to` 后常接动词原形。
- 形容词修饰名词，也常在 `be / become / remain / feel` 等系动词后作表语。
- 副词可修饰动词、形容词、其他副词或整个句子。
- 先判断句子成分，再看后缀；顺序不能颠倒。

## 难点

- 系动词后通常用形容词，不用副词，如 `remain silent`。
- `to + 动词原形` 属于非谓语结构，不能因此把整句中的空格都判断为谓语。
- 有些单词可兼作多种词性，不能只靠词尾。
- `-ly` 多为副词，但 `friendly / lovely / lively` 等通常是形容词。

## 特殊情况

- `hard` 可作形容词或副词，`hardly` 表示“几乎不”，意思不同。
- `fast / early / late` 等可同时作形容词和副词。
- 过去分词有时像形容词作表语，需要结合语义判断状态还是被动动作。
- 某些词形变化不规则，需要结合词汇积累。

## 例题与解析

### 例题一

- 所属台阶：L4

One morning, the school bell remained ____.

- A. silent
- B. silence
- C. silently

- 答案：A
- 考点特征：同词根的形容词、名词和副词。
- 判断流程：`remained` 是系动词，后面需要形容词作表语，所以选 `silent`。
- 来源：自编例题

### 例题二

- 所属台阶：L3

The teacher explained the rule ____.

- A. clear
- B. clearly
- C. clearness

- 答案：B
- 考点特征：不同词性形式。
- 判断流程：空格修饰动词 `explained`，需要副词 `clearly`。
- 来源：自编例题

## 常见错误

- 看到熟悉的词义就选，不判断句子成分。
- 认为 `be` 后一定接名词，忽略形容词表语。
- 看到 `-ly` 就一律判断为副词。
- 只靠词尾猜词性，不把答案代回句子。

## 掌握标准

- 能说出空格在句中的主要作用。
- 能根据修饰关系区分形容词和副词。
- 能利用后缀辅助判断，同时知道常见例外。
- 能在改变空格位置或系动词的变式题中继续正确判断。

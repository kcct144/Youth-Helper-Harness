# 语法选择考点：比

- 考点范围：形容词和副词的原级、比较级与最高级
- 考频：核心考点
- 教学类型：系统理解型
- 学习目标：能根据比较对象、标志和范围选择正确比较形式

## 考点特征

选项常呈现同一词的不同级别，例如：

```text
tall / taller / tallest
carefully / more carefully / most carefully
good / better / best
```

看到 `-er / -est / more / most` 或原级、比较级、最高级并列时，优先考虑“比”。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 从选项认出原级、比较级和最高级 | 复杂比较结构 |
| L1 比较级 | 看到明确的 `than`，选择常见规则比较级 | 不规则变化和修饰词 |
| L2 最高级 | 根据三者以上范围、`in/of` 和 `one of the` 判断最高级 | 特殊句型 |
| L3 原级与不规则 | `as ... as` 及 `good/better/best` 等常见不规则变化 | 复杂修饰和省略 |
| L4 特殊比较结构 | 比较级修饰词、“越……越……”等结构 | — |

默认先完成 L1，再进入 L2；每轮只新增一种决定信号。学生尚不能稳定利用 `than` 时，不用特殊结构提高难度。

## 标准思路

```text
判断空格需要形容词还是副词
→ 找比较对象和比较范围
→ 找 than、as...as、in/of、one of the 等标志
→ 判断原级、比较级或最高级
→ 检查固定结构和不规则变化
→ 代回句意验证
```

## 重点

- `than` 常提示比较级。
- `as + 原级 + as` 使用原级。
- 明确三者及以上范围、`in / of` 范围或 `one of the` 常提示最高级。
- `much / even / a little / far` 等可修饰比较级。
- 先判断形容词还是副词，再变化比较等级。

## 难点

- 没有明显标志时，要根据句意判断是否存在比较。
- `the` 常与最高级连用，但看到 `the` 不能直接选择最高级。
- 注意 `good / well → better → best`、`bad / badly → worse → worst` 等不规则变化。
- 比较对象必须同类，避免结构上比较了不同事物。

## 特殊情况

- `the + 比较级 ..., the + 比较级 ...` 表示“越……越……”。
- `比较级 and 比较级` 表示“越来越……”。
- `one of the + 最高级 + 可数名词复数` 是常见结构。
- 某些形容词通常不使用比较级，遇到时以可靠用法为准，不机械加 `-er`。

## 例题与解析

### 例题一

This tower is ____ than the old one.

- A. high
- B. higher
- C. highest

- 答案：B
- 考点特征：原级、比较级和最高级。
- 判断流程：`than` 提示两者比较，因此使用比较级 `higher`。
- 来源：自编例题

### 例题二

Emma is one of the ____ students in her class.

- A. careful
- B. more careful
- C. most careful

- 答案：C
- 考点特征：形容词不同等级。
- 判断流程：`one of the` 后接最高级和可数名词复数，所以选 `most careful`。
- 来源：自编例题

## 常见错误

- 看到 `the` 就选最高级，不检查结构。
- 看到两个对象就选比较级，但句中其实没有比较关系。
- 忘记比较级前的修饰词或不规则变化。
- 没有先判断空格需要形容词还是副词。

## 掌握标准

- 能识别原级、比较级和最高级选项。
- 能利用 `than`、比较范围和固定结构说明依据。
- 能处理常见不规则变化。
- 能在没有直接标志的变式题中根据比较对象和句意判断。

# 语法选择考点：非

- 考点范围：动词不定式、动名词和分词等非谓语形式
- 考频：核心考点
- 教学类型：按题补充型
- 学习目标：能先判断是否需要非谓语，再按搭配和动作关系选择形式

## 考点特征

选项常比较：

```text
to do / doing / done
find / finding / to find
```

出现 `to do`，或同一动词的原形、`doing`、`done` 形式对比时，优先检查“非”。

## 前置知识

先确认学生能找到当前分句的谓语。不会找谓语时，先补句子骨架；否则学生会把所有动词形式都混在一起。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 认出 `to do / doing / done` 等选项差异，并先找已有谓语 | 主被动和意义变化 |
| L1 常见 `to do` 搭配 | 一次积累一个真实遇到的 `动词 + to do` | `doing/done` 对比 |
| L2 常见 `doing` 搭配 | 一次积累一个 `动词 + doing`，并学习介词后 `doing` | 分词作定语或状语 |
| L3 常见功能 | 表目的的 `to do`、常见宾补结构 | 复杂主动被动关系 |
| L4 主动与被动关系 | 在结构清楚时区分 `doing/done` | 意义改变的成对结构 |
| L5 特殊意义 | `try/remember/stop` 等接不同形式时意义改变 | — |

默认一次只处理一个搭配或一个功能。学生只学过 L1 时，题目和干扰项不得要求他用 L4、L5 的知识排除答案；“看不出默认 `to do`”不能代替台阶教学。

## 标准思路

```text
先看当前分句是否已经有谓语
→ 没有连接词却已有谓语，空格常考虑非谓语
→ 优先检查前后词的固定搭配
→ 再判断非谓语在句中的作用
→ 判断与相关名词的主动、被动和动作先后关系
→ 选择 to do、doing 或 done 并代回验证
```

## 重点

- `want / decide / hope / plan / try` 等动词后常见 `to do`，具体搭配需要逐项确认。
- `enjoy / finish / mind / practise` 等动词后常见 `doing`。
- 介词后接动词时通常使用 `doing`。
- `ask / tell / want + somebody + to do` 是常见结构。
- 表目的时常使用 `to do`，但仍要看完整句子。

## 难点

- 非谓语考点既有规则，也高度依赖动词搭配积累。
- 同一动词后接 `to do` 和 `doing` 时，意思可能不同。
- `doing` 常表示主动或进行关系，`done` 常表示被动或完成关系，但不能脱离句子功能机械选择。
- 要先确认句中真正的谓语，避免把谓语形式误判为非谓语。

## 特殊情况

- `try to do` 表示努力做某事；`try doing` 表示尝试某种方法。
- `remember / forget / stop` 等动词接 `to do` 与 `doing` 时意义可能改变。
- 感官动词和使役动词后有省略 `to` 的结构，需要专项积累。
- “看不出时默认 `to do`”只可作为低置信度兜底，使用后仍要标记为未真正掌握。

## 例题与解析

### 例题一

Emma and her friends tried ____ what had happened.

- A. find out
- B. found out
- C. to find out

- 答案：C
- 考点特征：原形、过去式和不定式对比。
- 判断流程：句中已有谓语 `tried`；`try to do` 表示努力做某事，所以用 `to find out`。
- 来源：根据题型示例整理；答案为项目分析，非官方答案

### 例题二

The children enjoy ____ stories about the old tower.

- A. read
- B. reading
- C. to read

- 答案：B
- 考点特征：动词形式对比。
- 判断流程：句中已有谓语 `enjoy`；`enjoy doing` 是固定搭配，所以用 `reading`。
- 来源：自编例题

## 常见错误

- 看到 `to do` 选项就直接选，不查搭配。
- 不判断句中是否已经有谓语。
- 只背“某词后接 doing”，不结合例句和意义。
- 使用兜底猜对后误认为已经掌握。

## 掌握标准

- 能先找到句中谓语，再判断是否需要非谓语。
- 能调用已学的动词搭配。
- 能初步说明主动、被动或目的关系。
- 能在间隔复测中正确使用已经积累的搭配，并区分至少一组意义不同的结构。

# 语法选择考点：连

- 考点范围：并列连词和常见从属连词
- 考频：核心考点
- 教学类型：按题补充型
- 学习目标：能先看前后结构，再根据逻辑关系和语境选择连词

## 考点特征

选项通常是不同连词，例如：

```text
and / but / or
if / because / when
so that / although / since
```

看到选项主要表示不同逻辑关系时，优先考虑“连”。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 认出选项是连接词，并查看前后连接什么 | 从句成分分析 |
| L1 基本并列 | `and / but / or / so` 的并列、转折、选择和结果 | 成对连词和多义用法 |
| L2 常见从属关系 | `because / if / when` 的原因、条件和时间 | 复杂从句引导词 |
| L3 让步与目的 | `although / so that` 等常见关系 | 成对结构 |
| L4 结构边界 | 成对连词、`if` 多义和与从句引导词的边界 | — |

默认从 L1 开始，一次只比较两三种清晰关系。学生尚不能区分并列和转折时，不引入成对连词或复杂从句术语。

## 标准思路

```text
看空格前后连接的是词、短语还是分句
→ 检查两边结构是否完整
→ 判断并列、转折、选择、原因、结果、条件、时间、目的或让步
→ 比较连词的意义和用法
→ 放回上下文验证逻辑
```

## 重点

- `and` 表并列或顺承，`but` 表转折，`or` 表选择或“否则”。
- `because` 表原因，`so` 表结果；通常不在同一个简单结构中同时使用。
- `if` 常表条件，`when` 常表时间，`although` 表让步。
- `so that` 可表示目的或结果，要结合上下文。
- 先判断前后逻辑，再看中文翻译是否自然。

## 难点

- 同一句中文可能对应不同逻辑关系，必须看上下文。
- `because` 后接分句，`because of` 后接名词、代词或名词性结构。
- 有些词既可作介词、连词或副词，需要看后面结构。
- 从句引导词若在从句中还充当成分，不应只按普通连词处理。

## 特殊情况

- `although / though` 通常不与 `but` 在同一结构中重复使用。
- `not only ... but also ...`、`both ... and ...` 等成对结构要检查对应成分。
- `if` 既可表示“如果”，在某些宾语从句中也可表示“是否”。
- 特殊疑问词和从句引导词另有成分判断，属于相关低频考点。

## 例题与解析

### 例题一

The children wanted to find the cat a new home ____ the bell could ring again.

- A. so that
- B. ever since
- C. because of

- 答案：A
- 考点特征：不同连接表达。
- 判断流程：空格后是完整分句，前面行为的目的是让铃重新响，使用 `so that`。
- 来源：根据题型示例整理；答案为项目分析，非官方答案

### 例题二

Emma was tired, ____ she continued climbing the tower.

- A. and
- B. but
- C. because

- 答案：B
- 考点特征：连词对比。
- 判断流程：“疲惫”与“继续攀登”形成转折，所以用 `but`。
- 来源：自编例题

## 常见错误

- 只翻译一个连词，不分析前后逻辑。
- 混淆 `because` 和 `because of` 后面的结构。
- 同时使用 `although` 和 `but`。
- 看到空格后是句子就随便选连词，不检查关系。

## 掌握标准

- 能判断空格前后连接的结构类型。
- 能说出主要逻辑关系，而不只给中文意思。
- 能区分 `because / because of` 等结构差异。
- 能在完整语篇和间隔复测中调用已经积累的连词用法。

# 语法选择考点：感叹句

- 考点范围：`what` 和 `how` 引导的感叹句
- 考频：低频考点
- 教学类型：快速规则型
- 学习目标：能根据感叹部分的中心词判断使用 `what` 还是 `how`

## 考点特征

选项常出现 `what / what a / what an / how`，句末通常有感叹号，或句子语气明显表示赞叹、惊讶等。

常见结构：

```text
What + a/an + 形容词 + 可数名词单数 + 主语 + 谓语！
What + 形容词 + 可数名词复数或不可数名词 + 主语 + 谓语！
How + 形容词或副词 + 主语 + 谓语！
```

## 标准思路

```text
先找感叹部分的中心词
→ 中心词是名词或名词短语：用 what
→ 中心词是形容词或副词：用 how
→ what 后若是可数名词单数，再判断 a/an
→ 检查后面的主语和谓语是否完整
```

## 重点

- 判断 `what / how` 的关键是中心词，不是只看中文“多么”。
- `what` 后接名词短语；`how` 后直接接形容词或副词。
- `What a/an ...!` 中的 `a/an` 仍按后面词的发音判断。
- 感叹句后面的“主语 + 谓语”有时可以省略。

## 难点

- 名词前有形容词时，中心仍可能是名词，如 `a beautiful tower`。
- `How beautiful the tower is!` 中 `beautiful` 是中心词，不能因为后面出现 `tower` 就选 `what`。
- 可数名词单数、复数和不可数名词对应的 `what` 结构不同。

## 特殊情况

- `How time flies!` 中 `how` 修饰整个谓语表达，属于需要积累的固定感叹方式。
- 口语中常省略主谓部分，如 `What a pity!`、`How beautiful!`。
- 如果题目同时考冠词，仍要先识别感叹结构，再处理 `a/an`。

## 例题与解析

### 例题一

____ lovely cat it is!

- A. What a
- B. How
- C. What

- 答案：A
- 考点特征：`what / how` 感叹结构。
- 判断流程：中心是可数名词单数短语 `lovely cat`，使用 `What a`。
- 来源：自编例题

### 例题二

____ beautiful the old tower is!

- A. What
- B. How
- C. What a

- 答案：B
- 考点特征：感叹词对比。
- 判断流程：感叹部分以形容词 `beautiful` 为中心，后面是完整的 `the old tower is`，所以用 `How`。
- 来源：自编例题

## 常见错误

- 一看到名词就选 `what`，没有判断名词是否属于后面的主语。
- 忘记可数名词单数前的 `a/an`。
- 把所有“多么”都翻译成 `how`。
- 只背公式，不先找中心词。

## 掌握标准

- 能找出感叹部分的中心词。
- 能区分名词短语和形容词、副词中心。
- 能正确处理 `what a/an`、复数和不可数名词结构。
- 能在改变中心词的对比例题中继续使用流程。

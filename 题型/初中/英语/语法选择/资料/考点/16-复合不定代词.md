# 语法选择考点：复合不定代词

- 考点范围：`someone / anyone / everyone / no one / something / anything / everything / nothing` 等
- 考频：低频考点
- 教学类型：系统理解型
- 学习目标：能根据人或物、肯定或否定语境、修饰位置和主谓一致选择

## 考点特征

选项常由 `some / any / every / no` 与 `one / body / thing` 组成，例如：

```text
someone / anyone / no one
something / anything / nothing
```

看到这些形式时，要同时判断指人还是指物，以及句子的肯定、否定或疑问语境。

## 标准思路

```text
先判断空格指人还是指物
→ 再判断是某个、任何、每个还是没有
→ 结合肯定句、否定句、疑问句和说话人预期选择 some/any/no/every 系列
→ 检查后置形容词和主谓一致
→ 代回上下文验证
```

## 重点

- `-one / -body` 通常指人，`-thing` 指物。
- `someone / something` 常用于肯定句；`anyone / anything` 常用于疑问或否定语境。
- `everyone / everything` 表示全部；`no one / nothing` 本身带否定意义。
- 复合不定代词作主语时，谓语通常用单数。
- 形容词修饰复合不定代词时通常后置，如 `something useful`。

## 难点

- `some` 系列也可用于希望得到肯定回答的请求或邀请。
- `any` 系列在肯定句中可表示“任何一个”。
- `no one` 指人，`nothing` 指物，不能只按否定选择。
- 复合不定代词含义上可能指多人，但语法上通常按单数处理。

## 特殊情况

- `Would you like something to drink?` 是提供或邀请，常使用 `something`。
- `Anyone can join the club.` 中 `anyone` 表示“任何人”，用于肯定句。
- `no one` 通常分写，`nobody` 合写；两者都指人。
- 与反意疑问句和代词回指相关的细节可按实际年级要求补充。

## 例题与解析

### 例题一

There is ____ wrong with the bell.

- A. something
- B. someone
- C. everyone

- 答案：A
- 考点特征：复合不定代词对比。
- 判断流程：空格指某件事情，不是人；形容词 `wrong` 后置修饰，所以用 `something`。
- 来源：自编例题

### 例题二

____ in the class is ready for the trip.

- A. Everyone
- B. Everything
- C. Anything

- 答案：A
- 考点特征：指人或物及整体范围。
- 判断流程：指班里的每个人，使用 `Everyone`；谓语 `is` 也符合单数一致。
- 来源：自编例题

## 常见错误

- 指人和指物混淆。
- 看到疑问句就机械选择 `any` 系列，忽略请求或邀请。
- 形容词放在复合不定代词前面。
- 主语是 `everyone` 却使用复数谓语。

## 掌握标准

- 能先判断指人还是指物。
- 能根据语境区分 `some / any / every / no` 系列。
- 能正确使用后置形容词和单数谓语。
- 能处理请求、邀请和“任何人”这类常见特殊语境。

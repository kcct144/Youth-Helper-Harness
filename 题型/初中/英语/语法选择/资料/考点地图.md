# 语法选择考点地图

- 适用学段：初中，重点面向广东中考语法选择
- 内容类型：题型方法 / 考点索引
- 学习目标：先根据选项判断考点，再按对应步骤作答并说明依据
- 前置知识：基本句子成分、常见词性和简单句结构

## 核心原则

语法选择以考点为中心。每道题都先回答两个问题：

1. **这道题考什么？**观察三个选项的共同点和差异，给题目贴上考点标签。
2. **这个考点怎么判断？**按该考点的步骤检查句子结构、固定搭配和上下文。

推荐的完整顺序是：

```text
观察选项差异 → 判断考点 → 确定空格在句中的作用
→ 使用该考点的判断步骤 → 代回句子和上下文验证
```

不能只看选项外形就直接作答。选项特征用于“识别考点”，句子结构、搭配和语境才是“选择答案”的依据。

进入某个考点的做题流程前，先按 `学习路径.md` 检查该台阶需要的最小前置形式或概念。前置检查只针对当前考点，不一次普查整套语法；前置未稳时先补基础，不把问题误记为流程不会。

## 十类核心考点

用“人、时、名、非、介、连、比、冠、情、词”帮助记忆。它们是导航简称，不是学生必须先背会的术语。首次教学必须同时出现完整名称；学生理解概念和基本形式后，才要求使用简称。

| 口诀 | 考点 | 常见选项信号 | 作答时重点检查 | 详细文档 |
| --- | --- | --- | --- | --- |
| 人 | 人称代词及相关形式 | 同一代词的主格、宾格、物主代词或反身代词 | 指代对象、空格位置、后面是否有名词 | [02-人](考点/02-人.md) |
| 时 | 谓语动词的时态和语态 | 同一动词的不同时态、语态或单复数形式，通常没有 `to do` | 是否缺谓语、主谓一致、时间、主动或被动 | [04-时](考点/04-时.md) |
| 名 | 名词的单复数和所有格 | 单数、复数、`'s`、`s'` 等形式 | 是否表示所属、是否可数、数量信号 | [01-名](考点/01-名.md) |
| 非 | 非谓语动词 | 出现 `to do`，或比较 `to do / doing / done` | 是否已有谓语、固定搭配、主动被动和动作关系 | [08-非](考点/08-非.md) |
| 介 | 介词 | `in / on / of / with / for` 等介词 | 固定搭配、时间空间关系、句意 | [07-介](考点/07-介.md) |
| 连 | 连词 | `and / but / if / because / when` 等 | 前后结构、逻辑关系和句意 | [09-连](考点/09-连.md) |
| 比 | 形容词或副词的比较 | `-er / -est / more / most`，或不同比较等级 | `than`、比较范围、固定结构和句意 | [06-比](考点/06-比.md) |
| 冠 | 冠词 | `a / an / the` | 名词是否可数单数、泛指特指、读音和固定用法 | [03-冠](考点/03-冠.md) |
| 情 | 情态动词 | `can / could / may / must / should` 等 | 说话人的意思、语气、时态和语境 | [10-情](考点/10-情.md) |
| 词 | 词性 | 同词根但后缀不同，如名词、动词、形容词、副词 | 空格在句中的成分，以及修饰关系 | [05-词](考点/05-词.md) |

选项信号只是常见情况，不是绝对规则。例如，`to` 既可能是不定式标志，也可能是介词；`-s` 既可能是名词复数，也可能是动词第三人称单数。

## 教学分层

根据考点规则长度和掌握方式，默认分成三类：

| 类型 | 考点 | 学习特点 | 默认教学重点 |
| --- | --- | --- | --- |
| 快速规则型 | 名、人、冠 | 识别信号较清楚，标准流程较短，多数学生经过示范和少量练习即可入门 | 尽快建立“先认考点、再走流程”的习惯 |
| 系统理解型 | 时、词、比 | 需要句子结构、标志词、上下文或多个判断步骤配合 | 分步讲解、对比练习和变式迁移 |
| 按题补充型 | 介、非、连、情 | 有基本判断流程，部分题目还依赖固定搭配、词义和语境 | 先解决题型流程；真实题目暴露时再最小补充，学生可自行积累 |

这是默认教学分类，不代表每个学生的实际难度。诊断发现某位学生已经掌握或特别薄弱时，应调整顺序和用时。

## 常见错误

- 还没判断考点就直接翻译全文或凭语感选择。
- 只看到一个标志词，不检查句子结构和上下文。
- 把识别选项的口诀当成最终语法规则。
- 答对后不能说明考点和依据，导致换一道题又错。
- 使用兜底答案后不记录，误以为已经掌握。

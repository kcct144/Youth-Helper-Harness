# 选词填空做题流程

- 适用学段：初中为主；高中同类带词框题型可用
- 核心顺序：读说明 → 快看词框 → 略读文章 → 调用熟练模式 → 双向匹配 → 确定词形 → 全文检查
- 方法依据：`考点地图.md`
- 当前版本：0.2
- 更新日期：2026-08-26

## 总流程

```text
读题型说明：变不变形、一词几用、多余几个、每空几词
→ 快看词框：大意、基本词性、明显搭配和可疑生词
→ 略读文章：人物或话题、事件、主要时态和发展方向
→ 双向调用已经熟练的模式，先做证据最明确的空
→ 每空判断所需词性和形式，再从词框缩小候选
→ 依次检查搭配、句子结构和上下文意思
→ 低把握答案标记，不提前永久划掉候选
→ 用剩余词处理较难空
→ 逐空确定正确词形
→ 通读全文，检查语义、词形、使用次数、拼写和大小写
```

## 第一步：读题型说明

在词框上方先圈出规则：

- `use each word once` 或“每词仅用一次”；
- `change the form` 或“用正确形式”；
- `extra words` 或“有若干多余词”；
- `one word for each blank` 或“每空一词”。

规则不同，排除方式和最后检查也不同。不能因为平时练习允许变形，就擅自改变一份要求原词填入的材料。

即使说明要求“正确形式”，也只做有题型依据的变化。不要擅自把词框原词派生成说明和可靠样题均未支持的另一词性。

## 第二步：快速观察词框

第一遍只做轻量标注：

```text
词的大意 + 最常用词性 + 一眼能看出的常见搭配
```

不认识或词性不确定的词标 `?`，不要假装认识，也不要在这一步花很久列完所有可能形式。一个词可能兼具多种词性，暂时只写最可能的入口。

## 第三步：略读文章

在逐空前快速确认：

1. 主要写谁或什么；
2. 发生了什么、作者想说明什么；
3. 叙述的主要时间和人称；
4. 整体态度、转折和发展方向。

这一步只建立背景，不逐句翻译，也不要求马上解出全部空。

## 第四步：先做证据明确的空

不必机械按题号顺序。明显固定搭配、唯一词性位置或语义非常明确的空可以先做，减少词框候选。

这一步先从两个方向快速扫描：

```text
看到空格情况 → 有没有熟练的“这里通常需要什么”模式？
看到词框单词 → 有没有熟练的“这个词通常出现在哪里”模式？
```

能迅速说出触发特征，并且代回句子仍成立的空，优先完成。先稳定拿下几道熟悉题后，词框候选会自然减少，后面逐个代入和排除时的处理压力也会降低。

“熟悉”不等于可以机械填入。只能想起答案却说不出触发情况，或者代回上下文不成立时，仍标为低把握，不能借它继续排除。

使用两种把握标记：

- `✓`：有明确搭配、结构或上下文证据，可以暂时锁定；
- `?`：只是较可能，保留其他候选，不把这个词永久划掉。

后面只能把 `✓` 作为可靠排除条件。不要用一个低把握答案证明另一个答案，避免连续错。

## 第五步：每空执行双向匹配

### 1. 看空格需要什么

截取空格前后的最小有意义结构，回答：

- 空格在句中做什么？
- 大概需要什么词性？
- 可能需要什么形式？
- 有没有明显搭配或标志？

### 2. 回词框找候选

只比较能满足该词性或搭配的少数候选。若一个词有多种词性，把它保留为候选，不要只凭第一次标注排除。

### 3. 按证据选择

推荐检查顺序：

```text
明显搭配
→ 词性和句子结构
→ 当前句意思
→ 必要的前后文和全文方向
```

顺序不是说搭配永远优先于语义，而是先利用最强、处理负担最低的证据。任何候选都要放回上下文验证。

### 4. 再决定词形

原词确定后再问：

- 名词要单数、复数还是所有格？
- 动词作不作谓语，是什么时间，主语是什么，需不需要变第三人称、过去式、`-ing` 或过去分词？
- 形容词或副词是否有 `than / much / the` 等比较信号？
- 代词的人称、格和后面是否有名词是否正确？
- 是否需要句首大写？

只检查当前词真正可能发生的变化，不机械把每项都讲一遍。

## 第六步：处理剩余空格

完成高把握空后，利用剩余词缩小范围，但全局排除只是辅助：

```text
重新看难空的词性和语义
→ 检查剩余候选
→ 必要时回看前面的 ? 答案
→ 找到局部证据后再锁定
```

不能因为“只剩这个词”就跳过语法和语义检查。如果剩余词全部不合适，优先回查最早的 `?`，而不是强塞答案。

## 第七步：全文检查

### 文章与规则

- 从头到尾通读，人物、事件和逻辑是否连贯；
- 每个词的使用次数是否符合题型说明；
- 多余词数量是否正确；
- 每空词数是否符合要求。

### 词形与书写

- 名词：单复数、可数性、所有格；
- 动词：时态、主谓、语态、`-ing / -ed` 等必要形式；
- 形容词和副词：词性及比较等级；
- 代词：形式和指代；
- 所有答案：拼写、大小写。

通顺只是检查之一。答案仍要有词框、结构、搭配和上下文证据。

## 两种起手顺序

学生可以根据当前优势调整，但都不能省略双向匹配：

- **词框先行**：先快速标词性和大意，再找文中匹配位置，适合基本词性较熟的学生；
- **文章先行**：先理解话题和某空大意，再回词框找候选，适合语境理解较强的学生。

默认推荐“快看词框 → 略读文章 → 每空来回核对”，避免只看一边。

## 模式积累与熟练循环

每次完整练习都执行一个小循环：

```text
开局快速调用已经熟练的模式
→ 先完成有明确证据的空
→ 用正常双向匹配处理剩余空
→ 订正时只总结真正有复用价值的新模式
→ 在后续新题中再次主动提取
```

模式记录使用统一骨架：

```text
方向：情况 → 词 / 词 → 情况 / 原词 → 最终词形
触发：看到了什么结构、搭配、词或上下文信号
第一反应：优先判断什么或寻找什么
验证：放回哪里检查
边界：什么时候不能这样套
来源：在哪份可靠材料中出现
```

同一核心模式只记录一次，“情况 → 词”和“词 → 情况”只是指向它的两个检索入口。模式本身的可靠性与学生的熟练度分开判断：单题偶然共现、靠剩余词得到或尚无可靠答案依据的关系只能待验证，不能参加开局快速扫描。

不要求每道题都新增模式，也不追求模式数量。以下内容通常不单独收录：只对当前故事成立的细节、没有可靠答案依据的猜测、已经被更一般模式覆盖的重复说法，以及学生暂时没有前置知识理解的复杂边界。

熟练度按新题中的表现判断：

1. **见过**：接触或听懂过，尚未独立使用；
2. **需提示**：看到提示后能调用；
3. **可快速调用**：在新题中能主动认出并迅速验证；
4. **稳定迁移**：在不同材料或间隔复测中仍能正确调用，并能识别明显反例。

只有“可快速调用”和“稳定迁移”的模式，才能在开局作为可靠的减负工具。见过一次或背过一句话，不等于熟练。

同一模式用 按证据需要安排的无提示同范围新空完成即时验证后，就回到新的完整短文，不继续无限追加孤立题。模式已经稳定时移出当前主攻区，等间隔复测或相关材料出现时再调用。

## 时间安排

对于 10 空左右的成熟训练，维护者提供的参考目标是约 10 分钟：

- 前 1～3 分钟：读说明、快看词框和文章，处理明显搭配或简单空；
- 中段：细看、代入并排除剩余候选；
- 最后 1～2 分钟：通读和检查。

这是熟练后的参考分配，不是初学完成门槛，也不自动适用于所有学段、篇幅和考试。先保证流程能独立执行，再与学生自己的同难度基线比较速度。

## 错误诊断顺序

```text
题型说明读清了吗？
→ 词框中的关键候选认识吗？
→ 快看词框时判断了基本词性吗？
→ 说得出空格需要什么词性或形式吗？
→ 找到搭配、结构或上下文证据了吗？
→ 选对原词后改对形式了吗？
→ 是否把 ? 当成确定答案造成连续错？
→ 最后是否通读并检查规则、词形和大小写？
```

停在第一个真实断点。学生只是漏了复数时，不重新讲完整个词性体系；多个空因第一个低把握答案被错误划掉时，合并为一个全局排除问题。

## 报告驱动的结束条件

只处理报告实际暴露的问题。学生能在 按证据需要安排的同范围新空中独立执行刚补的步骤后，本轮即可结束，并回到新的完整选词填空中检验。不因看到一个动词变形错误就自动讲完所有时态、语态和非谓语。

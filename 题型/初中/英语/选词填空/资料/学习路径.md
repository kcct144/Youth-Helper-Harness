# 选词填空学习路径

- 适用学段：初中为主；高中同类带词框题型可按需使用
- 核心路线：读懂规则与词框 → 判断空格需求 → 双向匹配 → 沉淀并熟练调用模式 → 正确变形 → 整篇迁移
- 默认方式：报告驱动的查缺 → 最小补漏 → 回到新材料检验

## 报告优先

学生提交做题报告、原文或错题时，先按证据定位：

```text
题型规则是否读清
→ 词框词汇是否足够
→ 能否观察词框的词性和搭配
→ 能否判断空格需要什么
→ 能否用搭配、词性和意思锁定原词
→ 能否快速调用已经学过的双向模式
→ 能否改成正确形式
→ 能否做全局和全文检查
```

只补第一个真实断点。报告只暴露名词复数时，不安排整套词性课；报告没出现的能力保持未评估。

## L0：题型规则与词汇门槛

本级只解决：

- 从说明中找出能否变形、一词几用、多余词数量和每空词数；
- 说出词框中大部分关键候选的核心意思；
- 发现材料词汇明显不匹配时主动降难度。

默认停止点：学生不再因误读说明而丢分，并具备比较词框候选的基本词汇条件。

## L1：快速观察词框

本级只训练：

- 给熟悉词标最常用的名词、动词、形容词、副词等基本词性；
- 识别少量明显搭配；
- 从熟悉词出发，说出它通常可寻找的结构、搭配或语义位置；
- 不确定和一词多性的词标 `?`，不假装只有一种用法。

暂不要求列出所有后缀、词形转换、冷僻词义和搭配。默认停止点：学生能快速把词框分成几个基本候选组，而不是每做一空都重新搜索全部词。

## L2：观察空格需要什么

从最常见结构开始，逐步判断空格需要：

- 名词还是动作；
- 形容词还是副词；
- 谓语动词还是其他形式；
- 介词、连词、代词或限定词等明显功能词。

本级开始形成“看到这种空格，优先想什么词性或哪类词”的情况 → 词模式，但每条都必须保留代入验证。

先使用学生已学过、结构清楚的 `a/the`、形容词、介词、主语、情态动词、`to`、`be` 等常见信号。遇到一词多性或 `to / be` 等歧义时可以标为后续边界，不在本级一次讲完。

默认停止点：学生能截取空格附近的小结构，给出一个合理词性需求，并从词框缩小到少量候选。

## L3：搭配、词性和意思双向匹配

训练顺序：

```text
空格需求
→ 词框候选
→ 搭配和结构
→ 当前句意思
→ 必要上下文
```

学生要能说出最后锁定答案的是搭配、词性结构还是上下文意思。默认停止点：在不需要复杂变形的基础材料中，能独立选择原词并说明证据。

## 贯穿各级：模式沉淀与熟练化

模式积累不是额外背一整本规则，而是把真实题目中已经验证过的有效判断变成更快的第一反应。

每次只处理本轮真正出现的关系：

```text
订正一道题
→ 分清它属于“情况 → 词”“词 → 情况”还是“原词 → 最终词形”
→ 写清触发、第一反应、验证和边界
→ 后续新题先尝试主动调用
→ 根据表现从见过、需提示、可快速调用升级到稳定迁移
```

训练时先让学生快速浏览词框和空格，尝试用已熟练模式完成几道高把握题。若能做到，剩余候选变少，后续代入、排除和上下文判断的负担也会下降。不能为了追求开局速度，把低把握答案伪装成已熟练模式。

模式可靠性和学生熟练度必须分开：只有可靠规则或多个独立实例支持，模式本身才可以进入正式训练；单题偶然共现和只靠剩余词得出的关系先待验证。以下情况不升级熟练度：老师刚提示就答对、只在原题复述、只靠最后一个剩余词猜中，或说不出触发与验证依据。

同一模式完成 按证据需要安排的无提示同范围新空后就停止孤立训练，回到新的完整短文。已经稳定的模式移出当前主攻区，只保留间隔复测入口，避免模式表本身成为新的背诵负担。

## L4：按报告补词形变化

词形变化拆成小单元，按真实题目逐个补：

1. 规则名词单复数；
2. 一般现在、一般过去、一般将来等已学基本动词形式；
3. 常见 `-ing / -ed` 形式，只在题目和前置知识需要时启用；
4. 形容词、副词和比较等级；
5. 代词形式、所有格、拼写与大小写。

学生在哪个小单元出错，就只补那个单元。基本时态未稳定时，不因词框里有动词就自动讲被动、完成时和全部非谓语。

默认停止点：学生选中原词后，能对当前已学范围执行一次独立词形检查。

## L5：整篇、排除与时间迁移

在词汇难度匹配的新短文中检查学生能否：

1. 略读话题、人物、时间和发展方向；
2. 先完成高把握空，并区分 `✓` 与 `?`；
3. 主动调用已熟练的双向模式，并只用高把握答案缩小词框；
4. 发现剩余词不合适时回查最早的低把握答案；
5. 通读全文并检查词形、使用次数、多余词、拼写和大小写；
6. 在不牺牲证据和正确率的前提下，逐步接近个人时间目标。

默认停止点：学生能在完整新材料中独立执行全流程并说明关键证据。达到“稳定”还需要不同话题、混合变形或间隔复测中的持续表现。

## L6：一词多性与结构边界

只有真实题目或反复报告需要时，才处理：

- 一个词可作多种词性；
- `to` 是不定式标志还是介词；
- `be + 空格` 表示状态、身份、进行还是被动；
- 情态动词后已有动词时，空格是否为副词；
- 题型是否允许词性派生和较复杂变形。

本级不属于所有学生必学主线。默认停止点：学生能对当前真实边界题说明为什么基础信号不够、还需要检查哪一项；不要求背完所有例外。

## 常见分流

- 词框关键词不认识：词汇补漏或降低材料难度；
- 知道词义但不会标基本词性：回到 L1；
- 词框会分类，但看不出空格需要什么：回到 L2；
- 词性匹配但意思经常不通：补 L3 的语境验证；
- 原词选对但形式错误：只补 L4 对应小单元；
- 前面一个低把握答案导致后面连续错：补 L5 的把握标记和回溯；
- 会做但来不及：确认 L0～L5 流程已独立后，再做个人基线上的时间训练。
- 学过很多思路但开局想不起来：不新增知识，回到个人模式库做“触发 → 第一反应”的提取练习；
- 基础信号无法唯一判断、一词多性反复出现：按需进入 L6，不提前扩展。

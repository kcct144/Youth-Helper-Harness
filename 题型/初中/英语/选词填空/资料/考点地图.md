# 选词填空考点与证据地图

- 适用学段：初中为主；高中出现带词框的短文填空时同样适用
- 内容类型：题型方法 / 基础词汇与语法综合
- 常见名称：选词填空、方框选词、短文填空；是否允许变形以题型说明为准
- 核心任务：从词框选择合适的词，并在题目允许或要求时使用正确形式，使文章结构完整、意思连贯
- 核心意识：同时观察“词框里的词能做什么”和“空格需要什么”，并把反复有效的关系练成可以快速调用的双向模式

## 先确认题型规则

不同试卷的规则可能不同。正式作答前先从题型说明确认：

- 每个词是否只能使用一次；
- 是否有多余词以及有几个；
- 是否允许或要求改变词形；
- 每空是否限填一词；
- 答案是否需要写完整单词而不是序号。

不能把某一地区的规则自动套到所有选词填空。项目中的 `资料/题型示例/广东中考-短文填空.md` 明确要求“每空一词、每词仅用一次、有两词多余、使用正确形式”，但其他材料仍要重新读说明。

## 核心模型：两边观察，交叉匹配

```text
观察词框：词义、词性、常见搭配、可能的词形
                    ↘
                     找到交集 → 代入上下文 → 确定正确形式
                    ↗
观察空格：句子位置、所需词性、搭配、意思、形式信号
```

只看中文意思容易忽略语法，只看词性又可能留下多个候选。最终答案通常要同时满足：

1. 搭配或句子结构成立；
2. 词性符合空格作用；
3. 放入上下文后意思连贯；
4. 词形符合数量、时间、主谓、比较等要求；
5. 不违反“一词一次、多余词”等全局规则。

订正时必须把两个结论分开：

```text
第一问：词框里应该选哪个原词？
第二问：这个原词在当前空格要写成什么形式？
```

原词选对但形式写错，属于词形变化断点，不应笼统归为不会选词；形式碰巧正确但原词选择没有证据，也不算掌握。

## 双向模式：把判断练成第一反应

学生做过的题不能只留下答案，还要逐步沉淀两类可复用模式：

- **情况 → 词**：看到空格附近的结构、搭配或意思，优先想到需要什么词性、哪类词或哪个常见搭配；
- **词 → 情况**：看到词框中的某个词，优先想到它常见的词性、搭配、语义关系和可能出现的位置。

例如，“介词后面的空格”会先触发名词、代词或动名词候选；看到一个表示原因的连词，会主动寻找前后能形成因果关系的分句。第一反应只负责缩小范围，不能代替代入验证。

一条可学习的模式至少包含：

```text
触发情况 → 优先判断或候选 → 必须怎样验证 → 哪些边界不能机械套用
```

模式不是“这道题出现这个词，所以以后都填它”的答案表。只有符合可靠规则、常见搭配，或能在多道独立题中重复解释的关系，才值得作为通用模式；只解释一道题的具体语义仍留在该题解析中。靠“最后只剩这个词”得到的答案只能作为待验证案例，不能反推通用搭配。

必须分开判断“这条模式是否可靠”和“学生是否熟练”。可靠模式也可能是学生刚见过；学生碰巧答对，也不能证明模式可靠。模式的掌握标准不是“见过”或“背过”：学生要能在新题中主动认出触发情况、快速调用，并在放回句子或上下文后仍然成立，才算真正熟练。

## 词汇门槛

开始做题前，让学生标出词框中不认识、只眼熟但说不清核心意思、或不知道基本词性的词。

- 少量生词且能靠其他候选和上下文排除：可以继续方法训练，作答后补词义；
- 多个关键候选都不认识，无法进行真实比较：先归为词汇障碍，不把错误主要解释为不会技巧；
- 词框和正文整体明显超过学生水平：换难度合适的材料。

不设适用于所有词框长度的固定生词数量。关键是未知词是否让学生失去比较候选的能力。

## 观察词框：词性 → 可填位置

快速给认识的词标注最常用词性和大意，不要求第一遍列出所有词义、词形和搭配。

| 词性 | 常见作用或位置 | 需要继续检查 |
| --- | --- | --- |
| 名词 | 主语、宾语、表语；限定词、形容词或介词后 | 可数性、单复数、所有格和具体词义 |
| 动词 | 谓语；也可能在 `to`、情态动词或其他结构后 | 时态、主谓、语态及非谓语形式 |
| 形容词 | 名词前；`be` 或常见系动词后 | 是否真正修饰名词或说明主语状态 |
| 副词 | 修饰动词、形容词、副词或整个句子 | 位置、程度、逻辑和具体词义 |
| 介词 | 通常引出名词、代词或动名词短语 | 固定搭配和时间、空间、关系意义 |
| 连词 | 连接词、短语、分句或句子 | 前后结构是否对等、逻辑关系是什么 |
| 代词或限定词 | 指代人或物，或限定后面的名词 | 指代对象、人称、数、格以及后面是否有名词 |
| 情态动词 | 位于主语后、动词原形前 | 语气和上下文意思 |

一个词可能有多种词性，例如 `well`、`fast`、`hard`。词框标注只是候选入口，不是最终答案；不要看到熟悉词尾就锁死词性。

## 观察空格：情况 → 所需词性

先看空格前后的小结构，再根据需要扩大到完整句和上下文。

| 空格附近的情况 | 常见需求 | 不能机械套用的边界 |
| --- | --- | --- |
| `a / an / the / 限定词 + ____` | 名词，或形容词后面还有名词 | 必须继续看空格后是否已有名词 |
| `形容词 + ____` | 常见为名词 | 也要确认是不是固定结构或并列成分 |
| `介词 + ____` | 名词、代词或动名词 | 先确认前面的词确实是介词 |
| `主语 + ____` | 常见为谓语动词 | 还要检查句中是否已经有谓语核心 |
| `情态动词 + ____` | 空格直接承担后续动词时通常是动词原形 | 若后面已经有主要动词，空格也可能是修饰它的副词 |
| `to + ____` | 常见为动词原形 | `to` 也可能是介词，此时可接名词或动名词 |
| `be + ____` | 形容词、名词、现在分词或过去分词等 | 需要结合主语、结构和意思判断，不能只看 `be` |
| `常见系动词 + ____` | 常见为形容词 | 也可能接名词短语表示身份；只按学生已学结构和真实题目判断 |
| `very / so / too + ____` | 形容词或副词 | 看它说明状态还是修饰动作、形容词或副词 |
| `____ + 名词` | 常见为形容词、限定词，也可能是名词修饰名词 | 继续检查词义和固定表达 |
| `完整分句 + ____ + 完整分句` | 连词或起连接作用的表达 | 检查标点、前后结构以及并列、转折、因果等逻辑 |

这些结构用于缩小候选，不是无例外公式。结构判断后还必须代入意思和全文。

## 每空的主要证据

选词填空中的“考点”可以理解为：这一空主要靠哪类证据锁定。学生至少要能指出决定答案的主要证据。

| 证据标签 | 典型问题 | 处理方式 |
| --- | --- | --- |
| 搭配 | 哪个词能与空格前后形成常见组合？ | 先检查搭配，再回到上下文验证 |
| 词性与结构 | 这里需要名词、动词、形容词、副词还是其他词？ | 看句子位置和修饰关系，缩小词框候选 |
| 意思与上下文 | 多个候选词性都合适，哪个符合人物、事件和逻辑？ | 读完整句及必要前后文，不只翻译空格附近 |
| 词形变化 | 已经选中哪个原词，它在这里应该变成什么形式？ | 单独检查数量、时间、主谓、比较等信号 |
| 全局约束 | 这个词是否已使用、剩余词数是否符合说明？ | 只用来验证和排错，不替代局部证据 |

同一空可能同时使用多类证据，但反馈时指出最后锁定答案的关键依据，不能只说“感觉这个最顺”。

## 词形变化检查

先确定选哪个词，再确定写成什么形式。不要在原词尚未锁定时同时猜多个复杂变形。

| 选中词的类型 | 最低限度检查 |
| --- | --- |
| 名词 | 单数或复数、可数或不可数、是否需要所有格 |
| 动词 | 是否作谓语、主语人称和数、时间与上下文、主动或被动；必要时再看 `to do / doing / done` |
| 形容词或副词 | 原级、比较级或最高级；是否需要在形容词和副词间转换由题型规则决定 |
| 代词 | 指代对象、人称、单复数、主格或宾格、后面是否有名词 |
| 所有答案 | 拼写、大小写以及是否符合“每空一词” |

词形教学按真实报告逐项补。学生只错名词复数时，不顺带讲完被动语态、非谓语和全部词性转换。

题型说明写“使用正确形式”也不自动等于允许任意词性派生。名词复数、动词时态、比较级等屈折变化通常较明确；是否允许把一个词派生成另一词性，要依据当前考试说明和可靠实例，不能由 AI 自由创造远亲词形。

## 常见误区

- 没读题型说明，不知道能否变形、每词能用几次或有几个多余词。
- 词框完全不看，读到一个空就来回搜索所有词。
- 逐句翻译整篇后才敢开始填，增加负担却没有利用词框和空格结构。
- 只按中文意思选词，不判断空格需要什么词性。
- 只靠词尾或位置判断，不把答案放回上下文。
- 选对原词却直接抄词框形式，漏掉复数、过去式、第三人称单数或比较级。
- 看到 `to` 就一律填动词原形，看到 `be` 就一律填形容词。
- 过早划掉低把握词，前面一错导致后面连续错。
- 最后只看有没有用完词，不通读文章、不检查形式和大小写。

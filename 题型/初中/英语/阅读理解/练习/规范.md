# 统一题库规范 v1

根目录 `题库/` 是题目唯一维护源，按知识内容分目录，每道独立题一个 Markdown 文件。文件名等于永久 id；同一素材改成另一种作答形式时使用新 id，通过关联题组连接。学生状态与历史只写在对应工作区的进度、学情和学习记录中，题库不保存学生个人数据。

管理工具扫描所有非隐藏、非下划线开头的内容子目录（当前有 `语法/`、`阅读理解/`）；这些目录下的 Markdown 均须为题目文件。规范、校验报告等说明放根目录或仓库维护目录。阅读理解的局部短题仍沿用单题格式，题目中保留足以判断答案的上下文；填空作答不改变其适用题型。给定节选的正确作答不能证明整篇定位能力。

## 元数据

文件以 YAML frontmatter 开始。必填字段如下，列表即使只有一项也用列表格式：

```yaml
schema: enpractice-question/v1
id: GR-PRON-001
适用题型: [语法选择, 语法填空]
作答形式: 单项选择
考点: 人称代词
范围: 主格、宾格、形容词性物主代词
目标: 概念理解
台阶: L1
用途: [查缺, 补漏, 强化]
前置: [理解简单句句意]
初始难度: 基础
难度依据: 短句，单一目标，关系明确
来源: 自编
状态: 已校验
校验说明: 已人工或 AI 检查答案、歧义、范围和干扰项；尚未经学生实测
版本: 1
关联题组: PRON-基础-001
```

- `作答形式`：单项选择 / 填空。其他形式日后显式扩展规范，不能临时改变章节结构。
- `目标`：概念理解 / 形式回忆 / 考点识别 / 流程运用。强化是用途，不是另一种能力目标。
- `初始难度`：基础 / 常规 / 进阶。分别表示线索明确的单一判断、同范围内结构或语境判断、同范围内更复杂的多步判断。不得用后续台阶、冷僻词或例外制造难度。
- `状态`：待校验 / 已校验 / 停用。只有已校验题进入默认索引和分发；格式检查不等于内容正确，内容校验需要另做并注明依据。
- `台阶` 必须结合考点与范围理解，不能跨考点比较同名 L1；学会某组形式不等于全表掌握。
- `关联题组` 为可选字段；同素材、答案高度相似或彼此泄题的题必须关联。见过组内一题后，另一题不能作为完全未见材料的迁移证据。
- `材料形式` 为可选字段。普通单题省略；整篇填空写 `材料形式: 篇章`，仍使用同一 schema、一篇一个 Markdown，不把文章拆成失去上下文的单题。
- 篇章必须增加 `逐空考点` 数组，每项依次写 `题号`（整数）、`提示词情况`、`空格作用`、`考点`、`范围`。编号必须覆盖正文全部空且从 1 连续、无重复；字段不得留空。只填写已经逐空核验的结论，不能把来源标签或机器猜测当成核验。示例：

  ```yaml
  材料形式: 篇章
  逐空考点:
    - 题号: 1
      提示词情况: 给出动词 write
      空格作用: 谓语
      考点: 时态
      范围: 一般过去时
  ```

- 篇章顶部的 `考点`、`范围` 和 `台阶` 只作整篇检索摘要；不得把多空篇章视为一个单一考点的 L 级题，`台阶` 不得写成单独的 `L1`、`L2` 等。逐空教学判断以 `逐空考点` 为准。篇章 `初始难度` 是整篇作答的参考，不代表每一空难度相同。
- `适用题型` 表示可服务该题型的学习，不表示模拟整篇考试。选择题用于语法填空补漏时，仍只产生选择作答证据。
- id 永久不变；答案、题干或判分实质修订时增加版本，改变学习目标或作答形式则新建 id。引用来源不能伪称真题，自编示例不能写成官方题。题目附带的来源、年份、地区或考试名称只是来源标签；未经官方原文核验，不得据此声称“官方真题”或“官方答案”。

## 正文

严格按下面顺序使用二级标题，无额外一级题名，避免把考点泄露给学生：

单项选择：`题目 → 选项 → 答案 → 解析 → 判分说明`。
填空：`题目 → 答案 → 解析 → 判分说明`，不得附选项章节。

- 题目中的每个空统一写为 `\_\_\_\_`（源文件中每个下划线前只有一个反斜杠）。多空写 `（1）\_\_\_\_`、`（2）\_\_\_\_`，从 1 连续编号。
- 篇章原文、标题、提示词和空格必须完整保存在同一题目的“题目”章节。原材料规定了作答字数或词数时原样保留，不得在整理时放宽、缩紧或省略。
- 无需挖空的概念题可直接提问。填空题必须说明任务，如填写所给词的形式或指定代词形式；语境不足时不能强行只认一个答案。
- 选择题选项每行 `- A: 内容`，至少两项，字母从 A 连续排列；无备注、提示、对错标记。答案章节只写一个正确选项字母。
- 填空答案每空一行 `- 1: 答案`；多种可接受形式用 ` / ` 分隔。判分说明明确空格、大小写及合理变体的处理；逐空记录，不能丢失部分正确的信息。
- 解析写出关键依据，不扩展未学知识。判分说明用于教师或 AI，提交前不展示。
- 作答前只展示题目和选项，不展示 frontmatter、文件标题、答案、解析或判分说明。答案同文件是维护便利，不是技术上的防泄题措施。
- 篇章也严格沿用 `题目 → 答案 → 解析 → 判分说明`，不另设会暴露答案、考点或提示的章节；逐空考点只在 frontmatter 中维护，作答前不展示。

共享文章但包含不同作答形式的多小题题组仍属尚未定义的题组格式；整篇语法填空则按上述篇章扩展保存，不拆分上下文。

## 使用与维护

先按当前缺口、前置、考点范围和台阶选题，再选作答形式及难度。索引仅用于选题，正文按需读取。不得为了刷完索引而自动扩展学生学习范围。

学习记录保存 id、版本、作答结果、是否提示、首次或重做，进度或学情引用该证据；篇章还需记录空号。统计不同来源和形式分别进行。单纯填对不能直接证明学生会分析句子或识别考点，仍须依据实际作答过程判断。停用旧题不删除学生历史。题目耗尽时允许同范围自编并明确来源，不冒充预设题。

从本库练习时，来源记为“预设题库”并附题目 ID，不冒充真实作业报告或 AI 自编题。已在补漏中展示过的同篇材料，不能再记为未见材料迁移；整篇答对也不自动把全部相关能力改成稳定。

工具依赖 Python 3 和 PyYAML。维护者在仓库根目录运行：

```powershell
python -X utf8 题库/管理.py check
python -X utf8 题库/管理.py index
python -X utf8 题库/管理.py export --type 语法选择
```

`check` 只检查格式和引用约束；`index` 生成根题库索引；`export` 筛选已校验且适用的题，生成 `题型工作区/<题型>/练习/` 的分发副本和索引。导出只写练习目录，不修改学生进度。历史残留文件不自动删除，导出索引是本次可用题目的唯一清单，停用或移出适用范围的旧文件不得继续选用。

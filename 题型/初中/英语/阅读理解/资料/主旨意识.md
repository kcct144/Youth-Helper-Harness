# 阅读理解主旨意识

- 适用学段：初中、高中
- 内容类型：基础阅读方法
- 使用时机：学生首次完成一篇阅读时建立轻量主旨草图；学生只会局部定位、连续错或主旨与标题题不稳定时重点训练
- 核心目标：知道全文在围绕什么重点展开，并让局部答案服从原文主线

主旨意识不等于只会做主旨题。它是阅读所有题目的地图：先知道文章主要在讲什么，之后才知道某个细节属于谁、某句话为什么出现、推理能走到哪里。

学生如果必须把每句变成完整中文后才能概括主旨，说明他还没有形成高效的分层阅读方式。先按 `分层阅读与翻译边界.md` 区分词汇、句子结构和翻译依赖，再训练主旨；不要把“不逐句翻译”误解为完全不能使用中文概括。

## 作答前的主旨草图

略读后用一句话完成：

```text
这篇文章主要介绍 / 讲述 / 讨论 ______，重点说明 ______。
```

学生只需给出暂定答案，后面可以修正。主旨不是一个孤立名词，例如只说“trees”通常过宽；还要说明作者围绕树主要谈什么。

## 三类文章的最小框架

### 应用类材料

```text
这是什么材料？
→ 写给谁？
→ 主要让读者获得信息还是采取行动？
→ 信息按哪些栏目组织？
```

先看图片、标题、小标题、表格和栏目，不按普通记叙文逐行阅读。

### 记叙文

```text
主要人物
→ 起因或目标
→ 关键变化
→ 结果
→ 作者最终想突出什么
```

主旨通常不是某一个动作，而是人物经历和变化共同表达的重点。

### 说明或议论类文章

```text
说明或讨论对象
→ 核心问题或观点
→ 原因、影响、例子或解决办法
→ 结论或作者态度
```

## 高价值主旨线索

按文章实际情况观察，不机械要求全部出现：

- 标题、小标题、图片和整体版式；
- 开头提出的对象、问题或观点；
- 结尾的结论、变化或态度；
- 每段承担的功能；
- 反复出现或换词复现的实词；
- 转折之后、总结表达附近的信息；
- 例子共同在说明什么，而不是例子本身的细节。

## 段落功能草图

为每段写一个短标签，不逐句翻译：

```text
P1 提出问题
P2 第一种做法
P3 另一种做法
P4 成功原因和总结
```

然后问：这些段落共同服务什么中心？如果一个候选主旨只覆盖其中一段，它通常过窄；如果加入了各段都没讨论的大概念，它通常过宽。

## 主旨如何帮助其他题型

- **细节题**：先判断该信息属于哪一段，减少全篇乱找。
- **推理题**：限制推理方向，避免用常识推得太远。
- **词义题**：帮助判断词语在当前话题中的具体含义。
- **指代题**：帮助确认当前句延续的是哪个人物或概念。
- **结构题**：解释为什么作者先写这一段、再写下一段。
- **干扰项排除**：识别与全文重点冲突、过宽或过窄的选项。

## 主旨意识微训练

根据报告一次只选一种：

- **只看文章不做题**：用一句话完成主旨草图；
- **段落贴标签**：每段用几个字概括功能；
- **删细节**：从多个信息中留下能代表全文的内容；
- **宽窄对比**：判断两个概括哪个过宽、哪个过窄；
- **细节归位**：说明一道细节题属于文章哪一部分；
- **标题验证**：检查标题能否覆盖大多数段落。

## 连续错诊断

词汇和题干基本读懂但连续错时，先问：

1. 学生认为全文主要讲什么？
2. 各段分别在做什么？
3. 每道错题定位到了哪一段？
4. 学生是否只因选项出现原词就选择？

如果重新建立主旨和段落功能后多题同时解决，记录一个“主旨或篇章意识”问题，不把它拆成多个独立题型缺口。

## 掌握证据

- 能在略读后给出“对象 + 重点”的主旨草图；
- 能用短标签说明主要段落的功能；
- 能根据主旨预测某道题大概属于哪一段；
- 能识别局部细节、过宽概括和无中生有；
- 能在新文章中主动先建立主旨，再进入题目。

## 绝对不要

- 不把全文逐句翻译当作建立主旨；
- 不把“第一句就是中心句”当成普遍规则；
- 不只说一个话题名词而没有作者重点；
- 不因例子生动就把例子当全文主旨；
- 不用常识覆盖原文表达；
- 学生首次做整篇阅读或出现连续错、证据归属混乱时，不为了省时跳过主旨定位；若现成报告已提供完整定位和依据，并明确只是一个单句可定的局部断点，可直接补该断点，不能机械重做全文主旨诊断。

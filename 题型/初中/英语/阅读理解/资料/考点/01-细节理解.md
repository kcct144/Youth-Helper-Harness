# 阅读理解题型：细节理解

- 题型范围：原文明确提供的人物、时间、地点、原因、方式、结果和事实
- 核心阅读方式：scanning 定位 + 证据精读
- 默认目标：能用“定位词 → 原文证据 → 同义对应”作答

## 常见问法

`who / when / where / why / how / which / according to` 等明确询问信息的问题。

## 标准流程

```text
明确题干到底问什么
→ 划出少见且稳定的定位词
→ 预测可能的同义替换
→ 扫读找到证据区
→ 阅读定位句及必要前后句
→ 用自己的话说出答案
→ 核对四个选项
```

## 常见干扰项

- 张冠李戴；
- 原文未提；
- 信息正确但答非所问；
- 只说对一半；
- 偷换时间、范围、程度或肯否；
- 复现原词但改变原文关系。

## 边界

- “答案在原文”不代表一定原词重现，同义替换很常见。
- 找到关键词后不能立刻选，要读周围文本。
- 题目顺序与文章顺序接近只是弱提示。
- 高中题若定位正确但选项通过多句压缩、范围或语气变化改写，按 `../高中扩展.md` 的“复杂同义改写与范围、语气”处理；不要把它误判为新的细节题型。

## 完成证据

学生能指出题干定位词、原文证据位置及选项与原文的对应关系，而不是只报答案。

# 阅读理解题型：词义猜测

- 题型范围：划线单词、短语或句子在当前语境中的意思
- 核心方法：把四个选项分别替换划线词，放回它所在的短语，看哪个合适（代入法）
- 入门目标：先练短语代入即可确定答案的简单情况；不够用的复杂情况在后续关逐步练

## 常见线索

| 线索 | 常见信号 |
| --- | --- |
| 定义或解释 | `is / means / refers to / that is / in other words` |
| 举例 | `for example / such as / like` |
| 同义或补充 | `and / or / also / too`，以及换词复现 |
| 反义或转折 | `but / however / although / unlike` |
| 因果和结果 | 前后行为、原因或结果能够限制词义 |
| 构词信息 | 前缀、后缀、词根和词性 |

## 标准流程

```text
看清划线的是哪个词、它在哪个短语里
→ 把 A/B/C/D 分别替换掉划线单词，放回这个短语
→ 看哪个搭配和语义最合适（简单情况到这里即可）
→ 短语不够用时，才读整句、前后句或当前段
```

入门时可以把词义猜测当作一个小完形填空：在目标词的位置上逐个比较四个选项，看哪个在搭配和意思上合适。

## 教学台阶

先练短语代入，再练所在句的明显线索，随后练前后句，最后按需结合段落。具体关卡见 `../../练习模式/README.md` 的 Unit 05。前一层能解决当前题时就停，不要求为了“完整流程”读遍所有范围。

## 边界

- 构词法是辅助，清楚的上下文证据优先。
- 题目问的是当前语境义，不一定是学生最熟悉的词典义。
- 短语代入能确定答案时无需扩大；多个选项仍合理或都不通时，再读整句、前后句或当前段。这些复杂情况放在后续关练，不提前堆进入门讲解。
- 四个选项逐一放回同一短语比较，而不是挑一个自己最熟的词。

## 完成证据

简单情况看学生能否代入短语完成判断；复杂情况再看能否使用本关训练的所在句、前后句或段落线索。答对简单情况不能直接推断复杂情况也掌握；具体练习与判分随逐关出题确定。

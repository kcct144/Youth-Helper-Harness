# 阅读理解题型：标题归纳

- 题型范围：为整篇文章选择最合适的标题
- 核心方法：主旨准确性优先，再检查简洁性和文体
- 前置资料：`../主旨意识.md`

## 常见问法

- `What / Which is the best title for the passage?`

## 标准流程

```text
先独立说出全文主旨
→ 提取核心对象和作者重点
→ 检查标题是否覆盖主要段落
→ 检查是否符合文章文体和态度
→ 排除细节标题、过宽标题和无中生有
```

## 好标题的顺序

1. 准确；
2. 能覆盖全文；
3. 简洁清楚；
4. 在准确的前提下可以有吸引力。

## 边界

- 不硬性规定标题必须是 3～5 个词，选项题以准确概括原文为准。
- 最生动的选项不一定最好；一个醒目的例子也不一定代表全文。
- 标题题与主旨题相关，但还要考虑标题表达是否自然、凝练。

## 完成证据

学生能先说主旨再选标题，并用主要段落逐一验证覆盖范围。

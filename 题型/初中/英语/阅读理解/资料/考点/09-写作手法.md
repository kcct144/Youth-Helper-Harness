# 阅读理解题型：写作手法与作用

- 题型范围：作者怎样组织或呈现信息，以及这样写在局部起什么作用
- 考试范围：按学生所在地区和卷型启用
- 核心方法：识别文本信号 → 说明局部作用（全文目的见 `04-主旨大意.md`）

## 常见手法

| 手法 | 常见信号或表现 |
| --- | --- |
| 举例 | `for example / such as / like`，具体案例 |
| 对比 | `but / while / compared with`，两个对象并置 |
| 因果 | `because / so / as a result`，原因与结果 |
| 问题—解决 | 提出困难，再给办法或结果 |
| 顺序 | `first / then / next / finally` |
| 列数字 | 数量、比例、时间或实验结果 |
| 描述 | 特征、场景、动作和感受 |

## 标准流程

```text
确认题干问“手法”还是“局部作用”
→ 定位目标段或句
→ 找具体文本信号
→ 说清作者怎样写
→ 再说明它帮助解释、证明、对比或突出什么
```

## 手法与作用

- **写作手法**：作者怎么写；
- **局部作用**：这一写法让哪一点更具体、清楚或有说服力。

全文目的（作者为什么写整篇文章、希望读者理解或采取什么行动）属主旨大意题型，见 `04-主旨大意.md`，本文件不重复。

## 边界

- 出现数字不等于数字本身就是答案，还要说明数字证明什么。
- 出现例子时要回到例子支持的观点。
- 不根据文体常识猜手法，必须指出原文信号。
- 高中题问测量、实验设计、引语或段落为什么出现时，使用 `../高中扩展.md` 的“写作目的与段落作用”；先区分内容、局部作用和全文目的（全文目的见 `04-主旨大意.md`）。

## 完成证据

学生能指出文本中的具体信号，并分别回答“怎么写”和“在局部起什么作用”。

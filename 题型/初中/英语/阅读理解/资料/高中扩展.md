# 高中常规阅读理解扩展层

- 适用学段：高中
- 适用题型：常规 A—D 篇四选一阅读，即“一篇文章 + 每小题各自独立的 A、B、C、D 选项”
- 内容类型：题型方法 / 高中按需扩展
- 前置资料：`考点地图.md`、`做题流程.md`、`主旨意识.md`
- 核心目标：在基础流程之上，处理复杂同义改写、多声部立场、因果边界、研究或议论结构、跨句跨段证据以及目的与作用题
- 启用原则：按真实题目或做题报告暴露的第一个断点启用，不作为每篇高中阅读的固定加长流程

本文件不推翻已有的“略读建图 → 识别题型 → 扫读定位 → 证据精读 → 选项核对”。高中题的主要变化，是证据可能被压缩、拆散或换一种关系表达，文章中也可能同时出现多个人的观点。只有基础流程不足以唯一判断时，才调用本文件中的相应扩展动作。

## 题型边界：明确排除七选五

七选五使用全文共享选项池，存在多余项、跨空排除和整组回查；它的任务形式与“每道题拥有独立四个选项”的常规阅读不同。

- 本文件只处理常规 A—D 篇四选一阅读；
- 七选五不归入本文件所说的阅读理解体系；
- 即使七选五也会使用指代、复现和逻辑衔接，也不能因此把它并入常规阅读的考点、流程或能力评价；
- 不用 `考点/08-句子还原.md` 代替完整的七选五体系。

## 什么时候启用扩展层

先定位第一个断点。若基础流程已经能稳定完成当前题，就停在基础流程。

同时出现多个扩展信号时，只启用一个模块。优先处理让其他证据无法归属或无法理解的前置断点，例如先分清“谁的观点”，再判断该观点中的因果和语气；若不存在依赖关系，选择学生原始思路最完整、证据范围最窄的一题。其他信号只保留为待核验，不在同一轮顺带讲完。

| 真实表现或文本信号 | 优先启用的扩展模块 | 暂时不要做什么 |
| --- | --- | --- |
| 定位正确，却因选项没有原词而无法对应 | 复杂同义改写 | 不把“没看到同一个词”当成无中生有 |
| 原文与选项看似都对，但范围、程度或语气不同 | 范围与语气核对 | 不靠“哪个更像原句”选择 |
| 文中有研究者、受访者、机构或多组人物发言 | 作者与被引人物立场 | 不把所有引语合成一个“作者观点” |
| 选项把相关、影响、原因、条件或结果重新组合 | 相关与因果 | 不用常识补完整因果链 |
| 出现实验组、对照组、测量、数据、替代解释 | 研究类篇章结构 | 不逐个数字孤立作答 |
| 出现观点、理由、让步、反驳、权衡或建议 | 议论类篇章结构 | 不只抓最后一句当全文立场 |
| 单句不能决定答案，证据分散在前后句或不同段落 | 跨句跨段多证据 | 不无限扩大到全文，也不只守着关键词句 |
| 题干问 `why mention / why measure / purpose / role / function` | 目的与段落作用 | 不把该句或该段的内容复述一遍就当作用 |

以下情况不靠扩展技巧硬做：

- 题干、选项或证据句中的关键词大量不认识：先补当前题必要词汇；
- 词大多认识但关键长句主干不清：只拆当前证据句的意群和关系；
- 只是一个直接、单句可定的细节题：回到基础流程；
- 来源、原文或选项不完整：不据此总结规则或评价能力。

## 高中题的最短流程

```text
略读：对象 + 核心问题 + 文体 + 段落功能
→ 读题：问谁、问什么、需要哪类证据
→ 定位：先找锚点和相关段落
→ 扩围：单句不能定时，按“前后句 → 当前段 → 相关段”逐级扩大
→ 压缩：把证据写成“来源/主体—关系—对象—条件—范围—语气”
→ 核对：逐项检查主体、关系、条件、范围、语气、肯否、时间和立场来源
→ 回查：答案是否同时符合局部证据和全文方向
```

最短流程的关键不是每题填写八个栏目，而是在两个选项难分时，找出真正发生变化的那个栏目。直接细节题可能在定位句就停止；跨段推理、态度或目的题才继续扩围。

## 一、复杂同义改写与范围、语气

### 1. 先还原为“证据命题”

遇到长句或高度概括的选项，先不比较词面，把原文必要信息压缩为：

```text
信息来源 / 主体
+ 做了什么或具有什么关系
+ 对象或结果
+ 条件
+ 人群、地点、时间等范围
+ 程度、可能性和肯否
```

不是每题都要写全。优先保留能改变答案的限制词，如 `some / among / on average / if / may / could / not / rather than / in coming decades`。

### 2. 高中常见的改写层级

| 改写层级 | 常见变化 | 核对重点 |
| --- | --- | --- |
| 词汇替换 | 一个词换成同义词、上义词或解释 | 语境义是否一致，不只查词典第一义 |
| 词性或句式转换 | 动词变名词、主动变被动、比较结构改写 | 主体、动作方向和比较对象是否保留 |
| 肯否转换 | 否定词加反义表达，或用限制性否定 | `not all` 不能改成 `none`，`not happier` 也不能扩大成“没有任何情绪变化” |
| 因果或结果改写 | 原因、机制、结果压缩成影响或含义 | 方向、条件和中间环节是否被偷换 |
| 多句压缩 | 两三句事实概括成一个选项 | 每个关键分句是否都支持该概括 |
| 具体与概括转换 | 数字、例子或个体事实概括为趋势 | 概括是否仍受原文范围限制 |

### 3. 范围和语气检查表

| 原文信号 | 必须保留的边界 | 常见偷换 |
| --- | --- | --- |
| `some / around half / among those` | 只限部分人或某个子组 | 扩大为所有参与者或一般人群 |
| `on average` | 描述组平均值 | 推成每个个体都如此 |
| `may / could / can` | 可能、能力或条件性结果 | 改成 `will / must` 的确定结果 |
| `suggest / imply / indicate` | 证据支持某种解释 | 改成无条件“证明” |
| `if / when / under` | 结果依赖条件 | 删除条件后说成普遍事实 |
| `about / as much as / up to` | 估计值、上限或近似值 | 改成精确固定值或所有情形 |
| `higher than / lower than` | 与明确对象比较 | 改成自身增加，或换了比较对象 |
| 未来预测或模型结果 | 时间在未来，且可能带假设 | 改成已经发生的当前事实 |

选项可以比原文更简洁，但不能因此丢掉会改变结论的条件。反过来，不能因为选项没有复现原词就排除；只要上述关键栏目等值，它仍可能是有效改写。

### 4. 二选一时的最短核对

```text
主体一样吗？
→ 核心关系和方向一样吗？
→ 必要条件还在吗？
→ 人群、时间和数量范围被放大了吗？
→ 可能性或态度强度被升级了吗？
```

找到第一个不一致点即可，不必把四个选项都翻译成完整中文。

## 二、作者与被引人物的立场

高中说明文、科普报道和议论文常同时出现多种声音。先建立“谁对什么持什么态度”的立场表，不只圈褒义词或贬义词。

| 栏目 | 要记录的内容 |
| --- | --- |
| 来源 | 作者、研究团队、被引专家、机构、参与者或其他人物 |
| 对象 | 这个态度具体针对哪项做法、发现、风险或解释 |
| 方向 | 支持、反对、担忧、认可、质疑、保留或条件性接受 |
| 强度 | 提及 / 承认 / 倾向 / 建议 / 主张 / 强烈反对 |
| 依据 | 原文事实、评价词、转折、让步、建议或行动边界 |

### 最短流程

```text
题干锁定“谁”
→ 找此人的直接话语和前后转述
→ 标出态度对象，而不是只看褒贬
→ 处理 but / though / while 等让步转折
→ 用“此人认可 A，但对 B 持……，因此倾向……”概括
→ 核对选项是否换了人物、对象或强度
```

### 必须守住的边界

- 作者引用某人，不等于作者完全认同这个人；
- 两个人都认可同一背景，不等于他们赞成同一种解决办法；
- `acknowledge a risk` 不等于 `oppose the whole practice`；
- “不完全停止”不能改成“毫无保留地支持”；
- 人物说“可以做，但要满足某条件”，选项必须保留这种条件性；
- 推测人物会倡导什么时，要用其明确的原因判断、建议和行动边界作最短推理，不能替人物新增政策。

仓库 C 篇样例同时呈现树木价值、条件性环境风险、研究者提醒和管理部门的权衡。它可用于训练“共同前提相同，但风险管理重点或建议不同”的多声部识别；本文件不据此公布任何小题答案。

## 三、相关与因果

### 1. 先画关系，不先贴“原因”标签

```text
A 与 B 同时出现                → 相关或伴随
A 在 B 之前出现                → 只有时间顺序
A --在条件 C 下--> 中间机制 M → 结果 B
干预 A + 对照比较              → 文中可能支持因果解释
```

题目要求的是原文支持的关系，不是让学生脱离文章评价整个研究。若文章只写 `associated with / linked to`，不升级为“导致”；若文章明确给出作用机制或干预比较，也不能把关系弱化成毫无方向的“有关”。

### 2. 因果链的核对项目

- 起点和结果有没有倒置；
- 中间是否还有另一个必要因素；
- 是否只在某种条件、地点、时间或人群中成立；
- 原文说的是直接导致、间接影响、增加风险，还是仅提出可能解释；
- 选项是否把“因素之一”改成“唯一原因”；
- 文章是否用后续测量或对照来削弱某个替代解释。

仓库 C 篇样例中的环境影响不是一个词到一个结果的直线关系，而是物质、污染源及后续结果组成的条件性链条。教学时应让学生把链条画完整，再判断选项是否保留方向与条件，不直接给出题号或选项字母。

### 3. 研究结论的语气边界

- 随机分组、干预和对照有助于判断干预带来的差异，但仍以文章自己的结论措辞为准；
- `the study suggests` 不改写为“永远证明”；
- 子组中效果更大，只说明文章报告的子组现象，不自动证明该子组特征是原因；
- 平均值更高不等于每名参与者都更高；
- 排除一个替代解释，不等于已经排除所有其他解释。

## 四、研究类文章的篇章结构

研究类文章不要求学生掌握大学研究方法术语。目标是看懂“研究为什么做、怎样比较、测了什么、发现什么、怎样解释”。

| 常见部分 | 阅读时要回答的问题 | 题目常取的证据 |
| --- | --- | --- |
| 背景与研究问题 | 已知什么，还想比较或确认什么 | 研究目的、全文主旨 |
| 对象与分组 | 谁参加，如何分组，各组差异是什么 | 直接细节、设计作用 |
| 任务与测量 | 操作了什么，测量了什么结果 | 细节、变量对应 |
| 主要结果 | 哪些组相比，在哪项指标上怎样 | 数据改写、比较题 |
| 补充结果或子组 | 结论适用于谁，效果是否相同 | 范围、最高或更明显的比较 |
| 替代解释检查 | 是否可能由别的因素造成，文章怎样核对 | 为什么额外测量、推理判断 |
| 研究者解释 | 作者或研究者如何理解结果 | 结论、意义、态度 |

### 研究证据卡

```text
研究问题：
参与者与分组：
各组唯一关键差异：
测量结果：
比较对象：
主要发现及范围：
替代解释与核对：
研究者的解释语气：
```

只填写当前题需要的栏目。题干出现“最高、最大、最明显”时，先列全可比组和同一指标；原文没有提供的数值不能自行补齐。题干问“为什么还测量 X”时，要看 X 在后文用于支持、限制还是排除哪种解释，不能只答“为了了解 X”。

仓库 D 篇样例包含随机分组、不同任务、组间平均结果、子组结果、额外情绪测量以及对替代解释的处理，可验证这张研究证据卡能覆盖一组相互关联的题目。本文件只描述结构，不提供该篇小题答案。

## 五、议论类与观点型文章的篇章结构

高中议论类文章常把作者观点、他人观点和证据穿插在一起。科普报道也可能带有明显的争议、权衡和建议，可使用同一套功能标签，但不强行把每篇文章套成固定五段式。

| 功能标签 | 这一部分在推进什么 |
| --- | --- |
| 背景 / 共同前提 | 交代议题及各方都承认的事实 |
| 问题 / 核心争议 | 指出原做法的风险、缺口或分歧 |
| 机制 / 理由 | 解释为什么会出现该问题 |
| 证据 / 例子 | 用研究、数据、案例或引语支持观点 |
| 让步 | 承认另一面合理、价值或限制 |
| 转折 / 反驳 | 限制前述说法，或回应另一种解释 |
| 权衡 | 比较不同做法的收益、损失和条件 |
| 建议 / 启示 | 提出应如何理解或行动 |

### 最短结构图

```text
核心议题
→ 作者或文章主要在回应什么问题
→ 每段只贴一个当前最主要的功能标签
→ 标出“支持、限制、转向、回应”关系
→ 用主要段落共同覆盖来判断主旨、态度和目的
```

`but / however / though / while` 是高价值线索，不是看到后就机械认定前句作废。它可能表示让步后强调、对比两组情况、限制结论或引入另一人物的重点；必须结合转折两侧具体内容。

## 六、跨句、跨段多证据

### 1. 什么时候必须扩围

- 定位句只给结论，上一句给对象或条件；
- 代词、指代或省略使单句信息不完整；
- 一段报告结果，下一段给限制、解释或反例；
- 题干问人物总体态度，但人物的认可、担忧和建议分散出现；
- 题干要求比较多个组、多个阶段或多个观点；
- 题干问全文主旨、目的、标题或某段在全文中的作用。

### 2. 证据链只保留必要节点

| 题干目标 | 证据 1 | 证据 2 | 两者关系 | 能支持到哪里 |
| --- | --- | --- | --- | --- |
| 当前问题 | 直接事实或观点 | 条件、限制、结果或另一比较项 | 支持 / 限制 / 转折 / 因果 / 对比 | 最小结论 |

常见组合：

- **合并**：两处证据共同完成一个事实或比较；
- **限制**：第一处支持大方向，第二处缩小人群、条件或强度；
- **排除**：一处提出替代解释，后一处提供不支持该解释的证据；
- **立场拼合**：同一人物在不同位置分别表达认可、担忧和建议；
- **篇章覆盖**：多个主要段落共同决定主旨或写作目的。

### 3. 扩围的停止规则

```text
当前句能唯一决定 → 停
否则读前后句；能唯一决定 → 停
否则读当前段；能唯一决定 → 停
否则按段落功能找到另一相关段；能唯一决定 → 停
仍不能决定 → 检查是否定位错、题目材料不完整或需要全文覆盖
```

跨段不等于把全文所有信息混在一起。不同人物、不同实验组、不同时间或不同指标的事实，除非文章明确建立关系，否则不能自行拼接。

## 七、写作目的与段落作用

### 1. 先区分三个问题

| 题目目标 | 实际在问什么 | 回答形式 |
| --- | --- | --- |
| 内容 | 这一句、段或全文说了什么 | 对象 + 主要信息 |
| 局部作用 | 为什么在这里写这项内容 | 材料或动作 + 对附近论述的作用 |
| 全文目的 | 作者写整篇文章想完成什么 | 写作动作 + 具体对象 + 核心重点 |

### 2. 段落作用的最短公式

```text
本段写了什么材料
→ 它在局部完成什么动作（引出、解释、举证、对比、限制、转折、回应或总结）
→ 它怎样服务全文核心议题
```

例如，“列出实验数据”只是内容或手法；“用组间数据支持主要发现”才说明局部作用。又如，“引用另一位专家”不自动等于支持作者，需判断这段引语是在补充、限制、反驳还是展示权衡。

### 3. 全文目的的最短公式

```text
写作动作 + 核心对象 + 文章真正强调的关系或发现
```

常见写作动作包括介绍、解释、报告、比较、讨论、质疑、提醒和倡议。不能只答泛化的 `to tell readers something about...`，也不能把某段建议冒充全文目的。

### 4. 常见干扰

- 只复述目标段内容，没有说明它为何出现在这里；
- 把手法名称当作用，如只答“举例”或“列数字”；
- 把局部例子或末段引语扩大成全文目的；
- 使用“吸引读者”这一万能答案，却没有文本证据；
- 凭文体常识猜目的，没有用段落功能和全文主旨验证。

## 教学台阶

台阶用于定位当前缺口，不要求每名高中生从头到尾全部学习。学生有可用做题报告时，从报告暴露的最早断点进入。

| 台阶 | 单一目标 | 最小练习 | 当前台阶完成证据 | 默认停止点 |
| --- | --- | --- | --- | --- |
| 0. 基础流程 | 能建主旨草图、定位并读足必要证据 | 一篇难度匹配材料中的直接细节题 | 能说“题型 + 位置 + 证据” | 能独立完成就不启用高中扩展 |
| 1. 精确改写 | 保留主体、关系、条件、范围和语气 | 一组原文命题与选项对应 | 能指出某干扰项具体偷换了哪个栏目 | 新题独立成功后回到整篇 |
| 2. 证据扩围 | 单句不足时组成最小证据链 | 一道跨句或跨段题 | 能说明为何需要第二处证据，并在证据足够时停止 | 不继续训练无关结构 |
| 3A. 多声部立场 | 区分作者与不同被引人物 | 同文两个人物的立场表 | 能说清“谁、针对什么、态度和强度” | 不顺便讲完整议论文体系 |
| 3B. 相关与因果 | 保留方向、条件、中间环节和语气 | 一条因果链或研究比较 | 能区分相关、条件性影响和文章明确支持的因果解释 | 不展开超出原文的研究方法批判 |
| 4A. 研究结构 | 看懂分组、测量、结果和替代解释 | 一张只填必要栏目的研究证据卡 | 能把题目定位到设计、结果或解释，并正确限定人群和比较 | 当前研究题断点解决即停 |
| 4B. 议论结构 | 看懂观点、让步、回应和权衡 | 段落功能标签图 | 能解释主要段落怎样共同服务核心议题 | 不要求背冷僻修辞术语 |
| 5. 目的与作用 | 区分内容、局部功能和全文目的 | 一道 `why / role / purpose` 题 | 能用“材料—局部动作—全文作用”作答 | 新材料迁移成功后回到常规练习 |

3A 与 3B、4A 与 4B 是并列入口，不是必须按编号全部完成。真实报告只暴露其中一个问题时，只补该问题。

## 完成证据与能力边界

本轮最小补漏完成，需要学生在难度匹配、表述不同的新题中独立做到：

1. 说出题干要判断的对象和证据类型；
2. 给出最小充分的证据位置，必要时连接两处证据；
3. 用自己的话保留主体、关系、条件、范围和语气；
4. 指出所排除选项至少一个明确的偷换点；
5. 说明答案如何同时符合局部证据和全文方向。

只报对选项、复述老师分析、靠原词碰中或无法说明证据，不算当前方法已经掌握。一次新题成功只表示当前断点得到最小验证，不能自动写成“稳定”；稳定能力仍需后续间隔材料的新证据。

## 默认停止点

- 当前报告暴露的第一个断点在新题中得到最小验证后，停止专项讲解，让学生回到新的常规阅读；
- 不因学生进入高中，就一次讲完所有扩展模块；
- 不要求逐句翻译全文，也不把所有长句都升级为语法课；
- 不展开原文未要求的统计学、实验方法评价或冷僻修辞术语；
- 不用本文件训练、评价或记录七选五能力；
- 样例没有可靠答案来源时，可以做文本结构分析，并在证据充分时给出明确标注的“暂定判断”；不能把它包装成标准答案或官方答案，也不能据此判分、计算正确率或更新能力状态。证据不足时保留待核验，不强行选项。

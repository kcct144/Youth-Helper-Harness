# 七选五资料评审

这里记录外部资料对七选五体系的贡献和边界。评审记录不替代 `资料/` 中的学生正文。

## 证据等级

| 等级 | 常见来源 | 可以支持什么 |
| --- | --- | --- |
| A | 课程标准、考试机构命题或评价资料 | 题型目标、语篇能力和考查方向 |
| B | 可靠研究、完整真题与可靠答案、可核验的逐题分析 | 方法机制、题目证据和适用边界 |
| C | 教师经验、教学视频、单个学生报告 | 教学表达、候选策略和待验证现象 |
| D | 无题源口诀、命中率口号、剪辑后的单例 | 只能登记线索，不能进入正式规则 |

同一结论被多个转载重复，不视为多个独立证据。C、D 级材料中的方法若已被 A、B 级来源独立支持，可以吸收其更易懂的表达，但不能连带吸收原资料的频率和命中率结论。

## 已采用的核心依据

### A 级

1. [教育部：义务教育课程方案和课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)
   - 支持义务教育阶段按语篇知识、衔接与连贯理解意义；不据此推断某地当前必考某种固定数量的共享句池。
2. [义务教育英语课程标准（2011 年版）评价案例](https://www.moe.gov.cn/srcsite/A26/s8001/201112/W020220418401378728645.pdf)
   - 评价案例包含“从六个句子中选五个还原短文”，可核验共享句子池还原任务并非高中独有；只用于确认任务家族，不代表当前各地中考题面。
3. [普通高中英语课程标准（2017 年版 2020 年修订）](https://www.pep.com.cn/xw/zt/rjwy/gzkb2020/202205/P020220517522153664167.pdf)
   - 支持语篇结构、显性和隐性衔接、新旧信息承接及语义逻辑关系。
4. [浙江省教育考试院：2019 年高考英语命题思路](https://www.zjzs.net/art/2019/6/10/art_45_5437.html)
   - 说明该部分考查文章结构以及句子、段落之间的衔接。
5. [浙江省教育考试院：2024 年高考英语试题评析](https://www.zjzs.net/art/2024/6/11/art_31_9716.html)
   - 支持以句子语义和逻辑衔接恢复语篇连贯。
6. [中国教育考试网：2024 年高考英语试题评析](https://www.neea.edu.cn/xhtml1/report/2401/499-1.htm)
   - 用于核对考试编排与官方题型表述；本项目仍可为了教学独立管理七选五，但不把项目分类说成官方分类。

### B 级

1. [高中英语阅读理解“七选五”题型解题策略](https://flts.bnu.edu.cn/node/15260)
   - 支持宏观、微观语篇信息与功能，以及句间、段间逻辑关系。
2. [高考英语还原句子型阅读理解试题分析](https://flts.bnu.edu.cn/node/12211)
   - 支持从衔接、连贯和句段逻辑解释答案。
3. [浙江考试研究 2025 年相关真题特征分析](https://www.zjzs.net/module/download/downfile.jsp?classid=0&filename=76962f25be5549f59da6ebe792bf7def.pdf)
   - 支持复现、指代、新旧信息和前后语境联合验证。使用时保留原刊物或考试院下载来源，不依赖二手口诀。
4. [Cambridge English Grammar Today：`it`](https://dictionary.cambridge.org/grammar/british-grammar/it)、[other / others / another](https://dictionary.cambridge.org/grammar/british-grammar/other-others-the-other-or-another)、[besides / also](https://dictionary.cambridge.org/grammar/british-grammar/word-choice-besides-or-also)
   - 用于核验非回指 `it`、`other/another` 非强制配对以及相近连接表达不能机械互换等语言边界；不用于证明某种做题顺序或命中率。

这些依据共同支持本项目的试行核心：语篇功能、对象与意义链、语义逻辑、结构呼应、必要上下文和全文验证。它们没有证明所有学生都应使用同一个作答顺序。

### 有用并已吸收

| 视频表达 | 体系归属 | 处理 |
| --- | --- | --- |
| 对象一致或相关 | 对象与意义链 | 吸收“对象搭桥”作为学生口令，并明确对象不只等于语法主语 |
| 指示代词找所指 | 指代链 | 纳入对象线，但必须继续核对语义、功能和上下文 |
| 前后逻辑 | 语义逻辑 | 保留转折、因果、问题与回应等真实关系，不使用绝对口诀 |
| 平行句式 | 结构呼应 | 保留为辅助筛选，必须用内容和功能确认 |
| 先看选项 | 作答入口 | 作为“选项预检”候选策略，不设为所有学生必做 |

视频的真题示范有助于理解这些线索怎样出现，但例题本身仍需回到完整题目和可靠答案逐空核验。

### 进入候选、继续观察

- 先看选项是否比先读文章更适合某类学生；
- 只预检代词、逻辑词、对象和结构，是否能减轻阅读负担；
- 高把握项优先是否能降低共享池中的连锁错误；
- “确认项 / 暂定项”或把握度标记是否有实际教学收益；
- 平行结构在不同年份、不同卷型中的实际频率和区分度。

这些内容统一进入 本文件的候选策略说明，暂不用于学生能力评价。

### 明确不纳入

- “形式大于内容”；
- 平行句式“99% 正确”、指示代词“90% 以上正确”等命中率；
- “近十年只有一道指示代词干扰项”等无统计材料的频率结论；
- 例子通常成对、后面的信息总是更重要；
- 七选五大多数是问题—对策文章；
- 所有学生都必须先看选项；
- 第一段要翻译、其他部分只看空前空后；
- 看不懂也能在三分钟内稳拿满分。

排除原因不是这些说法在任何题中都不会碰巧成立，而是它们把可能的线索、经验或宣传口号变成了无边界的答案规则。

## 后续资料接收流程

维护者继续提供视频、文章、讲义或真题时，依次记录：

1. 原始来源、作者、日期和完整上下文；
2. 它提出了哪些具体方法或频率结论；
3. 现有体系能否解释；
4. 哪些只是更好的教学表达；
5. 哪些是真正的新方法候选；
6. 哪些是绝对口诀或无样本统计；
7. 真题示例是否有完整原文和可靠答案；
8. 准入、观察或拒绝后影响哪些文件。

单份资料不会自动扩充正式体系。学生当前遇到相关题目时，先解决那一道题的最小问题；公共方法按 工作区维护约定 进入候选与准入流程。

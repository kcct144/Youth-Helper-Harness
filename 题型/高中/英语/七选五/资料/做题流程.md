# 七选五做题流程（试行）

- 适用学段：初中、高中
- 核心动作：选择入口 → 看空前空后的对象与关系 → 比较候选 → 代回验证
- 当前版本：0.3.1
- 更新日期：2026-08-27

本流程适用于多个空共享一个句子选项池的短文还原任务，包括五选四、五选五、六选五、七选五等；“七选五”只是本工作区沿用的目录名。本流程提供一条可靠主线，不规定所有学生必须采用同一阅读顺序。

## 作答前提

先按题目说明确认空格数、选项数、选项使用规则以及有无多余项。若多个关键选项或上下文读不懂，先处理必要词汇、句子主干或材料难度；这属于材料适配，不要求学生把它背成考场步骤。

如果学生提供的题面不完整，先补齐原题说明；如果完整原题仍未写明选项能否重复或有几个多余项，就将规则标为待核实并向教师或原出处确认。确认前可以逐空建立暂定候选，但不执行“用过即删”，不靠最后剩余项定答案。

## 第一步：选择入口

两种入口都可以：

### 入口 A：先读文章

适合需要先建立话题和段落方向的学生：

1. 快速读标题、首段和各段主要信息；
2. 暂时跳过不影响主线的生词；
3. 遇到空格时再细读必要上下文。

### 入口 B：先预检选项

适合选项较短、学生能快速读懂选项时：

1. 用短语概括每个选项的核心意思；
2. 圈出明显的代词、逻辑词、对象词和结构呼应；
3. 只做预判，不在脱离文章时直接确定答案；
4. 回到文章建立主线和空格语境。

“必须先看选项”或“必须先看文章”都不是正式规则。比较哪种入口更适合某个学生，属于效率实验。

## 第二步：看空前空后

对当前空问四个问题：

1. 空前在说谁、什么事或什么观点？叙述者、发言者和参与者分别是谁？
2. 空后继续说谁、什么事或什么观点？角色或视角有没有变化？
3. 这里需要命名或引入对象，还是定义、展开、支撑、转向或收束？
4. 前后需要并列、转折、因果、条件、例外、过程先后或其他什么关系才能连起来？后文依赖什么语义前提？

不必在作答前一次性给全部空格分类，也不必先把所有空都做完预判。当前空的信息不足时，再把阅读范围从相邻句扩大到当前段、前后段或全文。

## 第三步：比较候选

按三条线找正面证据：

1. **对象线**：叙述者、发言者、参与者的延续或切换是否清楚；指代、新旧信息及原词、词族、同义反义、上下位或类属表达是否把对象接起来；同场景词只算弱线索；
2. **关系线**：并列、转折、因果、例证、条件、例外、顺序或过程链是否成立，候选是否给后文补上必要的语义前提；
3. **形式线**：先排除人称、单复数、时态或句法接口等硬语法冲突，再观察并列步骤和同层句式等软结构呼应；常见句壳相似只能算弱线索。

候选不必三条线全部具备，但要有足以区别干扰项的具体证据。语法兼容、同词、同话题、同场景或相似句式都只能建立候选，不立即确定；所有候选都必须进入下一步代回验证。

## 第四步：代回验证

把候选放回必要上下文，检查：

- 指代是否有明确对象；
- `it` 是否真的回指前文，而不是天气、时间、距离、形式主语或形式宾语、强调结构等非回指用法；
- 叙述者、发言者、参与者和视角的延续或切换是否清楚；
- 句子是否接住前文并自然推进后文；
- 逻辑方向、条件或例外范围是否正确，后文所需的过程环节和语义前提是否成立；
- 内容是否符合本段功能和全文主线；
- 是否有其他候选在这里证据更强。

中间空默认看两侧；文章首尾或特殊位置不机械要求双侧证据，而要结合段落和全文功能。

## 第五步：检查整组

完成或出现候选冲突时再检查共享选项池：

1. 是否符合题面规定的选项使用次数；
2. 若每项只能用一次，两个空是否争用同一候选；
3. 该候选在哪个空有更独特的对象、关系或功能证据；
4. 有多余项时，剩余选项是否只是话题相关，却无法真正衔接；
5. 没有多余项时，每个位置是否仍有正面证据，而不是按剩余项硬塞；
6. 全部代回后，段落和全文是否连贯。

只有出现真实冲突时才需要跨空比较，不要求每次画分配表。最后剩下的选项仍需正面验证，不能只因为“只剩它”就视为正确。

## 可选效率策略

以下方法可以试，但不是标准动作，也不用于评价学生：

- 先做自认为证据最明确的空；
- 标记确认项和暂定项；
- 给候选标高、中、低把握；
- 用表格比较两个空争用的选项；
- 固定先看选项或先看文章；
- 使用统一限时节奏。

试验时只比较它是否让该学生在难度相近的新题中更快、更准、证据更清楚。一次有效不能立即升级为通用规则。

## 报告诊断顺序

学生提交错题或做题报告时：

    材料和答案是否可靠
    → 关键内容是否读得懂
    → 学生当时依据了什么
    → 已准入核心动作中第一个有证据的断点
    → 多个错空是否同源
    → 本轮一个最小目标

常见断点示例：

- 只找一样的词，没有确认是不是同一对象；
- 把同场景词、相同句壳或语法没错当成充分证据；
- 混淆叙述者、发言者或事件参与者，或强行让非回指 `it` 寻找前文对象；
- 能看出对象，却没有判断前后关系；
- 漏掉条件、例外、过程环节或后文需要的语义前提；
- 只看一侧，没有把候选代回必要上下文；
- 局部通顺，却与本段功能或全文主线冲突；
- 两个空争用同一选项时，没有比较独特证据。

学生按题号顺序作答、没有先看选项或没有先做高把握项，本身不构成方法缺口。

## 报告驱动的停止点

只补报告实际暴露的第一个断点：

- 局部对象、关系或代回问题，可用 按证据需要安排的同范围新空验证；
- 题型规则、整篇连贯或真实跨空冲突，需要用完整共享池材料验证；
- 学生能在新任务中无需提示执行刚补的动作后，本轮结束，回到新题获取下一份报告。

不因一题出现代词就讲完所有指代，不因连续错空就自动重教完整流程。

## 新方法入口

现有核心无法稳定解释来源和答案可靠的题目时，先完成当前题的最小处理，再按 工作区维护约定 登记。候选方法未经准入，不能用于批量出题或能力评价。

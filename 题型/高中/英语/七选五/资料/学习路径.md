# 七选五学习路径（试行）

- 适用学段：初中、高中
- 当前版本：0.3.1
- 默认方式：报告驱动的“查缺 → 最小补漏 → 新题验证”
- 核心路线：材料适配 → 执行核心动作 → 只补真实断点 → 回到新材料

本路径适用于多个空共享一个句子选项池的短文还原任务，包括五选四、五选五、六选五、七选五等；“七选五”只是本工作区沿用的目录名。本路径不是必须依次学完的课程目录。学生已有做题报告时，直接从报告暴露的断点进入。

## 报告优先

收到完整七选五、学生答案或错题报告后：

    核实文章、选项池和答案来源
    → 判断关键内容是否读得懂
    → 还原学生当时的选择依据
    → 找到已准入核心中的第一个真实断点
    → 只补一个最小目标
    → 用匹配范围的新任务验证
    → 回到新的七选五

报告没有暴露的证据类型保持未评估。学生没有要求系统学习时，不沿对象、逻辑、指代、结构等目录自动补课。

## 分流一：材料与任务规则

先确认学生是否：

- 理解所有空共用一个句子选项池；
- 能按题面说清空数、选项数、能否重复使用以及有无多余项；
- 能说出文章或相关段落的大意；
- 能说出关键选项和空格附近句子的核心意思。

处理方式：

- 学生不理解共享池规则：用一个微型共享池说明规则概念；
- 学生提供的题面不完整：先索取完整说明或截图；完整原题仍漏写使用规则时，标为待核实并向教师或原出处确认，确认前不“用过即删”、不靠最后剩余项定答案；
- 少量生词或长句：只补完成当前空判断所需的语言；
- 多个关键选项和上下文都不懂：换较易材料，暂不评价方法；
- 规则和语言可用：进入核心动作。

材料适配随文章变化，不作为稳定能力等级。

## 分流二：核心动作

学生至少要逐步学会：

1. 看出当前空前后在谈的对象、角色、视角和关系；
2. 粗判这里是在命名或引入对象，还是定义、展开、支撑、转向或收束；
3. 用对象线、关系线或形式线建立并比较候选；
4. 把候选代回必要上下文验证；
5. 完成后检查共享池和全文连贯。

第一次系统学习时，可以用一篇难度合适、答案可靠的完整材料走一遍。只要某一步出现明确断点，就停在该步补漏，不一次讲完所有线索。任何线索都只负责建立候选，不能代替代回验证。

## 按报告进入的补漏分支

### 对象搭桥

适用于只找相同单词、看不出词族、同义反义或上下位关系，没有确认指代对象，或混淆叙述者、发言者和事件参与者。

最小目标：说清前文的旧对象和角色、候选怎样接住它，以及后文继续展开什么。遇到 `it` 时先判断它是否真的回指；天气、时间、距离、形式主语或形式宾语、强调结构等不能强行寻找前文对象。同场景词只能作为弱线索。

### 关系判断

适用于知道句子大意，却没有判断转折、因果、例证、并列、条件或例外等关系，或漏掉过程中的必要环节和后文依赖的语义前提。

最小目标：先用中文说出前后关系、过程先后和必要前提，再用候选验证；不背“看到某词就选某边”的口诀。

### 缺句功能

适用于候选局部通顺，却不符合本段需要。

最小目标：区分“命名或引入新对象”和“定义或展开已有对象”，再用“支撑、转向、结果、收束”等短标签说明这里缺什么作用的句子。

### 结构呼应

只在真实材料出现语法接口、并列步骤、重复句式或同层信息，而学生漏掉或误用时启用。

最小目标：先排除人称、单复数、时态或句法接口等硬语法冲突；再用并列步骤和同层句式等软结构呼应建立候选；把常见句壳相似降为弱线索，最后检查内容、关系和功能。

### 代回验证

适用于只看同词、只看一侧，或选项看似合理却放回不连贯。

最小目标：指出候选接住什么、推进什么；证据不足时主动扩大到段落或全文。

### 共享池冲突

只在两个以上空真实争用同一候选时启用。

最小目标：比较候选在哪个空有更独特的证据，并把整组代回验证。不能用孤立单空证明这项能力。

完成本轮最小目标后立即停止，不顺带进入其他分支。

## 新任务验证

- 局部对象、指代、逻辑或代回断点：按证据需要安排的有可靠答案的新空即可；
- 段落功能：至少使用包含必要段落的新任务；
- 共享池规则、真实跨空冲突或全文连贯：使用完整选项池材料；
- “可独立”要求学生无需提示说明证据并完成动作；
- “稳定”还需要变式、完整新篇或间隔复测。

AI 自编材料必须标明“自编”，并检查答案是否唯一、语言难度是否匹配。没有可靠答案的本地 2026 样例不能单独用于判分或定级。

## 可选效率实验

只有报告明确暴露速度、犹豫或候选冲突中的任一情况时，才可尝试：

- 先预检选项还是先读文章；
- 先做证据明确的空还是按题号顺序；
- 是否标记确认项、暂定项或把握度；
- 是否使用跨空比较表；
- 怎样安排限时节奏。

实验前要告诉学生“这是一种可选尝试”。只记录它是否适合该学生，不把未采用该策略记成错误，也不据此升降正式能力状态。

## 系统学习时的最小安排

学生明确要求从头学习时，可以采用：

1. 一篇较易完整材料：认识共享池并走核心动作；
2. 根据第一篇的真实断点，只练一个分支；
3. 一篇同难度新材料：验证能否独立迁移；
4. 再由新报告决定下一步。

不预设每名学生都必须依次学完固定六关或八步。学习顺序由证据决定。

## 默认停止点

学生能在新材料中独立执行本轮补上的动作后，就让他回到真实练习并带回下一份报告。没有新证据时，不继续补“以后可能会考”的相邻技巧。

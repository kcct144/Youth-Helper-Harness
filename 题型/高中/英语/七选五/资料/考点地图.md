# 七选五考点与证据地图（试行）

- 适用学段：初中、高中
- 项目定位：多个空共享一个句子选项池的还原型阅读；在本工作区中独立于常规四选一阅读管理
- 当前版本：0.3.1
- 当前状态：核心方法试行；效率策略仍在观察
- 核心目标：根据语篇功能和衔接证据，把缺句放回后恢复连贯

> “七选五”是本工作区沿用的目录名，实际覆盖五选四、五选五、六选五、七选五等“多个空共享一个句子池”的短文还原任务。“独立题型”是本项目为了教学和进度管理采用的分类，不代表考试文件一定不把它编排在阅读部分。

## 题型规则

具体空数、选项数以及有无多余项都按题面确认。常见形式包括五选四、五选五、六选五和七选五；名称中的数字不能代替阅读题目说明。

- 所有空共用一个句子选项池；
- 选项能否重复、每项最多使用几次，按题面规则确认；常见规则是一个入选句子只使用一次；
- 题目可能有多余项，也可能没有；有多余项时，它们也可能与全文话题相关；
- 若题面规定每项只能使用一次，一个空的选择会改变剩余选项池；
- 最终答案要放回上下文和全文检查。

若完整原题仍未说明选项能否重复或多余项数量，应把规则标为待核实并向教师或原出处确认。确认前可以分析每个空的衔接候选，但不能“用过即删”，也不能用最后剩余项倒推答案。

`资料/题型示例/高考全国1卷-七选五.md` 只展示其中一种任务结构，且没有答案和解析，不能单独用于判分或能力评价。

## 核心模型

每个空先回答两个问题：

1. **缺句在这里做什么？**判断它在本段或全文中的语篇功能。
2. **它怎样接住前后？**寻找对象、关系和结构证据。

学生可以先记成三条线：

- **对象线**：前后在说谁、什么事、什么观点；
- **关系线**：前后是并列、转折、因果、举例还是其他关系；
- **形式线**：句式、步骤或信息层级是否互相呼应。

其中对象线和关系线通常负责确定意义，形式线主要帮助筛选。任何正面线索都只能先建立候选，不能单独确认答案；候选最终都要代回必要上下文和全文主线验证。

## 一、语篇功能

功能标签用于缩小候选，不是固定答案公式。同一句可能同时承担两种作用。

### 1. 这句话在本段做什么

| 粗标签 | 可能的作用 |
| --- | --- |
| 命名或引入 | 提出接下来要谈的人、事、问题、观点或步骤，给后文提供展开对象 |
| 定义或展开 | 解释已经提出的对象是什么、为什么、怎样做或具体包含什么 |
| 例证或支撑 | 用例子、事实、理由或细节支持前文 |
| 承接或转向 | 接住前文并改变角度、层次或方向 |
| 结果或收束 | 说明结果、总结本段或引向下一部分 |

### 2. 它和邻句是什么关系

- 并列或递进；
- 转折或对比；
- 原因或结果；
- 概括或例证；
- 时间或步骤顺序；
- 问题与回应。

“主题、过渡、补充、例证、结果、总结”等词可以作为学生用语，但不是封闭分类。尤其要区分：命名或引入是把一个对象带入当前语篇，定义或展开则以这个对象已经出现为前提，继续解释它。段首、段中、段尾只能提供线索，不能单独决定功能。

## 二、对象线：对象搭桥

“对象”不是只指语法主语，而是当前语篇正在谈论的人、事物、行为、问题、观点或结果，也包括叙述者、发言者和事件参与者的角色与视角。

一个可靠的对象桥通常是：

    前文给出旧信息 X
    → 候选接住 X，并引入或突出 Y
    → 后文继续解释 Y

### 1. 指代链

常见表现：

- `children → they`；
- `a method → this method`；
- `several problems → these problems`；
- 前文一整件事 → `this/that/such a change`。

要问：

1. 代词或概括语具体指谁、什么或哪件事？
2. 单复数、人物和事物是否匹配？
3. 候选放入后，所指是否清楚？

`this`、`that`、`these`、`those` 常提供较强指代约束，但出现它们不等于答案已经确定。`so` 有多种词性和用法，必须按句中作用判断，不能一律当作指示代词。

`it` 既可能回指前文对象，也可能不承担回指功能。例如天气、时间、距离表达，形式主语或形式宾语，以及 `It is/was ... that/who ...` 强调结构中的 `it`，都不能强行寻找前文名词。先判断它在句中的语法和语义作用，再决定是否建立指代链；这些例子不是封闭清单。

### 2. 角色与视角链

叙事、对话或观点材料还要分清：

- 谁是全文或当前片段的叙述者；
- 谁在说话、表达判断或提出建议；
- 谁是动作的执行者、承受者或其他参与者；
- 引语中的 `I/we` 与引语外的作者或叙述者是否发生切换。

候选若无提示地改变发言者、参与者或观察视角，通常不能顺接。角色延续或切换清楚只能建立候选，仍要检查句意和篇章功能。

### 3. 词汇链

同一对象或概念可以通过不同表达延续：

- **原词复现**：前后使用同一个词；
- **词族或词形变化**：如 `decide → decision`；
- **同义、近义或反义关系**：反义词只有在对比、转折等关系成立时才构成衔接；
- **上下位或类属关系**：如 `animals → birds`、`technology → messaging apps`；
- **同场景词**：如 `teacher、classroom、homework`，只能说明话题可能相关，通常是弱线索。

原词、词族和其他语义关系都只能建立候选。还要确认两处说的是同一个对象、概念或有效对立，而不是偶然同词；同场景更不能单独决定答案。

### 4. 新旧信息承接

强候选往往既接住前文已经出现的旧信息，又给后文提供继续展开的新信息。学生要能说：

- 它从前面接住了什么？
- 它给后面带来了什么？

只因为两个句子都属于“科技”“教育”等大话题，只能算弱相关。多余项也常与全文话题相关。

## 三、关系线：语义逻辑

先用中文说清关系，再看连接词。

| 关系 | 常见显性信号 |
| --- | --- |
| 并列或递进 | also、moreover、in addition |
| 转折或让步 | but、however、yet、although |
| 原因或结果 | because、therefore、as a result |
| 概括或例证 | for example、for instance、such as |
| 顺序 | first、then、later、finally |
| 条件、假设或例外 | if、unless、only when、except、otherwise |
| 问题与回应 | 问句后回答，或提出问题后给出办法 |

连接词是关系约束，不是答案口诀：

- 有连接词时，要检查它连接的两部分是否真的满足该关系；
- 没有连接词时，也可能存在隐性的转折、因果或对比；
- `but` 后的信息通常改变方向，但不能用“看到 but 就选后者”代替语义判断；
- “问题—对策”只是可能的篇章结构，不是所有七选五的默认结构。

### 过程链与语义前提

有些衔接不靠显性连接词，而靠事件或推理的先后条件：

    提出对象或条件
    → 完成必要动作或说明
    → 出现下一步、结果或例外

要检查候选是否给后文建立了必要的语义前提，例如后文的 `then`、结果句或进一步说明究竟承接了什么。时间相邻不等于过程成立；条件、例外、动作和结果必须在意思上真正衔接。过程链和语义前提也只能缩小候选，仍要代回验证。

## 四、形式线：结构呼应

形式线要分强弱：

1. **硬语法兼容**：人称、单复数、时态、连接结构或句法接口不能冲突。硬冲突可以排除候选，但“语法没错”不能确认答案。
2. **软结构呼应**：多个并列步骤、相似句式、同层信息或多段相同组织框架，可以帮助建立候选。
3. **弱句壳相似**：两个句子只是都采用 `It is ...`、`There are ...` 等常见外壳，区分度很低，不能据此选定。

形式可以帮助预测候选的样子和信息层级，但无论强弱都必须继续检查：

1. 内容是否属于同一层级；
2. 语义关系是否正确；
3. 句子在本段承担的功能是否合适。

核心口令是：

> 形式帮助筛选，内容、关系和篇章功能负责确认。

## 五、局部与整体证据

默认先读空格相邻的必要上下文；证据不足时再扩大：

    相邻句 → 当前段 → 前后段 → 全文主线

- 中间空通常需要检查前后两侧；
- 文章首尾天然少一侧；
- 段首或段尾有时需要跨段判断；
- 个别空可能由一侧的唯一强约束和全文结构共同决定。

因此，“前后都看”是默认动作，不是要求每个空必须凑出两条同等强度的证据。

## 六、共享选项池

正式规则只包括：

- 所有空共用一个选项池；
- 按题面确认选项能否重复以及有无多余项；
- 有多余项时，它也可能局部通顺或话题相关；没有多余项时，每个位置仍须有正面证据；
- 若题目规定每项只用一次，两个空争用同一候选时，需要比较哪个位置有更独特的证据；
- 最终要把全部句子代回全文复查。

“必须先做高把握项”“必须使用跨空分配表”“必须给每项标高、中、低把握”等属于可选效率策略，当前不作为学生能力标准，见 本文件的候选策略说明。

## 七、材料适配

方法训练前要确认学生能够：

- 大致说出文章或相关段落在讲什么；
- 理解关键选项的句子主干和核心意思；
- 理解空格附近决定答案的信息。

若多个选项或关键上下文都读不懂，当前首先暴露的是词汇、长句或材料难度问题。此时只补完成当前判断所需的语言，或换较易材料；不能靠技巧猜中率评价七选五能力。

目标也不是逐句翻译全文。学生能理解文章主线和决定答案的必要范围即可。

## 不进入正式体系的口诀

以下说法缺少足够证据，或会把辅助线索误用成答案规则：

- “形式大于内容”或平行句式有固定命中率；
- 出现指示代词且能找到所指，就几乎一定是答案；
- 例子通常成对出现；
- 论点后一定有两个平行例子；
- 前后对象相同，中间句主语就必须相同；
- 只要对象相关就能选；
- 正确项一定有原词复现或相同句壳；
- 同场景词出现就能确定答案；
- 所有代词都必须向前寻找同名名词；
- 出现 `some/others` 或 `one/another` 中的一项，另一项就必须出现；
- `instead`、`but`、`similarly`、`and` 等同类逻辑表达可以完全互换；
- “虽然但是看但是，因为所以看所以”；
- 问题与对策中，对策一定更重要；
- 七选五大多数都是问题—对策文章；
- 所有学生都必须先看选项；
- 不理解文章也能在固定时间内稳拿满分；
- 重复词、空格位置或最后剩余项可以单独决定答案。

这些说法可以成为待检验的观察，不能用于批量出题、判分或评价学生。

- 《义务教育英语课程标准（2022 年版）》关于语篇知识、衔接与连贯及理解语篇意义的要求；

- 北师大《外语教学理论与实践》中关于七选五宏观、微观语篇信息及句间、段间关系的研究；

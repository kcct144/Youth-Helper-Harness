# 统一题库规范 v1

根目录 `题库/` 是题目唯一维护源，按知识内容分目录，每道独立题一个 Markdown 文件。文件名等于永久 id；同一素材改成另一种作答形式时使用新 id，通过关联题组连接。学生状态只写在工作区的学习进度，题库不保存学生个人数据。

## 元数据

文件以 YAML frontmatter 开始。必填字段如下，列表即使只有一项也用列表格式：

```yaml
schema: enpractice-question/v1
id: GR-PRON-001
适用题型: [语法选择, 语法填空]
作答形式: 单项选择
考点: 人称代词
范围: 主格、宾格、形容词性物主代词
目标: 概念理解
台阶: L1
用途: [查缺, 补漏, 强化]
前置: [理解简单句句意]
初始难度: 基础
难度依据: 短句，单一目标，关系明确
来源: 自编
状态: 已校验
校验说明: 已人工或 AI 检查答案、歧义、范围和干扰项；尚未经学生实测
版本: 1
关联题组: PRON-基础-001
```

- `作答形式`：单项选择 / 填空。其他形式日后显式扩展规范，不能临时改变章节结构。
- `目标`：概念理解 / 形式回忆 / 考点识别 / 流程运用。强化是用途，不是另一种能力目标。
- `初始难度`：基础 / 常规 / 进阶。分别表示线索明确的单一判断、同范围内结构或语境判断、同范围内更复杂的多步判断。不得用后续台阶、冷僻词或例外制造难度。
- `状态`：待校验 / 已校验 / 停用。只有已校验题进入默认索引和分发；格式检查不等于内容正确，内容校验需要另做并注明依据。
- `台阶` 必须结合考点与范围理解，不能跨考点比较同名 L1；学会某组形式不等于全表掌握。
- `关联题组` 为可选字段；同素材、答案高度相似或彼此泄题的题必须关联。见过组内一题后，另一题不能作为完全未见材料的迁移证据。
- `适用题型` 表示可服务该题型的学习，不表示模拟整篇考试。选择题用于语法填空补漏时，仍只产生选择作答证据。
- id 永久不变；答案、题干或判分实质修订时增加版本，改变学习目标或作答形式则新建 id。引用来源不能伪称真题，自编示例不能写成官方题。

## 正文

严格按下面顺序使用二级标题，无额外一级题名，避免把考点泄露给学生：

单项选择：`题目 → 选项 → 答案 → 解析 → 判分说明`。
填空：`题目 → 答案 → 解析 → 判分说明`，不得附选项章节。

- 题目中的每个空统一写为 `\_\_\_\_`（源文件中每个下划线前只有一个反斜杠）。多空写 `（1）\_\_\_\_`、`（2）\_\_\_\_`，从 1 连续编号。
- 无需挖空的概念题可直接提问。填空题必须说明任务，如填写所给词的形式或指定代词形式；语境不足时不能强行只认一个答案。
- 选择题选项每行 `- A: 内容`，至少两项，字母从 A 连续排列；无备注、提示、对错标记。答案章节只写一个正确选项字母。
- 填空答案每空一行 `- 1: 答案`；多种可接受形式用 ` / ` 分隔。判分说明明确空格、大小写及合理变体的处理；逐空记录，不能丢失部分正确的信息。
- 解析写出关键依据，不扩展未学知识。判分说明用于教师或 AI，提交前不展示。
- 作答前只展示题目和选项，不展示 frontmatter、文件标题、答案、解析或判分说明。答案同文件是维护便利，不是技术上的防泄题措施。

共享文章的多小题题组将来以一个材料文件保存，届时增设题组 schema；本版示例只实现单项选择和填空，不混入尚未定义的题组格式。

## 使用与维护

先按当前缺口、前置、考点范围和台阶选题，再选作答形式及难度。索引仅用于选题，正文按需读取。不得为了刷完索引而自动扩展学生学习范围。

学习进度记录 id、版本、作答结果、是否提示、首次或重做；统计不同来源和形式分别进行。停用旧题不删除学生历史。题目耗尽时允许同范围自编并明确来源，不冒充预设题。

工具依赖 Python 3 和 PyYAML。维护者在仓库根目录运行：

```powershell
python -X utf8 题库/管理.py check
python -X utf8 题库/管理.py index
python -X utf8 题库/管理.py export --type 语法选择
```

`check` 只检查格式和引用约束；`index` 生成根题库索引；`export` 筛选已校验且适用的题，生成 `题型工作区/<题型>/练习/` 的分发副本和索引。导出只写练习目录，不修改学生进度。历史残留文件不自动删除，导出索引是本次可用题目的唯一清单，停用或移出适用范围的旧文件不得继续选用。

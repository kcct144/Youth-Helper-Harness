# 完形填空做题流程

- 适用学段：初中、高中
- 核心顺序：判断材料可做性 → 建立篇章草图 → 逐空处理 → 全文验证
- 方法依据：`考点地图.md`
- 当前版本：0.3
- 更新日期：2026-08-26

## 总流程

```text
检查正文和选项的词汇门槛
→ 建立“谁、什么事、什么方向”的篇章草图
→ 决定完整通读放在作答前还是作答后
→ 每空提取最小有意义短语并代入
→ 排除有明确冲突的选项
→ 不确定时寻找前后文线索
→ 仍有多个答案时回到全文话题和情节
→ 标记低把握题
→ 至少完整通读全文一次并复查
```

## 第一步：检查材料可做性

先抽查正文理解和各题选项词汇。大量题目有两个以上选项不认识，或正文无法说出基本人物和事件时，先处理词汇或更换材料，不继续用技巧硬做。

面对学生目标考试的高中材料时，“材料偏难”是诊断结论，不是永久回避。先换难度匹配材料训练当前方法，同时把反复阻断理解的高频词义、短语或关键句结构安排为独立补漏，再逐级回到目标材料。

## 第二步：建立篇章草图

无论完整通读安排在前还是后，逐空作答前都必须先完成一次轻量定位：

1. 谁或什么是主要人物、事物？
2. 出现了什么目标、问题、行动或变化？
3. 整体态度和发展方向是什么？

只用短语或一两句中文回答，不逐句翻译。信息暂时不足可以标记“待更新”。详细方法见 `篇章意识.md`。

## 第三步：选择完整阅读策略

两种策略都可以，学生不需要同时执行两次精读：

- **先读后做**：适合能够较顺畅读懂文章、需要先掌握情节的学生。
- **先做后读**：适合看到大量空格容易卡住的学生；先逐空处理，完成后带答案完整读一遍。

无论选择哪种，都不能省略完整阅读，也不能省略作答前的篇章草图。

## 第四步：逐空执行

### 1. 先看四个选项是否认识

- 0～1 个生词：进入方法流程。
- 2 个生词：标记“词汇障碍”，该题不适合用于评价方法掌握。
- 3～4 个生词：停止硬猜，记录材料偏难。

如果只是学生不确定自己是否认识，让他先用中文说出每个选项的大意；不要由学习助手直接假定。

### 2. 提取最小有意义短语

只保留能决定搭配或意义的部分，例如：

```text
____ information
feel very ____
____ from the app
```

先在短结构中代入，减少整句同时处理的压力。

最小短语只是默认起点，不是每空必须停留的范围。四个选项词性相同、局部都能搭配，或空格承担逻辑、态度和篇章推进作用时，直接扩大到完整句、前后句、段落或全文；高中材料出现这些信号时按 `高中扩展.md` 处理。

### 3. 逐项代入并排除

每个选项至少检查：

- 词义是否符合；
- 放入短语是否自然；
- 与人物、动作或褒贬方向是否冲突。

能明确排除就说出理由，不能因为不认识而排除。

### 4. 局部不能决定时找线索

按由近到远的顺序扩大：

```text
当前短语 → 完整句 → 前后句 → 当前段 → 全文
```

重点寻找原词复现、同义复现、反义复现、转折、因果、人物态度和事件结果。

### 5. 回到话题并标记把握

如果仍有两个选项可选，问哪个更符合全文主线。仍无法确定时保留标记，不用编造理由把猜测包装成确定答案。

低把握答案标记为 `?`。后续题只能把没有挖空的正文和已有明确证据的答案当作确认信息，不能用一个 `?` 答案证明另一个答案。

## 第五步：全文验证

带着所选答案从头到尾读一遍，检查：

1. 故事或说明是否连贯；
2. 人物态度和褒贬方向是否前后一致；
3. 代词、动作和事件发展是否合理；
4. 标记的低把握题能否从后文得到新线索。

全文读起来顺也不是唯一证据。修改答案时应指出新发现的词义、搭配或上下文线索。

## 连续错的防护与回溯

同一段或相邻题连续出错时，优先检查篇章意识，不把每题立即拆成独立知识点：

```text
找最早的错误或 ? 题
→ 去掉它及后续待定答案
→ 用原有正文重新确认人物、问题和方向
→ 更新篇章草图
→ 再做这一串题
```

如果主线修正后多题一起解决，记录一个“篇章定位或上下文使用”问题，不记录成多个互不相关的方法缺口。

## 错误诊断顺序

```text
选项认识几个？
→ 作答前是否说出了谁、什么事和发展方向？
→ 是否提取了合适的短语？
→ 是否逐项代入和排除？
→ 是否寻找了上下文线索？
→ 是否利用了话题主线？
→ 是否完整读过并复查？
```

第一个断点决定补漏内容。若词汇门槛未达到，先归为词汇或材料难度问题，不继续诊断后面的技巧。

## 报告驱动的结束条件

只处理做题报告实际暴露的问题。学生能在 按证据需要安排的同类新空中独立执行刚补的步骤后，就可以结束本轮，并回到新的完整练习中获取下一份报告。不要因为已经打开“复现”就顺带讲完所有线索类型。

按证据需要安排的新空只能关闭本次单点补漏，不能单独证明高中整篇能力。高中“可独立”还需要在一篇难度相近的新完形中建立主线、处理至少一个局部不能决定的空，并完成全文复查。

## 新方法的维护入口

新的单词、搭配、话题或单题巧合不直接进入方法体系。多个独立可靠语篇出现现有流程无法处理的同一证据关系时，按 工作区维护约定 登记候选；通过准入后才修改本流程，并保留旧题、新题和反例的回归检查结果。

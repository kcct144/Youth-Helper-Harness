# 完形填空学习路径

- 适用学段：初中、高中
- 核心路线：先判断词汇门槛，再进行方法补漏
- 默认方式：报告驱动的查缺 → 补漏 → 回到新题检验

## 报告优先

学生提交做题报告、错题或原文时，只处理它实际暴露的问题：

```text
先查选项和正文是否读得懂
→ 区分词汇障碍、篇章意识与其他方法障碍
→ 只补第一个真实断点
→ 少量验证
→ 回到新完形继续做
```

报告没有出现的技巧、词义或线索类型保持未评估。学生没有要求系统学习时，不沿本路径自动补完所有方法。

## 第一关：材料与词汇匹配

### 查缺

- 让学生标出每道错题四个选项中的生词。
- 检查是否有大量题目达到两个以上选项不认识。
- 让学生用一两句中文说出文章主要人物、事件和结果，判断正文是否基本可理解。

### 分流

- **材料适合**：大多数题只有 0～1 个选项生词，且能说出文章大意，可以训练方法。
- **局部词汇缺口**：少数题有两个以上选项不认识，只处理这些高频或本次必要词汇，再回到原题。
- **材料整体偏难**：大量题有两个以上选项不认识，或无法理解文章主线。暂停技巧训练，换更容易的完形，并另行安排词汇积累。

材料整体偏难时，不要求学生把整篇所有生词一次背完，也不继续用正确率评价完形能力。

## 第二关：篇章意识

词汇基本够用后，先检查学生是否在逐空作答前建立了上下文：

- 能否说出主要人物或事物；
- 能否说出当前目标、问题或变化；
- 能否判断整体态度和发展方向；
- 是否把低把握答案当成后续题的事实。

如果出现同一段连续错，优先寻找最早改变人物、事件或态度理解的那一题。不要立即把连续错拆成多个词义问题。

完成证据：学生能在新文章开始时用短语建立篇章草图；局部无法决定时能主动寻找前后文，并把待定答案与确认信息分开。

## 第三关：代入与排除

先学最基础、负担最小的流程：

```text
提取短语 → 逐项代入 → 说出能排除的理由
```

完成证据：学生能自己截取合适的小结构，不把整句全部塞进脑中；能区分“我知道它不合适”和“我只是不认识它”。

## 第四关：找线索

按实际报告逐个补，不一次教完：

1. 报告出现原词照应，再学原词复现；
2. 出现换一种说法，再学同义复现；
3. 出现转折或对比，再学反义复现；
4. 形容词选择出现情感方向问题，再学褒贬法。

完成证据：学生不仅能圈出线索，还能说明线索怎样支持或排除某个答案。

## 第五关：全文检查

学生需要养成两个习惯：

- 根据作答后的新信息更新人物、事件和整体方向；
- 一篇完形至少从头到尾完整读一遍，并回查低把握题。

完成证据：局部有两个选项都说得通时，学生能主动扩大上下文；填完后能利用后文线索修正或确认答案。

## 高中扩展关：精辨和句篇证据

只有学生已经通过前面相关基础关，或真实高中题明确需要时才进入。详细内容见 `高中扩展.md`。

按报告只选择一个当前分支：

- **词都认识但分不清**：比较语境义、搭配对象、褒贬或语气、抽象与具体含义；
- **局部都成立**：判断逻辑关系、指代链、段落功能、态度或主题变化；
- **证据句看不懂**：只拆当前关键句的主干、修饰范围和连接关系，再回到选项；
- **单空能做、整篇不稳**：在难度相近的新整篇中标记低把握题并完成全文回查。

完成一个分支不自动证明其他高中能力。学生只暴露近义词问题时，不顺带讲完复杂论证和长句分析。

## 强化方式

补完报告中的问题后，优先让学生回到来源相近、词汇难度合适的新完形中检验。AI 当场只需用 按证据需要安排的同范围空格确认方法能被调用，不自动连续生成多篇材料。

如果新报告继续暴露同一个问题，再增加近变式或间隔复习；如果出现新问题，下一轮只处理新的第一断点。

## 暂不适合做当前完形的信号

- 多数题的四个选项中有两三个不认识；
- 即使解释选项后，正文仍无法理解；
- 做题主要依靠随机猜或按字面外形选择；
- 换成更容易材料后表现明显改善。

结论应表述为“当前材料与词汇水平不匹配”，不要给学生贴“不会完形”或“英语差”的标签。

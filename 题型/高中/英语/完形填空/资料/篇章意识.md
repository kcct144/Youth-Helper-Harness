# 完形填空篇章意识

- 适用学段：初中、高中
- 内容类型：题型方法
- 使用时机：选项和正文词汇基本可理解，但学生仍只看局部、忽略上下文或连续出错
- 核心目标：作答前建立篇章草图，作答中把每个答案接回全文主线

篇章意识不是逐句翻译，也不是先把所有空做对。它是先知道文章大致在讲什么，再理解每个空在这件事中起什么作用。

## 作答前的篇章草图

开始逐空作答前，先用已有正文回答三个问题：

1. **谁或什么？**主要人物、事物或说明对象是谁？
2. **发生什么？**目前出现了什么目标、问题、行动或变化？
3. **往哪里发展？**整体是解决问题还是遇到困难，态度偏正面还是负面，可能走向什么结果？

学生只需用短语或一两句中文回答，不要求精确翻译，也不要求提前猜出全部情节。文章信息不足时允许写“暂不确定”，后面读到新内容再更新。

## 确认信息与待定答案分开

篇章草图优先依据题目中没有挖空的正文、明确的人物关系和已经确认的答案。学生自己低把握填入的词只能作为假设，不能立刻成为后续题目的事实依据。

可以使用两种标记：

- `✓`：有明确词义、搭配或上下文证据；
- `?`：暂选，等待后文或全文验证。

这样可以防止“前一空猜错 → 把错误答案当线索 → 后面连续错”。

## 作答中的上下文意识

每个空先从局部开始，但要知道何时扩大范围：

```text
最小短语能唯一决定 → 使用局部证据
局部有两个选项都成立 → 看完整句和前后句
人物、态度或事件关系仍不清楚 → 看当前段
答案涉及主题、结果或首尾照应 → 回到篇章草图和全文
```

“看上下文”不是重新读一遍所有文字，而是带着一个明确问题寻找证据，例如：

- 这个动作是谁做的？
- 前面遇到的是什么问题？
- 后一句写的是原因还是结果？
- 人物此时的心情应与哪件事一致？
- 这个词是否在后文被解释、重复或对比？

## 段落推进

文章较长或情节有转折时，每读完一段，用几个字更新草图：

```text
背景 → 出现问题 → 采取行动 → 得到结果 → 表达主题
```

不要求所有文章都套这个结构。说明文可以改成“对象 → 特点或问题 → 原因 → 作用或结论”。关键是学生能说出当前段与全文话题的关系。

## 连续错的回溯方法

相邻或同一段连续错时，不先逐题补十个知识点。按顺序检查：

1. 找这一串中最早的低把握或错误题；
2. 回到它前面的确认信息，检查人物、问题和态度方向是否已经理解错；
3. 去掉该题及后续低把握答案，重新读原有正文；
4. 更新篇章草图；
5. 再按“局部 → 上下文 → 全文”重新处理这一串题。

如果重新建立主线后多题同时改正，主要断点是篇章意识，而不是多个独立词汇或技巧问题。

## 篇章意识微训练

根据报告只选择一种最小训练：

- **只读不填**：遮住选项，只说人物、事件和发展方向；
- **段落排序**：用短语排出背景、问题、行动和结果；
- **线索定位**：给出一个答案，让学生圈出支持它的前文或后文；
- **范围判断**：判断某空只需短语、前后句还是全文才能决定；
- **连错回溯**：从连续错题中找到最早改变主线判断的一题。

一次只练报告暴露的断点。学生能在一篇新材料中主动建立草图，并借助上下文避免同类连错后，就回到正常完形练习。

## 掌握证据

- 作答前能用简短中文说出人物、事件和大致方向；
- 局部证据不足时会主动扩大上下文，而不是继续凭感觉；
- 能区分正文中的确认信息和自己的待定答案；
- 连续错时会回查最早断点并更新主线；
- 能指出答案来自短语、前后句、段落还是全文。

## 常见误区

- 把“篇章意识”理解成逐句全文翻译，导致负担过大。
- 看完第一句就把话题固定下来，后面出现转折也不更新。
- 把自己低把握的答案当成确定线索，造成连续错误。
- 每空都强制看全文，反而忽略能直接决定答案的局部搭配。
- 只说“联系上下文”，却不能指出具体哪句话支持答案。

# 考点基础知识

记录“懂不懂、记不记得、知道怎么做、能不能做对”。不在本文件重复记录考点识别或具体句子成分定位；对应记录见 [考点识别能力](考点识别能力.md)、[句子分析能力](句子分析能力.md)。通用状态和证据约定见 [学习进度](../学习进度.md)。

- 知识理解：明白当前概念、规则与适用条件，不能只凭背过定义判断。
- 形式回忆：不看选项或表格能写出必要形式；不要求当前不需要的整表默写。
- 知道流程：知道先判断什么、再根据什么决定；与实际执行分开。
- 独立运用：在未提示关键线索的新情境中完成判断；写对检查另记词形、拼写和代回验证。

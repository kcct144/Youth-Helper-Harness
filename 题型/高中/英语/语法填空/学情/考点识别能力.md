# 考点识别能力

记录“看到什么提示，结合空格判断考什么”。概念知识在 [考点基础知识](考点基础知识.md)，句中关系定位在 [句子分析能力](句子分析能力.md)，这里不重复维护这两类状态。状态及证据约定见 [学习进度](../学习进度.md)。

- 观察提示：是否正确注意到有无提示词、词义、可能词性及所给形式。无提示词行记录是否注意到题面限制和候选信号，不把它当成脱离句子猜词类。
- 结合空格认考点：能将提示与句中作用、语境结合，判断当前语法问题并说明依据。老师已经告知考点后，答对不能算独立识别。
- “可能方向”不是答案规则或穷尽表，不凭提示词词性排除其他合理变化。无提示词也不限定只能填冠、介、连、代。

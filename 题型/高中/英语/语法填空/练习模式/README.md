# 高中语法填空练习模式

本目录维护 真实练习材料 高中语法填空练习模式的内容设计，采用 `module → unit → level` 结构。适用于没有共享词框、按题面说明填写适当单词或提示词正确形式的任务。

2026-09-26：完成首轮题库调研后，结合维护者提供的分类强化资料目录，按确认方向重排为 14 个单元。从句拆成三个单元，非谓语保留一个单元并细分内部内容，专项末尾安排易混对比与混合应用。维护者已授权边读边写、后续迭代，现已完成全部14个Unit的首版并补充题量，共60关，均有做前说明和题目或已校验整篇引用；局部题附答案、解析与来源。

## 组织方式

- 本目录对应一个 module；每个 unit 围绕一个明确范围，每个 level 服务一个具体目标。
- unit 文件夹拟采用 `两位序号-单元标题`，level 文件采用 `两位序号-关卡标题.md`，关卡序号在单元内从 01 开始。当前不批量创建空目录和关卡。
- 单元序号表示编排顺序，不代表学生必须从头学习；按实际缺口选择，最小补漏后回到真实材料 未见材料中检验。
- 单元和关卡的目标、边界集中在本 README 维护，全部已写目标见下方关卡表。

## 单元目录

| 序号 | unit 标题 | 主要目标与范围 |
| --- | --- | --- |
| 01 | 基础知识 | 词性与句子成分、基本句子结构、主语中心、分句边界、并列单位与完整谓语；具体起点待细化 |
| 02 | 判断空格需要什么 | 结合提示词与空格作用判断考点；有提示与无提示均覆盖 |
| 03 | 谓语动词 | 根据语境与结构判断时态、语态、主谓一致，组成完整形式 |
| 04 | 非谓语动词 | 根据当前结构、搭配和逻辑关系确定所需形式 |
| 05 | 名词 | 可数性、单复数、所属关系与相应形式 |
| 06 | 形容词、副词与词性转换 | 根据句中作用与修饰关系确定词性，再完成派生或形式变化 |
| 07 | 比较等级 | 根据比较范围、意义和结构判断并填写 |
| 08 | 代词 | 判断指代对象与句中作用，独立写出形式 |
| 09 | 冠词 | 结合名词短语、泛指特指和形式填写 |
| 10 | 介词 | 在具体搭配与语境关系中练习，只补当前必要范围 |
| 11 | 定语从句 | 判断先行词、从句结构与关系词作用，结合语境填写 |
| 12 | 名词性从句 | 区分主语、宾语、表语和同位语从句的当前结构需求，选择并填写引导词 |
| 13 | 并列句与状语从句 | 判断连接单位、并列或从属关系及语义，完成连接表达；末尾安排三类从句的混合判断 |

以上是练习内容组织目录，不是完整高中语法知识目录或新教学规则。正式知识以 [考点地图](../资料/考点地图.md) 和 [做题流程](../资料/做题流程.md) 为维护源；复杂考点的完整教学台阶仍待逐项完善。

## 单元内部编排

以下是各单元的内容分组，用于接收资料、规划关卡；实际已建level以下方关卡表为准。一组可拆成多关，也可按材料与目标合并；不照搬资料的“100题”数量。

| 单元 | 内容分组与顺序方向 |
| --- | --- |
| 01 基础知识 | 词性与成分的区别 → 基本句子关系 → 主语中心与完整谓语 → 修饰范围 → 分句边界与并列单位。共用词形概念在此解释，具体形式练习归专项 |
| 02 判断空格需要什么 | 提示词的词义、词性和形式 → 空格作用 → 两边结合判断 → 词性转换后继续变形 → 有提示与无提示混合识别。无提示词不限定为封闭词类清单 |
| 03 谓语动词 | 时态 → 语态 → 主谓一致 → 完整形式组合 → 时态、语态、一致的易混对比与混合填空。分别覆盖已有助动词和整个谓语待填的外观；具体时态关卡待材料核验 |
| 04 非谓语动词 | 共用概念与形式 → 动词不定式 → 动名词 → 现在分词 → 过去分词 → 非谓语易混对比与混合填空。各组结合实际材料再按搭配、定语、状语、补足语等作用拆关，不只背形式名称 |
| 05 名词 | 可数性与数量 → 单复数形式 → 所属关系 → 混合应用。派生为名词的过程归 Unit 06，本单元处理确定名词后的形式需求 |
| 06 形容词、副词与词性转换 | 句中作用与修饰对象 → 形容词、副词应用 → 派生为名词、形容词、副词或动词 → 转换后继续核对形式 → 易混对比与混合应用。后续数、谓语等判断调用相应单元 |
| 07 比较等级 | 比较关系与范围 → 所需形式及拼写 → 语境中的比较表达 → 原级、比较级、最高级混合应用 |
| 08 代词 | 指代对象与句中作用 → 必要形式回忆 → 有提示形式变化 → 无提示语境填写 → 混合应用；具体代词范围随材料确认 |
| 09 冠词 | 名词短语与限定需求 → 泛指、特指及形式 → 具体语境与搭配 → 混合应用 |
| 10 介词 | 当前搭配 → 时间、位置等语境关系 → 结构中介词的作用 → 混合应用；按实际材料选用，不扩成脱离题目的搭配大全 |
| 11 定语从句 | 先行词与从句边界 → 关系词在从句中的作用 → 关系代词与关系副词 → 介词与关系词组合等具体结构 → 易混对比与混合应用 |
| 12 名词性从句 | 主语、宾语、表语、同位语从句分组 → 各组的结构与意义需求 → 引导词填写 → 单元内易混对比与混合应用；不把认出从句名称当成会填 |
| 13 并列句与状语从句 | 并列连接的单位与关系 → 状语从句按语义关系分组 → 连接表达的易混对比 → 定语、名词性、状语从句的跨单元混合应用 |
| 14 完整语法填空 | 根据已学范围和实际缺口选择整篇 → 扩大混合范围 → 未见材料独立应用。按原题要求、语境和结构复杂程度选题，不按热点新旧排列能力等级 |

Unit 03、04、11—13 的易混对比先服务已学的具体判断。三类从句的跨单元练习统一放在 Unit 13 末尾，引用前两单元内容，不再重复维护知识讲解；关卡序号不要求学生必须顺序学完全部内容。

### 进阶内容的待定位置

用户目录中的“特殊句式”“with 复合结构和独立主格”保留为进阶材料入口，当前不增加必修单元，也不预设其全部内容已经准入。整套资料到齐后逐项核验：服务非谓语判断的内容优先放 Unit 04 进阶关；服务谓语或从句判断的内容归相应专项。只有确有独立训练目标、现有单元容纳不合适时，再讨论单列。

非谓语单元与 Unit 06 可能共用分词形式材料，按主要训练目标安排；同素材复用需标记，不将换分类或换问法计作未见迁移。

## 每关题量

按关卡目标安排题量，当前采用下列范围的下限作为基础版，必要时再补题：

| 关型 | 建议题量 | 本轮落实方式 |
| --- | --- | --- |
| 单点教学、基础分析与形式回忆 | 4—6题 | 每关4题 |
| 易混对比、关系对照 | 6—8题 | 每关6题，通常组成3组；组内不一定只换一个词 |
| 混合或综合应用 | 8—10题 | 每关8题，覆盖本关所列范围 |
| 完整语篇 | 每关1篇 | 保留原空数；现有两关各10空 |

题量按独立题目或任务计，不按答案中的单词数计。配对是教学呈现方式，不要求相同句型或两边题数完全相同；例如时间关系对照还包含限制性与非限制性的差别。比较等级第03关保留混合判断，按综合关8题安排。Unit 02仍是单点识别任务，每关4题。

这些数量用于内容编排，不是固定通关门槛；有提示答对、同源复习与未见迁移分别看待。实际补漏可按当前问题选题，不要求学生每次做完一整关；课内验证数量仍按问题需要决定。

### 共同使用边界

- 学生按已暴露问题选择关卡，不必顺序学完；基础概念和形式回忆不稳时，先用Unit 01及当前专项的小范围说明补前置。
- Unit 01用已补全的原句做结构分析；形式回忆关遮去目标词形；Unit 02要求先判断再填写，判断与填写分别看待。中文同义表述可接受，不能机械按术语字符串评分。
- 各专项的做前说明是教学提示。03-04明确限定一般现在时，03-05第5题限定按一贯表现理解，04-06明确限定动名词结构；条件已写在学生题面与维护说明中，不把有条件练习当自由选形证据。
- Unit 04可先做01—03，再做05—07补目的、主语与补足语，最后做04、08混合。其他单元内，综合练习可在相关教学之后使用；文件序号不是学生强制路线。
- 单句允许多词形式；无提示填空按题面限定一个词。已列合理变体逐项接受，未列但合理的答案仍结合语境复核。书写大小写、撇号、拼写错误与概念判断分别记录。
- 同一题用于基础辨认、专项应用、混合复习时，只换任务不算未见迁移。每道局部题附专题原题号；跨专题重复和与完整语篇的重叠见维护记录。
- 全部关卡的答案、解析、来源与核验状态均是维护信息，作答前只展示做前说明和题面。平台导入只取学生题面与做前说明，答案和解析独立保存，不能直接把整个Markdown作为学生页面。导入与验证状态见下方平台适配说明。

## 关卡设计方向

专项单元按实际需要安排以下任务，不固定关卡数量，也不要求每个单元机械重复同一结构：

| 任务 | 学生实际做什么 | 能支持的判断 |
| --- | --- | --- |
| 知识与形式 | 理解当前概念，独立写出必要形式 | 当前概念或形式是否掌握，不能直接推及语境运用 |
| 局部判断 | 判断主语、修饰对象、空格作用或相关语境 | 能否执行当前分析动作，不能代替完整填空 |
| 方法应用 | 阅读做前说明后完成句子或短语篇填空 | 提示后的方法应用，不是无提示迁移 |
| 易混对比 | 对照容易混淆的结构或语境，分别判断并独立填写 | 能否分清当前差异；成对呈现可能提示判断方向，不能直接当无提示迁移 |
| 混合练习 | 在几种已学情况之间自行区分并填写 | 当前混合范围内的独立运用；仍需检查标题和讲解是否提示考点 |

基础知识与考点识别可用选择题；词形回忆和填写必须包含独立输入。判断考点正确、选中正确答案与独立写对分别看待。不要求学生每题提交完整五步分析。

Unit 01 负责共用前置概念；各专项单元负责本范围的形式与应用，避免重复讲解。Unit 02 训练综合识别入口，各专项单元处理识别之后的求解。词性转换按实际目标归 Unit 06，已确定名词后的数与所属关系归 Unit 05；多步变化的题可关联多个目标，不强行互斥归类。

## 关卡文档格式

沿用阅读理解练习模式，每份 level 文档只保留两节：

1. **做前说明**：学生开始前看到的文字，用代码块包裹，便于复制到平台。教学关可讲当前方法；独立验证关不能提示具体考点、判断步骤或答案。
2. **题目**：必要的完整语境、题面要求、提示词与空格，或已入库题目的 ID、版本与选用范围。答案、合理变体、考点、解析、来源和核验状态放在题目节作为维护信息，作答前不展示。

未确定的题目写“待补”，不得当成可发布关卡。填空输入、多词答案与合理变体的实际判分支持须在发布前核对平台能力，不预设平台已经支持。

## 选材与使用边界

- 维护者已授权基于提供材料边看边写、持续调整。可以按既定目录选题、整理做前说明、重写经核验的解析及作必要的题面调整，并记录来源与改动；不自行编造整篇文章。新教学通则和复杂流程扩充仍按体系维护规则核验。
- 单句练习须保留足够语境；时间关系、指代、篇章连接等若依赖上下文，保留相关语段或整篇。
- 完整语篇用于综合训练，保留原题说明，不预设所有材料词数要求和空数一致。
- 本目录维护单元与关卡编排，`练习/` 保存统一题库导出的可用练习。已入统一题库的题目引用 ID 和版本，不复制维护正文；尚未入库的关卡题目确定后在关内维护来源与改编情况。
- 外部题库标签、答案、解析只作待核验材料。抽样用于检查设计覆盖，不等于全量校题，不据此推断高考考频。
- module、unit、level 标题也可能提示考点。专项通关、提示后答对、同篇改问法不能自动视为未见材料迁移；完整练习关也须核对是否见过材料。
- 不写入虚构学情，不把预列单元变成全范围普测清单。学生学习记录仍遵循本工作区 AGENTS。

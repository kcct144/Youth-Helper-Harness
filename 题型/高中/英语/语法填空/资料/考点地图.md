# 语法填空考点地图（试行）

适用范围：无共享词框的语法填空。学习目标：根据提示与空格需求识别考点，再进入对应求解流程。前置为当前任务所需的词义、词性、基本句子关系和词形，不要求先学完整套语法。

## 两边信息结合判断

“提示词是什么”只提供入口；“空格需要什么”包括词性、句子成分、连接关系和形式。二者结合后才确定考点。单词可有多种词性，不能机械按词尾归类；无提示词也不能直接认定只填某几类词。

| 观察入口 | 结合空格重点确认 | 可能进入的求解方向 |
| --- | --- | --- |
| 给出动词 | 所属分句是否需要谓语，是否有其他结构要求 | 谓语动词、非谓语动词，或词性转换 |
| 给出名词 | 是否仍需名词，数量、所属或修饰关系如何 | 单复数、所有格，或词性转换 |
| 给出形容词或副词 | 修饰什么，是否表达比较关系 | 词性转换、比较等级 |
| 给出代词 | 指代谁，在句中承担什么作用 | 代词形式 |
| 无提示词 | 缺限定、连接、指代、搭配成分，还是其他结构所需词 | 冠词、介词、代词、并列连词、从句引导词等 |

这是检索入口，不是互斥且穷尽的答案表。一个词可能经历多个变化，如先确定所需词性，再确定数或其他形式。

## 求解时要细分的范围

- 谓语动词：时态、语态、主谓一致。记录具体时态、时间关系和句型；识别为谓语只是进入求解，不能直接视为会判断时态。
- 非谓语动词：当前结构要求、固定搭配、逻辑关系及所需形式；不得使用“句子里已有动词就一定填非谓语”的绝对口诀，要区分分句和并列结构。
- 名词：词性、数量、可数性或所属关系。
- 形容词、副词与派生：句中作用、修饰对象、构词与所需形式。
- 比较等级：比较范围、语义和结构，不凭单个标志词机械作答。
- 代词：指代对象、作用与形式，基础形式不熟时先补回忆。
- 冠词：名词短语结构、泛指特指与形式。
- 介词：当前搭配和语境关系，只补当前必要内容。
- 并列连词、从句引导词：先看连接单位和关系，再判断结构、意义；从句类型和具体判断另行分范围记录。

目前仅给出这些入口，高中复杂时态、语态、非谓语和从句的完整台阶、边界、练习仍待逐项完善。不直接复制语法选择的 L 编号和初中完成门槛。题库台阶须结合考点、范围和前置理解。

# 语法选择学习路径

- 适用学段：初中，重点面向广东中考
- 内容类型：通用学习计划
- 核心路线：查缺 → 补漏 → 强化

本路径描述语法选择的通用课程顺序。学习助手应根据 `学习进度.md` 和实际诊断结果，把具体任务写入 `学习进度.md`，不要求所有学生按同一速度推进。

## 报告优先于完整课程

当学生带来一份可用的做题报告、错题或测验结果时，默认不按本文件从头推进完整课程，而是执行：

```text
报告暴露什么
→ 只确认这些问题的第一断点
→ 补到能解决最常见情况
→ 少量新题验证
→ 回到新练习获取下一份证据
```

一份报告可能暴露多个候选问题，但本轮默认只激活一个。解决后就结束本轮，不需要为了“学完整”补同考点的其他知识。例如报告只暴露主格、宾格和形容词性物主代词的混淆，就处理“人称代词 L1（简称：人）”；名词性物主代词和反身代词等以后真正出现在题目或报告中再学。

下面的阶段和周计划用于没有有效报告时的系统起步，或学生明确要求完整学习某题型时的规划参考。它们不能覆盖报告驱动的最小补漏原则。

## 最终目标

学生面对一道新题时，能够独立完成：

```text
观察选项 → 说出考点 → 说明空格作用
→ 使用对应判断步骤 → 选出答案 → 给出证据
```

整篇训练中，学生还能结合上下文检查答案，并在错误后判断自己错在“考点识别、流程记忆、步骤执行、语境理解还是执行检查”。具体步骤见 `做题流程.md`。

## 教学台阶与“点到为止”

每个核心考点都在对应的 `考点/*.md` 中定义了 L0、L1……等教学台阶。台阶不是难度标签，而是前置关系：前一级没有稳定，后一级通常没有可用的理解基础。

每次学习必须先确定“当前台阶”和“本次只解决的小目标”。教学、例题、干扰项和批改依据都不得超出当前台阶。资料文件里的“难点、特殊情况”和后续台阶是教师参考，不是看到后就要顺带讲完的课程清单。

进入某个考点前先做“前置基础检查”：确认学生能回忆或辨认完成本台阶所需的基本形式。比如学习“人（人称代词）”前，先检查主格、宾格、形容词性物主代词的基本形式；写不出或认不出时，先补这张最小基础表。做对过题不等于基础形式已经掌握。

“人、时、名、非、介、连、比、冠、情、词”只是导航简称。首次讲解必须写出完整名称并确认学生理解，不能让尚未理解概念的学生直接用简称回答。学生能解释概念和基本形式后，再逐步使用简称。

### 默认推进规则

满足以下证据后，才考虑进入下一台阶：

1. 当前台阶所需的前置形式或概念已经具备；
2. 能认出当前考点或本级结构；
3. 能用自己的话说出本级最短流程；
4. 能在无提示的同台阶新题中独立执行并说明证据，题量按证据需要决定；
5. 系统理解型考点进入更高台阶前，还应有新材料或稍后复查证据。

以上证据是“可以进入下一台阶”，不是“必须马上进入”。本次小目标达成后应先停下总结，不以“顺便讲一点”为由自动扩展。只有以下三种情况可以开启后续台阶：学习计划明确安排、可靠诊断或真实题目显示当前需要、学生明确要求继续深入。

### 越级题处理

真实题目偶尔会提前出现高阶内容。此时只解释完成当前题目所需的最小知识，明确告诉学生“这属于后续 Lx，现在先会处理这一题”，并且不立刻追加同类高阶训练。若它反复出现并影响得分，再协商调整计划。

## 第一阶段：会认考点

### 学习内容

- 先理解十类核心考点的完整名称和最简单例子，再把“人、时、名、非、介、连、比、冠、情、词”作为可选导航简称；不要求先背简称。
- 观察选项差异，只判断考点，暂时不要求选答案。
- 认识选项信号的边界，例如 `-s` 不一定是名词复数，`to` 不一定是不定式。
- 知道考点地图中另有六类低频考点；核心考点识别稳定后再集中辨认，或在真实题目首次出现时按需补充。

### 查缺方式

没有可用报告时，优先让学生拿真实材料练习（试卷/作业，或题库的题）。只有学生明确要求诊断或暂时拿不到真实材料时，才从少量混合选项开始，做到足以选出一个当前主问题就停止；不做十类全覆盖，也不连续生成多轮诊断。可以使用 `资料/题型示例/广东中考-语法选择.md` 做“只认考点”练习；该示例当前没有官方答案解析，不直接作为计分诊断答案来源。

### 建议完成证据

- 连续两轮混合识别达到约 80%，且主要判断能说出选项依据。
- 能指出至少两个“外形信号不能直接决定答案”的例子。

未达到时不必背更多长规则，只回到混淆的两三类考点进行对比。

## 第二阶段：按三类考点逐个突破

诊断结果始终优先。没有明显个体差异时，按“快速规则型 → 系统理解型 → 按题补充型”的主线推进。

### 第一层：快速规则型——名词、人称代词、冠词（简称：名、人、冠）

这三类的识别信号和判断流程相对集中，适合最先学习，用来建立考点意识和流程意识。

- **名词（简称：名）**：先判断是否用所有格，再判断可数性和单复数。
- **人称代词（简称：人）**：先完成 L1 的主格、宾格和形容词性物主代词；稳定后再进入名词性物主代词或反身代词。
- **冠词（简称：冠）**：先看可数名词单数和限定关系，再判断泛指、特指及 `a / an` 的发音。

这里的目标不是让学生记住三个答案口诀，而是让他第一次清楚体验：认出考点后，可以按固定顺序缩小答案范围。

### 第二层：系统理解型——谓语动词的时态和语态、词性、比较（简称：时、词、比）

这三类通常需要多步判断，应放慢速度，训练学生看句子结构和标志词。

- **谓语动词的时态和语态（简称：时）**：先会找谓语，再按一般现在、一般过去、一般将来和三种基本时态混合铺台阶；之后才进入进行、被动和完成。
- **词性（简称：词）**：先从名词与动词、`be` 后形容词开始，再学基础形副辨析；之后才扩展其他系动词和 `-ing/-ed` 形容词。
- **形容词或副词的比较（简称：比）**：判断形容词或副词 → 找比较标志和范围 → 检查固定结构 → 看句意。

每次重点解决一个流程断点，并通过近变式和易混考点对比确认迁移。

### 第三层：按题补充型——介词、非谓语动词、连词、情态动词（简称：介、非、连、情）

这些考点有基本判断流程，但部分题目还依赖搭配、用法和语境积累。本工作区不把它们当作独立的长期背诵课程：先教会学生识别考点和执行基本流程，只有真实题目暴露某个具体搭配或用法时，才做最小说明并可由学生自行记录。

- **介词（简称：介）**：积累动词、形容词和名词的常见介词搭配，并比较一般用法。
- **非谓语动词（简称：非）**：积累动词后接 `to do / doing` 的搭配，同时理解主动、被动和动作关系。
- **连词（简称：连）**：积累常见连词的逻辑关系，并在完整上下文中辨析。
- **情态动词（简称：情）**：积累情态动词的核心含义、语气强弱和典型语境。

若学生主动要求积累，或同一内容重复造成错误，再处理少量“用法或搭配 + 例句 + 易混对比”；不得一次展示长表，也不能因为考点属于这一类就自动安排背诵任务。

### 每个考点的小闭环

每个考点完成一个小闭环：

1. 检查当前台阶所需的最小前置基础。
2. 看选项识别考点。
3. 学习该考点的判断步骤。
4. 跟随一个最小示范。
5. 独立完成同一目标的基础题或变式题，题量按证据需要决定，证据足够立即停止。
6. 换新材料（真实试卷/作业，或题库的题）验证迁移；需要时再安排间隔复习。

### 建议完成证据

- 能不看提示复述该考点的主要判断顺序。
- 在新题中能先认出考点，再独立给出结构或语境证据。
- 同类关键错误连续两轮不再重复。

快速规则型达到证据后可尽快进入混合题；系统理解型需要更多变式；按题补充型不设置“一次学完”，以遇到新题能识别并调用基本流程为目标，具体未知搭配不作为本工作区的主线课程。

### 低频考点：按需插入

感叹句、特殊疑问词、从句引导词、`other` 系列、`few / little` 系列和复合不定代词不必平均分配固定课时。诊断中出现、真题或高质量练习反复出现，或它正是学生当前断点时，再读取对应文件完成一个小闭环，并加入后续混合复习。

## 第三阶段：混合强化

### 训练顺序

1. 两到三个容易混淆的考点混合。
2. 十类考点随机混合的单句练习。
3. 按学生已学范围加入低频考点。
4. 完整语篇，但暂不限时。
5. 完整语篇并加入合理时间要求。

每题都在答案记录中保留完整的考点名称；学生提交前不显示标签或简称。即使答案正确，如果考点判断错误或只能凭语感猜中，也不能提升相应能力状态。

### 建议完成证据

- 能稳定执行“认考点 → 用规则 → 查语境”的顺序。
- 在完整语篇中能够解释大多数答案依据。
- 错误从反复出现的基础规则问题，转为少量语境或低频考点问题。

## 第四阶段：整篇复盘与保持

完成一篇后按四层复盘：

| 错误层级 | 表现 | 下一步 |
| --- | --- | --- |
| 考点识别 | 没认出或认错考点 | 回到选项对比训练 |
| 流程记忆 | 考点正确，但说不出先做什么 | 学习并复述标准流程 |
| 步骤执行 | 知道流程，但某一步判断错误或被跳过 | 补对应知识并做单步变式 |
| 语境理解 | 结构可行，但句意或上下文判断错误 | 精读相关句段并比较选项含义 |
| 执行检查 | 会做但漏看标志、主语或上下文 | 使用固定检查清单后再限时 |

已经掌握的考点仍需间隔复习，建议在 1 天、3～4 天和 1～2 周后用少量新题检查。间隔可根据学生表现调整。

## 默认六周起步安排

在没有临近考试等特殊情况时，可采用以下首轮方案。介、非、连、情不预设独立积累线，只在相关题目暴露具体缺口时按需补充。

| 周次 | 主任务 | 完成证据 |
| --- | --- | --- |
| 第 1 周 | 核心考点识别诊断；快速突破名词、人称代词、冠词 | 能识别主要选项信号，并按流程解决三个考点的基础题 |
| 第 2 周 | 系统学习谓语动词的基本时态；按题补充必要用法 | 能从谓语、主语、时间和语态说明选择依据 |
| 第 3 周 | 系统学习词性、比较；复习基本时态 | 能先判断句子成分或比较结构，再选择词形 |
| 第 4 周 | 学习介词、非谓语动词的基本流程；按题补充具体缺口 | 能先查搭配、再看一般关系或非谓语结构，知道未知搭配可暂记 |
| 第 5 周 | 学习连词、情态动词的基本流程；混入前面考点复习 | 能结合逻辑和语气判断，不因个别积累项偏离主线 |
| 第 6 周 | 十类随机混合、完整语篇、适度限时和复盘 | 能认考点、走流程、说证据，并确定下一轮主攻点 |

这六周只是第一轮，不代表介、非、连、情已经积累完成。后续周期继续用错题和新语篇扩充积累。

如果学生的缺口集中，跳过已经有稳定证据的内容，尽快进入相关考点和混合强化；如果十类考点普遍不稳，可以延长补漏阶段，不为赶周次跳过掌握证据。临近考试时按照高频错误和得分收益压缩，不机械覆盖全部考点。

## 单次 30 分钟参考结构

| 环节 | 时间 | 学生活动 |
| --- | ---: | --- |
| 查缺 | 5 分钟 | 只看选项判断 3～5 题的考点 |
| 补漏 | 10 分钟 | 学一个判断步骤，分析少量代表题 |
| 强化 | 12 分钟 | 独立完成基础题或变式题；只有本轮暴露搭配缺口时才顺手记录 |
| 总结 | 3 分钟 | 记录错误层级、掌握证据和复习时间 |

时间较短时减少题量，不省略“先判断考点”和最后复盘。

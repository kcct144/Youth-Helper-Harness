# 语法选择考点：名

- 考点范围：名词的单复数和所有格
- 考频：核心考点
- 教学类型：快速规则型
- 学习目标：能从选项认出名词考点，先判断所有格，再判断单复数

## 考点特征

选项通常是同一名词的不同形式，例如：

```text
student / students / student's
child / children / children's
```

看到单数、复数、`'s` 或 `s'` 的对比，优先考虑“名”。但还要检查 `-s` 是否可能是动词第三人称单数，`'s` 是否可能是 `is / has` 的缩写。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 识别 | 从选项认出单数、复数和所有格形式 | 不要求判断答案 |
| L1 基础流程 | 先判断是否表示所属，再用常见数量词判断规则可数名词的单复数 | 不规则复数、不可数名词、复数所有格 |
| L2 名词性质 | 不规则复数和常见不可数名词 | 复杂所有格和省略 |
| L3 所有格边界 | 复数所有格、不规则复数所有格、`at Tom's` 等省略 | — |

默认从 L1 停下：学生会对规则可数名词执行“先所有格，后单复数”即可完成本轮。只有当前级稳定、真实题目需要或学生明确追问，才进入下一台阶。

## 标准思路

```text
确认空格需要名词
→ 先看是否表示所属：空格后的名词属于谁或什么？
→ 需要所属，用所有格
→ 不需要所属，再判断可数或不可数
→ 根据数量词和上下文选择单数或复数
→ 代回验证所属关系和句意
```

## 重点

- 空格后有另一个名词时，先检查是否构成“某人的某物”。
- `a / an / one / each / every` 常提示可数名词单数。
- `many / several / a few / few` 常提示可数名词复数。
- `some / a lot of` 后既可能是可数名词复数，也可能是不可数名词，要先判断名词性质。
- `other + 可数名词复数` 是常见结构，如 `other students`。

## 难点

- 区分复数 `students`、单数所有格 `student's` 和复数所有格 `students'`。
- 记住 `children / men / women / feet` 等不规则复数。
- 不可数名词通常没有复数形式，如 `advice / information / water`。
- 所有格不只看“后面有没有名词”，还要确认语义上确实存在所属或修饰关系。

## 特殊情况

- 不规则复数的所有格仍加 `'s`，如 `children's books`。
- 复数已经以 `s` 结尾时，所有格通常只加 `'`，如 `students' desks`。
- 所有格后面的地点或事物有时可以省略，如 `at Tom's`，属于较低频用法，不能把“后面没有名词”当成绝对排除规则。

## 例题与解析

### 例题一

Many other ____ joined the school club.

- A. student
- B. students
- C. student's

- 答案：B
- 考点特征：同一名词的单数、复数和所有格。
- 判断流程：空格后没有表示被所属事物的名词，不用所有格；`many other` 后接可数名词复数，所以选 `students`。
- 来源：自编例题

### 例题二

This is my ____ new bicycle.

- A. sister
- B. sisters
- C. sister's

- 答案：C
- 考点特征：名词形式对比。
- 判断流程：自行车属于妹妹，空格后有 `new bicycle`，需要所有格 `sister's`。
- 来源：自编例题

## 常见错误

- 看到 `s` 就选复数，不先检查所有格。
- 看到空格后有名词就机械选择所有格，不判断所属关系。
- 把 `some` 当成只能接复数，忽略不可数名词。
- 答案碰巧正确，但说不出先判断所有格还是单复数。

## 掌握标准

- 能从选项认出名词考点。
- 能先判断是否需要所有格，再判断单复数。
- 能解释至少一个数量信号或所属关系。
- 能在改变数量词或后续名词的变式题中继续正确使用流程。

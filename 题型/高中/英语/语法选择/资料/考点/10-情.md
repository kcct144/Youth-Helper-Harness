# 语法选择考点：情

- 考点范围：情态动词的形式、意义和语气
- 考频：核心考点
- 教学类型：按题补充型
- 学习目标：能确认情态结构，并根据能力、许可、可能、义务和建议等语境选择

## 考点特征

选项常出现不同情态动词，例如：

```text
can / may / must
could / should / might
mustn't / needn't / can't
```

看到多个情态动词并列，或选项主要改变语气和可能性时，优先考虑“情”。

## 教学台阶与默认停止点

| 台阶 | 本级只解决什么 | 暂不展开 |
| --- | --- | --- |
| L0 结构识别 | 情态动词后接动词原形 | 语气强弱大全 |
| L1 核心意义 | `can` 的能力、`should` 的建议、`must` 的义务 | 推测和委婉差异 |
| L2 可能与委婉 | `may / could / might` 的常见可能或请求语境 | 复杂推测 |
| L3 否定辨析 | `mustn't / needn't / can't` 的禁止、不必和否定推测 | 复杂替代表达 |
| L4 扩展表达 | 推测强弱及 `have to / be able to` 等相关结构 | — |

默认从 L0、L1 开始，每次只比较当前语境需要的两三个意义。不得在学生刚掌握“情态动词后原形”时立即用复杂推测或委婉程度考他。

## 标准思路

```text
确认空格后是否接动词原形
→ 判断句子表达能力、许可、可能、建议、义务、必要还是推测
→ 比较语气强弱和肯定、否定
→ 检查时间背景和委婉程度
→ 代回上下文验证说话人的真实意图
```

## 重点

- 情态动词后接动词原形。
- `can / could` 可表示能力，也可用于请求；`could` 的语气常更委婉。
- `may / might` 常表示可能或许可，具体强弱看语境。
- `must` 常表示强烈义务或有把握的推测。
- `should` 常表示建议、责任或“应该”。

## 难点

- 情态动词的选择主要依赖说话人的意图和语境，不能只背一个中文意思。
- `mustn't` 表示“禁止”，`don't have to / needn't` 表示“不必”，意思不同。
- `can`、`may`、`could` 都可能出现在请求或许可中，语气和场景有差异。
- 情态动词后动词形式正确，不代表情态意义一定正确。

## 特殊情况

- `must` 表推测时通常表示把握较强；否定推测常用 `can't`，不是简单使用 `mustn't`。
- `could` 既可能是 `can` 的过去式，也可能是现在的委婉表达。
- `had better`、`have to`、`be able to` 与情态意义相关，但结构不完全等同于单个情态动词，需要分别积累。

## 例题与解析

### 例题一

You ____ wear a helmet when riding a bicycle. It is safer.

- A. should
- B. might
- C. could not

- 答案：A
- 考点特征：不同情态动词。
- 判断流程：句子给出安全建议，语气适合使用 `should`。
- 来源：自编例题

### 例题二

Students ____ run in the science lab because it is dangerous.

- A. needn't
- B. mustn't
- C. may

- 答案：B
- 考点特征：情态动词的否定形式。
- 判断流程：危险场所禁止奔跑，`mustn't` 表示“禁止”；`needn't` 只表示“不必”。
- 来源：自编例题

## 常见错误

- 只看情态动词后是不是原形，不判断语气。
- 混淆“不必”和“禁止”。
- 把 `could` 一律理解成过去时。
- 依据中文单字对应，不读完整情境。

## 掌握标准

- 能确认情态动词后接动词原形。
- 能区分能力、建议、义务、许可和可能等主要意义。
- 能解释 `mustn't` 与 `needn't` 的差别。
- 能在新语境和间隔复测中选择合适语气，而不是只靠固定翻译。

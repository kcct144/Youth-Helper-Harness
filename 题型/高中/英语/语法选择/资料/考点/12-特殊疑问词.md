# 语法选择考点：特殊疑问词

- 考点范围：`who / what / which / whose / when / where / why / how` 等
- 考频：低频考点
- 教学类型：按题补充型
- 学习目标：能根据缺失信息、句子成分和上下文选择特殊疑问词

## 考点特征

选项常是不同特殊疑问词，例如：

```text
who / when / why
what / which / whose
where / how / when
```

它们既可用于直接疑问句，也可引导宾语从句等结构。

## 标准思路

```text
先看上下文缺少哪类信息
→ 人、物、选择范围、所属、时间、地点、原因还是方式
→ 再看疑问词在句中是否充当主语、宾语、定语或状语
→ 检查直接疑问或从句语序
→ 代回上下文验证问答是否对应
```

## 重点

- `who` 问人，`what` 问事物或内容。
- `which` 常在明确范围中选择；`whose` 询问所属。
- `when` 问时间，`where` 问地点，`why` 问原因，`how` 问方式或状态。
- `how many / how much / how long / how often` 等组合要结合被询问的信息。

## 难点

- 不能只根据后面的单词选择，要看前后完整意思。
- 特殊疑问词进入宾语从句后通常使用陈述语序。
- `what` 和 `which` 的差别常在于是否有明确选择范围。
- `who`、`what` 可在从句中作主语，此时后面直接接谓语。

## 特殊情况

- `how` 可与形容词或副词构成多种疑问短语，如 `how far / how soon`。
- `whose` 后可接名词，也可在语境清楚时独立使用。
- 特殊疑问词与从句引导词会有交叉；如果重点是从句是否完整，应同时参考 `13-从句引导词.md`。

## 例题与解析

### 例题一

The children wanted to know ____ was inside the tower.

- A. who
- B. when
- C. why

- 答案：A
- 考点特征：不同特殊疑问词。
- 判断流程：空格指塔里的人，并在从句中作主语，所以用 `who`。
- 来源：自编例题

### 例题二

—____ did the bell stop ringing?
—Because a cat was sleeping on the button.

- A. Where
- B. Why
- C. How many

- 答案：B
- 考点特征：问答信息对应。
- 判断流程：回答由 `Because` 引出原因，问题应使用 `Why`。
- 来源：自编例题

## 常见错误

- 不看回答内容，只凭句子翻译选择。
- 混淆 `what` 和 `which` 的范围。
- 宾语从句中仍使用疑问语序。
- 认出问人或问物，却没有检查疑问词在从句中的成分。

## 掌握标准

- 能根据缺失信息选择主要疑问词。
- 能说明疑问词在句中的作用。
- 能处理直接疑问句和简单宾语从句中的语序。
- 能在问答对比和明确范围的变式中正确选择。

# 语法选择考点：other 系列

- 考点范围：`other / another / the other / others / the others`
- 考频：低频考点
- 教学类型：系统理解型
- 学习目标：能根据后面是否有名词、数量范围和是否特指选择正确形式

## 考点特征

选项常集中出现：

```text
other / another / the other
others / the others
```

看到这些形式对比时，先判断它们后面是否需要接名词，再判断范围和特指。

## 标准思路

```text
先看空格后有没有名词
→ 有名词：考虑 other、another、the other
→ 没有名词：考虑 others、the others
→ 再判断是“另一个”、两者中的另一个，还是一组中的其余部分
→ 判断是否特指
→ 代回上下文检查数量范围
```

## 重点

- `other + 可数名词复数或不可数名词`，表示“其他的”。
- `another + 可数名词单数`，常表示“另一个、再一个”。
- `the other` 常表示两者中的另一个，也可修饰特定范围中的其他名词。
- `others` 相当于 `other + 复数名词`，后面不再接名词。
- `the others` 表示特定范围内剩余的全部人或物。

## 难点

- 后面是否有名词只是第一步，还要判断数量和特指。
- `another` 不等于所有语境中的“其他”，它通常强调再一个或不同的一个。
- `others` 和 `the others` 的关键区别是是否指特定范围内的其余全部。
- `the other + 复数名词` 可表示特定范围内其他的若干项，不能只记“两者中的另一个”。

## 特殊情况

- `another + 数词 + 复数名词` 可表示“再……个”，如 `another two days`。
- `one ... the other ...` 常用于两者；`some ... others ...` 常表示一些……另一些……。
- `each other` 和 `one another` 表示“彼此”，属于固定表达。

## 例题与解析

### 例题一

Emma had two keys. One was small, and ____ was large.

- A. another
- B. the other
- C. others

- 答案：B
- 考点特征：`other` 系列对比。
- 判断流程：明确只有两把钥匙，指两者中的另一把，使用 `the other`。
- 来源：自编例题

### 例题二

Some students stayed downstairs, while ____ climbed the tower.

- A. other
- B. another
- C. others

- 答案：C
- 考点特征：`other / another / others`。
- 判断流程：空格后没有名词，表示另一些学生，使用代词 `others`。
- 来源：自编例题

## 常见错误

- 后面没有名词却选择 `other`。
- 看到“另一个”就选 `another`，忽略两者限定。
- 混淆 `others` 和 `the others` 的特指范围。
- 只背固定搭配，不在上下文中数清范围。

## 掌握标准

- 能先根据后续名词排除不合适形式。
- 能区分一个、两个和一组中的其余部分。
- 能说明是否特指。
- 能在改变数量范围的变式题中继续正确选择。

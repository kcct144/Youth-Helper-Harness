# 语法选择考点：few / little 系列

- 考点范围：`few / a few / little / a little`
- 考频：低频考点
- 教学类型：快速规则型
- 学习目标：能根据可数性和肯定、否定含义选择正确形式

## 考点特征

选项常出现：

```text
few / a few / little / a little
```

判断需要同时处理两个维度：后面的名词是否可数，以及句子表达“有一些”还是“几乎没有”。

## 标准思路

```text
先看后面的名词
→ 可数名词复数：在 few / a few 中选择
→ 不可数名词：在 little / a little 中选择
→ 再看句意是肯定“有一些”还是否定“几乎没有”
→ 有 a 通常偏肯定；没有 a 通常偏否定
→ 代回上下文验证
```

## 重点

- `few / a few` 修饰可数名词复数。
- `little / a little` 修饰不可数名词。
- `a few / a little` 表示“有一些”，通常带肯定意味。
- `few / little` 表示“几乎没有”，通常带否定意味。
- 先判断可数性，再判断句意，不能颠倒。

## 难点

- 中文都可能翻译成“少”，但语气不同。
- `time / money / water / information` 等通常为不可数名词。
- 句中出现 `but / so / enough` 等上下文信息时，会影响肯定或否定判断。
- 不能只看到字母 `a` 就机械选择，还要确认名词类型。

## 特殊情况

- `quite a few` 表示“相当多”，不是“相当少”。
- `only a few / only a little` 虽然形式带 `a`，语境仍强调数量有限。
- `few` 可代替人或物独立使用，但中考语法选择中更常见的是修饰名词。

## 例题与解析

### 例题一

Only ____ students knew how to open the old door, but they were willing to help.

- A. a few
- B. a little
- C. little

- 答案：A
- 考点特征：`few / little` 系列。
- 判断流程：`students` 是可数名词复数，只能考虑 `few / a few`；句子表示确实有一些学生，选 `a few`。
- 来源：自编例题

### 例题二

There was ____ time left, so they had to hurry.

- A. few
- B. little
- C. a few

- 答案：B
- 考点特征：数量词形式对比。
- 判断流程：`time` 是不可数名词；后文“必须赶快”说明几乎没时间，选择 `little`。
- 来源：自编例题

## 常见错误

- 不判断名词可数性，只凭中文选。
- 混淆“有一些”和“几乎没有”。
- 认为带 `a` 的形式后一定接单数名词。
- 忽略 `so / but` 等上下文信号。

## 掌握标准

- 能先区分可数名词复数和不可数名词。
- 能解释带 `a` 与不带 `a` 的语气差别。
- 能利用上下文判断肯定或否定含义。
- 能处理 `only a few`、`quite a few` 等常见变式。

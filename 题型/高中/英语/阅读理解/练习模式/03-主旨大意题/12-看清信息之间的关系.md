# 12 看清信息之间的关系

## 做前说明

```
抓到几个关键词之后，还要看它们是怎么连起来的：

- but / however：前后有转折；
- because：后面说明原因；so / therefore：后面给出结果或结论；
- if：说明在什么条件下；
- and / also：连接或补充信息。

先看前后各说了什么，再用“但是、因为、所以、如果、还”等短词把意思连起来。遇到 not 等否定表达，也要保留它的意思。

本关先练关系词明确、关系简单的句子，不要求分析复杂语法。
```

## 题目

### 阅读材料（原文节选）

In the wild, a group of pelicans work together to catch fish. But Big Bird didn’t have a group, **so** the workers fed it fish.

### 题目

这里的 so 把哪两部分连成了“原因—结果”？

A. 工作人员喂鱼是原因；Big Bird没有群体是结果。  
B. 鹈鹕一起捕鱼是结果；工作人员喂鱼是原因。  
C. Big Bird没有群体是原因；工作人员给它喂鱼是结果。  
D. Big Bird想回到群体是原因；野外鹈鹕停止捕鱼是结果。

**答案（维护信息）：** C  
**考点：** 看清关系词连接的两部分，保留因果方向。  
**解析：** so 后面给出结果：工作人员喂 Big Bird 鱼；前面 “didn’t have a group” 说明原因。A把因果倒置，D加入原文没有的信息。

**来源与核验：** 广东省深圳市福田区红岭实验学校（上沙）2025—2026学年八年级上学期开学英语试题，阅读理解原题第51—55题。截取原文第二段的原因与结果句，按原文核对关系方向。

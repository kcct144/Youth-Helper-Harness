# 阅读理解练习模式

本目录维护阅读理解练习模式的内容设计。平台结构为 `module → unit → level`；本目录对应“阅读理解” module。

逐关导航、选材特征、初步出题思路及内容状态见 [关卡出题索引](关卡出题索引.md)。索引每关一行；实际题目仍在对应 level 的“题目”节维护。

本目录与 `练习/` 分工不同：这里维护单元、关卡及其做前说明和题目编排；`练习/` 保存统一题库导出的可用练习。已入统一题库的题目以题库为唯一维护源，本目录引用题目 ID 和版本，不再复制维护一份题文。

2026-09-24 从现有材料另行精简了对话补漏短题 RC-MICRO-001—008（版本1），可从 [预设练习索引](../练习/索引.md) 按当前缺口选用。原关卡的完整材料与平台任务保留；短题是另行改写设问或作答形式的版本，不把短题正文再抄回关卡。题目元数据记录来源关卡与同源组；见过对应关卡文章后，这些短题不能作为未见材料迁移。

## Unit：单元

一个 unit 围绕一类明确的阅读能力或学习问题组织若干 level。单元主题、适用基础和范围由维护者逐项确认，不直接把知识目录全部转换成课程。

每个 unit 使用一个文件夹，命名为 `两位序号-单元标题`。序号表示编排顺序，不表示所有学生必须从第一单元依次学习。

## Level：关卡

一个 level 是一次完整的练习任务，有明确主题、做前说明和题目内容。它应服务一个具体学习目标，不以“多做一篇”代替目标定义。

每个 level 使用一个 Markdown 文件，命名为 `两位序号-关卡标题.md`，保存在所属 unit 文件夹内。关卡序号在各 unit 内从 `01` 开始。

每份关卡文档只保留两项内容：

1. **做前说明**：学生开始前实际看到的文字，对应平台的关卡讲解内容，用代码块包裹，便于整段复制。答案、解析、维护标签和核验信息不写进这里。原 66 关的做前说明按**教学关**写成，写明了方法与步骤；另增的 19 个完整阅读练习关只说明独立完成整组任务，不提示具体答案。两种关都用于教学练习，不能自动当作未见材料迁移验证；若某关要当独立验证关使用，必须换成不含方法、不提示考点的版本，不能直接沿用。
2. **题目**：文章和小题，或已入库题目的 ID、版本及选用小题。常规阅读题保留完整文章，小题从 1 连续编号，每题独立提供 A、B、C、D 四个选项。知识辨认或局部方法训练可改编为选择题、填空题，具体形式逐关讨论；填空是否能直接发布以平台实际支持为准。每道小题后跟答案、考点标签和解析，这部分是维护信息，作答前不展示给学生。

关卡的主题、单一目标和当前边界按 unit 集中记在本文件下方，不在关卡文档重复。适用材料、具体出题思路和完成证据随每关实际题目一起确定；当前不额外建立逐关验收表或固定题量。未确定的题目写“待补”，不得伪装成可发布内容。

## 逐关出题方式

- 方法应用关通常给一篇阅读材料，让学生实际做对应题目；教学先选简单、线索明确的情况，再练更复杂的情况。
- 常见问法关练的是识别考点：可以给一篇含多种设问的阅读原题，让学生判断“第几题是推理判断题”等；本轮不要求把这些阅读小题全部做完。四选一时应选取有唯一目标题的题组，或将题号组合设计成唯一正确选项。
- 知识型关卡可以设计多道选择题；适合局部辨认或补全的内容，也可以讨论改成选择题或填空题。未入统一题库的改编题在本关维护，标明来源与改编情况。
- 按维护者 2026-09-23 的授权，先完成逐关索引和初步思路，再持续接收资料；能确定适配的材料直接整理进相应 level 并同步状态，不逐题重新申请。有歧义、缺上下文或答案不能确定时标待核验。本次索引阶段不批量编写文章或题目。
- 答对考点识别题只说明认出了设问，不等于会解该题；阅读习惯类仍不能仅凭选择题正确就判断习惯已改变。具体题目落地时再写清它能支持的判断。

## 做前说明与独立作答

关卡文档中的内容不应整体发送到学生答题页面。做前说明对应平台的关卡讲解内容；答案、解析、维护标签及核验信息不进入做前说明。

正式独立作答前不得透露答案、具体考点、定位位置或解题提示。若后续设计需要先讲方法再练习的教学关，须先明确其与独立验证关的边界；接受方法提示后的表现不能记录为无提示迁移。

平台会展示 module、unit 和 level 标题，因此学生可见标题也需检查是否提前透露待评估的考点。需要隐藏目标的验证关，其展示方式在发布前另行确认。

本地 Markdown 是维护文档，不是防泄题机制；学生作答时只展示允许在当前阶段出现的内容。

## 编排与使用边界

- 先确认 unit 和 level 主题，再逐关整理做前说明与题目，不自动生成大量课程或例题。
- 默认整理维护者提供的材料；已授权在材料基础上调整设问、选项、挖空和编排，并补写经核验的答案与解析，实质性改编须标明。默认不自行编造整篇文章；正式扩充教学方法仍按体系维护规则处理。
- 同一材料可用于多个关卡，以教学适配为先，不为去重舍弃合适材料。可复用材料编号或引用维护源，实际使用时仍须保证各关文章与题目完整；重复材料不自动计作未见材料迁移。
- 根据学生报告选择当前实际暴露的一个问题，不沿目录自动扩课；关卡序号不等于能力等级。
- 主旨、篇章、定位、同义对应及题型流程按实际证据分层，高中扩展不自动分配给基础薄弱学生。
- 平台标签、答案和解析均须结合原文核验；格式通过不等于内容正确。
- 一次答对、通关、获得奖励或提示后重做，不等于稳定掌握；同篇改问法不算完全未见材料迁移。
- 最小补漏完成后进入强化，并换未见材料检验，带回结果继续判断。
- 配对阅读单列，不在本目录编排；回答问题类不纳入当前练习体系。多空共享句子选项池沿用七选五独立体系。
- 关卡按“怎么做对”设计，不设“不要……”式反向关卡；易错点在该关的做前说明里说一句即可，不单独成关。

| 03 指代人的情况 | `he / she / they` 等指人时的单复数与人物信息匹配 |
| 04 指代物的情况 | `it / one / ones` 等指物或指同类事物时的匹配 |
| 05 指代句子或观点的情况 | `this / that / it` 指前面的整个动作、事实或观点 |
| 06 完整阅读练习 | 在完整议论文题组中核对 it 对前一事实的指代，并完成混合题 |

边界：“最近的名词只是候选，不是规则”写成 02 关讲解里的一句，不单独成关。候选对象不匹配时继续向前寻找，并检查这一段在延续谁或什么。

### Unit 08 文章结构题

| 关卡 | 单一目标 |
| --- | --- |
| 01 文章结构题常见问法 | 认出 `How is the passage organized?` / `How does the author develop the passage?` 这类问法 |
| 02 文章结构题基本流程 | 先看有没有开头总，再看有没有结尾总，中间是分 |
| 03 开头总 | 第一段或开头几句在不在提中心 |
| 04 结尾总 | 最后一段在不在总结、呼应或表态 |
| 05 中间的分怎么展开 | 分项并列、举例、时间先后、对比 |
| 06 总可以出现多处 | 总—分—总—总、总—总—分—总这类变体怎么认 |
| 07 完整阅读练习 | 通过段落功能关系判断一篇说明文的总述、展开与总结，并完成混合题 |

边界：以“总—分—总”为中心，不背结构名称；时间顺序、对比、分类归入 05 关“分怎么展开”。“用选项核对，而不是只数段落”“`first / then / finally` 只是线索”写成 02 关讲解里的话。高中研究类、议论类结构归以后的高中单元。

### Unit 09 句子还原题

| 关卡 | 单一目标 |
| --- | --- |
| 01 句子还原题常见问法 | 认出 `Which sentence can be put in the blank?` / `Where can the sentence best go?` |
| 02 句子还原题基本流程 | 主旨与段落功能 → 读候选句 → 看前一句 → 看后一句 → 代入通读 |
| 03 和前面关系紧密 | 先练前句线索明显的回答、解释或延续，再确认后句通顺 |
| 04 和后面关系紧密 | 先练后句明显承接候选句的问题、对象或概括，再确认前句通顺 |
| 05 留意代词 | 先练对象明确的向前指代，找到对象后代入核对；复杂指代按需处理 |
| 06 留意起承转合的词 | 用 however、therefore、also 等判断整句与上下文的衔接方向 |
| 07 留意连词连接的内容 | 确认 and、but、because、so、if 等连接哪两部分，不把候选句内部连接误当成空格两侧的关系 |
| 08 原词与同义复现 | 用原词、同义词、上下位概念接上前后 |
| 09 总述与分述衔接 | 总述句要与后面的例子、分述相连 |
| 10 前后一起通读 | 综合代入通读，前后都要接上；时态与人物变化须有语境依据 |
| 11 完整阅读练习 | 在完整说明文题组中用问题与后续解释的衔接定位段首补句，并完成混合题 |
| 12 完整阅读练习（段落衔接） | 将段首提问补句与段间承上启下的陈述句放在整篇中辨认 |

边界：本单元只处理单个独立句子的位置判断；多空共享句子选项池转七选五体系。该题型按地区卷型启用，学生卷面没有出现时不主动训练。03—09 按主要线索分情况练习，情况可以重叠，不是互斥题型；前侧或后侧是本关重点，不意味着另一侧可以矛盾。06 与 07 按任务侧重点区分，不考连接表达的词性分类。

# 阅读理解做题流程

- 适用学段：初中、高中
- 核心顺序：略读建图 → 识别题型 → 扫读定位 → 证据精读 → 选项核对
- 方法依据：`考点地图.md`、`分层阅读与翻译边界.md`、`主旨意识.md`
- 当前版本：0.6
- 更新日期：2026-09-23

## 总流程

```text
观察版式、标题、小标题、图片和段落
→ skimming：不逐句翻译，建立“对象 + 重点 + 段落功能”的主旨草图
→ 读题干，判断题型和要找的信息
→ scanning：用定位词和结构预测找到证据区
→ close reading：读定位句及必要上下文
→ 先用自己的话说证据意思
→ 逐项核对，排除有明确问题的选项
→ 选择后说明“题型 + 位置 + 证据”
→ 完成整篇后检查答案是否与主旨和原文范围一致
```

## 第一步：略读建立主旨

默认先略读，再看具体题目。应用文、广告、图表等先调查用途和信息结构；记叙文先抓人物、事件变化和结果；说明议论文先抓对象、问题、观点和结论。

略读的产出不是“我大概看过了”，而是一句暂定主旨和几个段落标签。词汇明显超过学生水平时，先判断材料难度，不用技巧掩盖词汇问题。

第一遍不要求把每句整理成完整中文。优先抓“谁或什么、发生什么、作者重点和段落作用”；不阻断当前目的的生词或细节可以先标记后继续。

## 阅读阶段的翻译边界

```text
略读建图：不逐句翻，可写中文短标签
→ 扫读定位：不翻扫过的全部内容
→ 证据精读：先按意群理解必要范围
→ 关键关系仍不清楚：才局部拆句或翻译
```

学生读得慢不等于有翻译依赖。关键词大量不认识时先处理词汇或材料难度；词大多认识但句子关系看不清时补当前关键句结构。只有基本能懂却坚持每句形成完整中文才继续，才把它作为阅读习惯补漏。详细诊断和台阶见 `分层阅读与翻译边界.md`。

## 第二步：识别题型

根据题干判断当前主要是细节、推理、词义、主旨、标题、指代、结构、句子还原还是写作手法。确定后只读取并调用对应题型流程，不一次复述所有题型技巧。

## 第三步：扫读定位

1. 划出题干中的定位词；
2. 优先选择人名、数字、地点、专有名词和少见实词；
3. 预测原文可能使用的同义表达；
4. 结合主旨草图判断大概段落；
5. 找到后停止扫读，进入证据精读。

“题目顺序大致对应文章顺序”只能辅助缩小范围。找不到时回到文章结构，不盲目在预计位置作答。

## 第四步：确定证据范围

不同题目所需范围不同：

```text
一个短语 → 一个句子 → 前后句 → 当前段 → 多段或全文
```

先用最小足够范围；局部不能唯一决定时再扩大。找到关键词不等于找到答案，必须阅读它所在句及必要上下文。

## 第五步：先说证据，再看选项

在能够做到时，先用简短中文说出原文证据的意思，再比较选项，减少被干扰项的原词和熟悉表达带偏。这里允许准确概括必要证据，不要求翻译整篇或把译文修饰得完整通顺。

推理题的选项常有一两个一眼就错，可以先扫选项把明显错的排掉，再对剩下的选项找决定性证据（见 `考点/02-推理判断.md`）。排错必须有依据，不能凭感觉；最后定案仍以原文证据为准。

词义猜测按 `考点/03-词义猜测.md` 先将选项代入所在短语比较；简单情况到这里即可，信息不足时再扩大到所在句、前后句或段落。不要求这类题先自行猜义再看选项。其余题型仍按各自流程核对证据。

逐项检查：

- 是否回答了题干；
- 人物、时间和对象是否一致；
- 范围、程度、肯否和语气是否改变；
- 是原文、合理最短推理，还是无中生有；
- 是否只复现关键词却改变了关系。

## 高中扩展分支

高中常规四选一阅读在基础流程走完后，若仍出现以下断点，再读取 `高中扩展.md` 并只调用对应模块：

- 选项没有原词，需要保留主体、关系、条件、范围和语气进行复杂同义改写；
- 作者、研究者、机构或被引人物的立场被混在一起；
- 相关、条件、原因、机制和结果被选项重新组合；
- 研究类或议论类文章需要先识别分组、测量、结果、让步、反驳或权衡；
- 一处证据不足，需要组成最小跨句或跨段证据链；
- 题干问某项测量、引语或段落为什么出现、起什么作用。

没有这些证据时不启用扩展。七选五不走本分支，直接转入独立七选五流程。

## 第六步：整篇复查

- 主旨或标题题放回全部段落检查覆盖范围；
- 低把握题重新核对定位和证据范围；
- 同一段连续错时，检查是否主旨或段落功能理解错误；
- 修改答案必须有新证据，不因“感觉另一个更顺”随意更改。

## 错误诊断顺序

```text
材料关键内容、题干和选项是否基本读懂？
→ 是否把每句变成完整中文后才继续？这是语言障碍还是阅读习惯？
→ 作答前是否建立主旨草图？
→ 是否识别了正确题型？
→ 是否选对定位词和证据位置？
→ 是否读足了必要上下文？
→ 是否准确理解证据？
→ 是否识别了干扰项变化？
```

定位第一个断点即可。学生答案错误不等于对应题型方法不会；先听学生说当时的阅读方式、主旨、定位和证据。不能只因总用时较长就判定翻译依赖。

## 报告驱动的结束条件

只处理报告实际暴露的问题。若多个错题都源于没有主旨和上下文意识，合并成一个基础断点；若主要问题是逐句翻译，用难度匹配的新材料确认学生能略读建图、按题定位、只精读必要证据。达到当前断点的最小验证后，即可回到新的真实阅读练习。

## 新问法与新题型的维护入口

题干措辞或选项包装变化不直接视为新题型。只有判断目标、证据范围和决策流程都与现有分类明显不同，并在可靠材料中重复出现时，才按 工作区维护约定 建立候选；通过准入后再更新题型地图和本流程。

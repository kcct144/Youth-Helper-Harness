# 阅读理解学习路径

- 适用学段：初中、高中
- 核心路线：材料与阅读方式适配 → 主旨先行 → 题型分流 → 证据作答
- 默认方式：报告驱动的查缺 → 最小补漏 → 回到新阅读检验

## 报告优先

学生提交阅读报告、错题或原文时，只处理它实际暴露的问题：

```text
先排除词汇、题干理解等基础障碍
→ 检查是否把逐句翻译当成默认阅读方式
→ 检查是否建立主旨和段落地图
→ 判断错在哪一种题型流程
→ 定位第一个断点
→ 少量验证
→ 回到新阅读
```

报告没有出现的题型保持未评估，不把九种题型一次讲完。

## 第零关：材料适配与分层阅读

在主旨训练前先确认材料基本适合，并观察学生怎样读：

- 关键词大量不认识：先处理词汇或更换材料；
- 词大多认识，但看不清句子主干和关系：补当前关键句结构；
- 基本能懂，却坚持每句形成完整中文才继续：按 `分层阅读与翻译边界.md` 训练；
- 能略读建图、扫读定位，只精读必要证据：直接进入主旨和题型流程。

完成证据：学生能在难度匹配的新材料中，不逐句翻译也能给出“对象 + 重点”和段落标签；能跳过暂时不影响任务的内容，并知道证据受阻时可以局部拆句或翻译。

## 第一关：主旨意识

这是默认优先级最高的阅读方法。学生先练：

- 根据版式、标题、开头结尾和重复实词判断话题；
- 用“对象 + 重点”说出全文主旨；
- 给主要段落贴功能标签；
- 识别过宽、过窄和局部冒充主旨。

完成证据：在新文章中无需提醒先建立主旨草图，并能大致说出一道题应去哪个段落找。

## 第二关：Scanning 与细节证据

先从最常见的明确细节开始，训练：

```text
题干定位词 → 预计同义替换 → 原文位置 → 必要上下文 → 选项核对
```

完成证据：学生不会只因原词重现就选答案，能指出定位句并解释选项与原文的对应关系。

## 第三关：按报告补题型流程

只在真实题目出现时逐个补：

- 推理：先扫选项排掉明显错的，再对剩下的选项回原文找决定性证据，只补最短一步；
- 词义：把四个选项分别替换划线词，放回所在短语，看哪个合适；不够用时再读整句、前后句或当前段；
- 主旨和标题：用段落覆盖检查；全文目的看写作动作加核心对象；
- 指代：语法匹配、语义合理和代回；
- 结构：识别段落功能和逻辑推进；
- 句子还原：同时检查前后衔接；
- 写作手法：区分“怎么写”和“在局部起什么作用”。

完成一个题型的当前断点后就停止，不继续自动讲相邻题型。

对应练习模式按先简单后复杂编排：词义先练短语代入，后续关再分别用所在句、前后句与段落；句子还原先分别练前侧或后侧线索明显的情况，再练指代、起承转合、连词连接等。略读的实词提取与关系理解分开练，具体关卡以 `../练习模式/README.md` 为准。

## 高中扩展关：精确改写与复杂篇章

只有基础定位和证据流程已经做到，或真实高中题明确需要时才进入。详细内容见 `高中扩展.md`。

按报告只补一个分支：

- 复杂同义改写及范围、程度、可能性偷换；
- 作者与被引人物立场；
- 相关与因果、条件与机制；
- 研究类或议论类篇章结构；
- 跨句跨段最小证据链；
- 写作目的、研究设计目的或段落作用。

完成证据不是“听懂分析”，而是在表述不同的新题中独立指出最小证据、保留必要边界，并说明干扰项偷换在哪里。一次只处理当前断点，不把高中扩展变成每篇固定加长流程。

## 第四关：混合与整篇迁移

在词汇难度合适的新文章中混合不同题型，检查学生能否：

1. 先建立主旨；
2. 自己识别题型；
3. 使用相应定位和证据范围；
4. 识别干扰项；
5. 低把握时回到原文，而不是凭印象修改。

强化优先回到学生原有练习平台或新试卷。AI 当场只需提供足以验证刚补断点的短材料或少量题目。

## 主旨意识不足的常见信号

- 一开始就看题、搜关键词，从未概括全文；
- 每道题都能找到相似单词，但连续选错；
- 主旨只能说成一个宽泛名词；
- 不知道各段分别有什么作用；
- 把例子、单个人物或某一段当全文中心；
- 推理依赖常识，没有用全文方向限制结论。

出现以上信号时先补主旨意识，不急着逐题讲九种技巧。

## 翻译依赖的常见信号

- 从第一句开始按相同速度逐句处理，不区分主旨信息和例子细节；
- 每句话都要在脑中或纸上形成完整中文才继续；
- 遇到不影响主旨的生词也立刻停下；
- 全文译了很多，却说不出段落功能和证据位置；
- 基本词汇和结构够用，在“不求完整译文”的任务中理解不下降而速度改善。

只出现“用时较长”不能确诊。先按 `分层阅读与翻译边界.md` 排除材料、词汇和句子结构问题。

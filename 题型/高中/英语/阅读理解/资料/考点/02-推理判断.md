# 阅读理解题型：推理判断

- 题型范围：由原文事实能够支持但未完全照抄的结论
- 核心方法：在理解全文主旨的前提下，先扫选项排掉明显错的，再对剩余选项用原文证据定案
- 默认目标：推得出，但不推太远

## 常见问法

`infer / imply / suggest / conclude / probably / learn from` 等。

## 标准流程

```text
看清题干在问什么，带着它扫四个选项，排掉一眼就错的（常识代替原文、绝对化、多跳、与全文方向冲突）
→ 对剩下的选项回原文找决定性证据
→ 用自己的话重述证据，只补最少的一步关系，不新增原文没有的信息
```

“一步推理”表示推理距离尽量短，不是机械规定只能进行一个逻辑动作。

**先理解全文主旨，再走上面的流程会顺利很多**：主旨决定方向，能帮着判断哪些选项一看就偏。主旨是前提，不是流程的最后一步。

选项预筛只用来去掉明显错的，排错必须有依据；对最后留下的选项仍要找到决定性原文依据，不能用“哪个顺眼”定案。这与 `../做题流程.md` 第五步“先说证据，再看选项”不冲突，只是把明显错的选项先去掉。

## 常见干扰项

- 符合常识但原文没有依据；
- 从“可能”推成“一定”；
- 把局部人物的情况扩大到所有人；
- 加入新的原因、动机或结果；
- 与全文态度或发展方向冲突。

## 边界

- 不能仅因某个选项接近原文表述就排除它。判断关键是题干所问及选项是否正确表达原文能支持的结论。
- 主旨草图用于限制推理方向，但不能代替具体证据。
- 高中题涉及作者与被引人物、条件性因果、研究结论语气或跨段证据时，读取 `../高中扩展.md` 对应模块；“最短推理”仍然有效，但必须先分清信息来源和结论边界。

## 完成证据

学生能分别说出“原文写了什么”和“我从中多推出什么”，且后者没有新增未经支持的信息。

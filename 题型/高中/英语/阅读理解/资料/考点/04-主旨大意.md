# 阅读理解题型：主旨大意

- 题型范围：全文或某一段的主要内容；作者写整篇的目的
- 核心方法：对象 + 作者重点 + 段落覆盖；目的题另加写作动作
- 前置资料：`../主旨意识.md`

## 常见问法

- `What is the passage mainly about?`
- `What is the main idea of the passage / paragraph?`
- `The passage mainly tells us ...`
- `What is the purpose of the passage?`
- `Why does the author write this passage?`

## 标准流程

```text
确认问全文还是某一段
→ 找核心对象
→ 结合标题、首尾、段落功能和重复内容确定作者重点
→ 用一句话概括
→ 检查是否覆盖主要段落
→ 排除过宽、过窄、局部细节和无中生有
```

问全文目的（作者为什么写整篇）时，在概括主旨之后再加上写作动作：

```text
概括主旨
→ 提取核心对象
→ 加写作动作：介绍、解释、报告、比较、讨论、质疑、提醒、倡议
→ 核对选项是不是动作开头
```

## 常见干扰项

- 文章确实提到，但只覆盖一个例子或一段；
- 只有宽泛话题，没有作者具体重点；
- 加入文章没有讨论的大概念；
- 把结果、原因或背景中的一项冒充全文中心。

## 边界

- 首段、末段、段首句是高价值线索，不是固定答案位置。
- 记叙文主旨常要结合人物变化和结果，不能只抄第一句。
- 目的题问的是“为什么写”，不是“讲了什么”；答案多为动作开头（`To encourage ...` / `To warn ...`），与主旨题的概括式选项不同。
- 判断全文目的必须先有全文主旨；“这样写起什么作用”的局部作用属 `09-写作手法.md`，本文件不管。

## 完成证据

学生能解释正确选项如何覆盖主要段落，并指出其他选项过宽、过窄或偏离在哪里；目的题还能说出写作动作和核心对象。

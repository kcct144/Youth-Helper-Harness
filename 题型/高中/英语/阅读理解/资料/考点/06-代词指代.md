# 阅读理解题型：代词指代

- 题型范围：`it / they / this / that / these / those / one / ones` 等具体指什么
- 核心方法：候选先行词 → 语法匹配 → 语义代回 → 篇章延续
- 默认目标：不机械选择最近名词

## 标准流程

```text
找到代词及所在句
→ 向前寻找可能的名词、名词短语或整件事
→ 检查单复数、人或物等语法匹配
→ 代回原句检查语义是否合理
→ 检查当前段正在延续哪个人物或概念
```

## 重点

- `he / she` 通常指人，并要符合人物信息；
- `it` 常指单数事物，但也可能承担形式结构；
- `they / them` 通常要求复数或群体；
- `this / that` 可能指前面的整个动作、事实或观点；
- `one / ones` 指前文同类事物，不一定是完全相同的对象。

## 边界

最近名词只是候选，不是答案规则。若最近名词在单复数、语义或篇章重点上不匹配，应继续向前寻找。

## 完成证据

学生能列出候选、说明语法和语义排除依据，并把最终对象代回原句读通。

# 阅读理解题型：文章结构

- 题型范围：段落怎样组织、信息怎样推进
- 核心方法：段落功能标签 + 过渡和逻辑关系
- 前置资料：`../主旨意识.md`

## 常见结构

| 结构 | 常见推进 |
| --- | --- |
| 总—分 / 总—分—总 | 提出中心 → 分项说明 → 可选总结 |
| 时间或事件顺序 | 起因 → 经过 → 变化 → 结果 |
| 对比 | 对象 A 与对象 B 的异同 |
| 问题—解决 | 问题 → 原因或影响 → 办法 → 结果 |
| 观点—理由—例子 | 观点 → 支持理由 → 证据或例子 |
| 说明分类 | 对象 → 多个方面、类型或步骤 |

## 标准流程

```text
先确认全文主旨
→ 给每段贴功能标签
→ 找时间词、转折、因果、顺序和总结表达
→ 画出段落之间的关系
→ 用选项核对，而不是只数段落
```

## 边界

- `first / then / finally` 等是线索，没有明显连接词时仍要看内容关系。
- 同一文章可能同时具有多层结构，例如全文“总—分”，某一段内部按时间推进。
- 高中研究类的“问题—分组—测量—结果—解释”，或议论类的“观点—让步—回应—权衡”按 `../高中扩展.md` 处理；只在真实材料需要时启用。

## 完成证据

学生能用几个短标签概括段落功能，并说明选项描述的是全文结构还是局部结构。

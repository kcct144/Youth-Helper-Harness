# 阅读理解题型：句子还原

- 题型范围：选择或判断一个独立句子应放在文章哪个位置
- 考试范围：按学生所在地区和卷型启用
- 核心方法：全文主线 + 前后双向衔接
- 题型边界：只处理单个独立句子的位置判断，或各小题不共享句子池的独立判断；不处理初高中短文多空共享句子选项池的整组任务

## 标准流程

```text
先掌握全文主旨和段落功能
→ 读候选句，圈出代词、连接词和关键词
→ 看空格前一句需要怎样承接
→ 看空格后一句需要怎样开启
→ 检查指代、复现、逻辑、时态和人物一致
→ 代入后同时通读前后
```

## 常见线索

- 指代对象必须已经出现或能自然引出；
- `however / therefore / also / then` 等显示逻辑；
- 原词、同义词和上下位概念形成复现；
- 总述句与后面的例子、分述相连；
- 时间、人物和时态保持一致。

## 分情况训练

先练和前面关系紧密、和后面关系紧密的明确情况，再分别练指代、起承转合、连词实际连接的内容、复现和总分关系，最后综合通读。关卡编排见 `../../练习模式/README.md` 的 Unit 09。

这些是训练侧重点，可以重叠。前后双向核对仍保留，但入门时只让一种线索成为主要难点；复杂指代或多种线索纠缠的题放到后续实际需要时讨论，不一次讲完。

## 使用边界

- 只与前一句通顺不够，还要与后一句相连。
- 看到相同词不能直接选择，要检查整个关系。
- 本题型未出现在学生当前考试范围时不主动训练。
- 题目若在同一短文中有多个空共用一个句子选项池，无论题面称五选四、六选五、七选五还是其他名称，也无论是否有多余项，立即转入 七选五题型工作区（本目录不加载其技能）；具体数量、能否重复和剩余项规则按题面确认，不能用本单题文件评价该独立题型能力。

## 完成证据

学生能分别说明候选句怎样承接前文、怎样引出后文，并验证它在段落中的功能。
